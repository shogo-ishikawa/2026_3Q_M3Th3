# プロジェクトの管理

学生・グループのコードは、この `projects/` ディレクトリ以下で管理します。作品ごとにディレクトリを作り、その中にコード、データ、説明書をまとめてください。

## 名前と置き方

- ディレクトリ名には、作品の内容が分かる英小文字・数字・ハイフンを使います。例：`recipe-suggester`。
- 別のグループで開発する作品は、既存の作品と重ならない名前にしてください。
- 氏名や学籍番号をディレクトリ名に含める必要はありません。
- ファイルの置き方は作品に合わせて構いませんが、実行方法を `README.md` に書いてください。

| ファイル・ディレクトリの例 | 内容 |
| --- | --- |
| `README.md` | 作品の目的、使い方、工夫した点 |
| `notebooks/` | Google Colabなどで実行するノートブック |
| `data/` | 配布するサンプルデータと、その説明 |
| `docs/` | 試した結果、改善案、発表資料など |

上の構成は一例です。小さな作品では、ノートブックと `README.md` だけでも構いません。

## 開発を始めるとき

1. 作品用ディレクトリを作り、目的を `README.md` に書きます。
2. 最小限の機能を動かし、試した条件と結果を記録します。
3. 改善目標を一つ決めてコードを変更し、結果を比較します。
4. AIを利用した場合も、変更した処理の役割を説明できるようにします。

## 現在のプロジェクト

- [料理・レシピ提案](recipe-suggester/)：教員が用意した初期コード（Google Colab 用のノートブック `recipe_suggester.ipynb`）です。
- [pip0](pip0/)：グループが考えたファイル整理アシスタントの初期コードです（Windows 11 用。Python の本体、C# の画面と OS 連携、ブラウザー拡張）。Windows 以外でも、ダミーデータのデモ（`python -m pip0 demo`）と自動テストを試せます。
