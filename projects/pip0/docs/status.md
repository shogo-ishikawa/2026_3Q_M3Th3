# pip0 の実装状況と確認の状況（2026-11-02 時点）

指示書（[CLAUDE_CODE_PROMPT.md](../CLAUDE_CODE_PROMPT.md)）7節が求める、M1〜M5・基本仕様・権限・削除確認の「実装状態と検証結果の対応表」です。
実際に行った確認の手順と結果は [verification.md](verification.md) にあります。

**大事なこと：この初期コードは、Windows 11 の実機ではまだ一度も動かしていません。**
下の表の「確認」は、Linux 上での自動テスト・デモ・ビルドなどの結果です。実機で確かめたら、この表を更新してください。

## 6. 実機（Windows 11）で確かめること

[setup-windows.md](setup-windows.md) の手順で導入し、上の表の W を順に確かめます。修正のときに加えた決まりのうち、実機でしか確かめられないものを、ここにまとめます。

| 確かめること | 見るところ |
| --- | --- |
| 「常にこのデバイス上に保持する」の属性の値 | pip0 専用フォルダーの中の通常のファイルに `attrib +P`、またはエクスプローラーの「常にこのデバイス上に保持する」を付けたとき、属性が `PINNED` だけで再解析ポイントがなく、`get_local_state` が `placeholder=False`・`pinned=True` になり、退避が「常にこのデバイス上に保持する」の理由で断られること |
