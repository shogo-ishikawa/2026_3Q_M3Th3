# pip0 の実装状況と確認の状況（2026-10-30 時点）

指示書（[CLAUDE_CODE_PROMPT.md](../CLAUDE_CODE_PROMPT.md)）7節が求める、M1〜M5・基本仕様・権限・削除確認の「実装状態と検証結果の対応表」です。
実際に行った確認の手順と結果は [verification.md](verification.md) にあります。

**大事なこと：この初期コードは、Windows 11 の実機ではまだ一度も動かしていません。**
下の表の「確認」は、Linux 上での自動テスト・デモ・ビルドの結果です。実機で確かめたら、この表を更新してください。

## 0. 表の言葉

**状態**

| 言葉 | 意味 |
| --- | --- |
| 実装済み（実機未検証） | コードは最後まで書いてある。Windows の機能を使う部分は、実機でまだ動かしていない |
| 実装済み（Linux で試験済み） | OS に依存しない処理で、自動テストで動きを確かめた（Windows でも同じ Python のコードが動く。ただし Windows の Python では未実行） |
| 部分実装 | 一部だけ実装した。足りない点を「残っていること」に書く |
| 未実装 | まだ作っていない |
| 対象OSで非対応 | Windows 11 の制約で、原設計どおりにはできない。代わりの扱いを書く |

**確認の種類**

| 記号 | 確認 | 行った場所 |
| --- | --- | --- |
| T | 自動テスト（`python -m pytest`）。OS の機能は代役（`platform_fake.py`）、ファイルはダミーだけ | Linux、Python 3.11／3.12／3.13 |
| D | デモ（`python -m pip0 demo`）。ダミーデータで検索の3例・改名・機密の判定 | Linux |
| C | pip0 シェル（C#）のビルドと、OS を使わない部分の確認（`shell/Checks`） | Linux の .NET 8 SDK |
| E | ブラウザー拡張 → 受け口 → 暗号化DB の通し確認（Chromium に拡張機能を読み込み、本物の受け口を起動） | Linux の Chromium |
| S | スクリプトの構文と、Windows のコマンドを代役にした関数の確認 | Linux の PowerShell 7 |
| **W** | **Windows 11 の実機での確認** | **すべて未実施** |

「代役での試験」（T）は、Windows の動きをまねた結果です。Windows で同じ結果になることは、実機（W）で確かめるまで分かりません。
