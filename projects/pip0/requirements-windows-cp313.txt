# pip0 専用の Python（Windows 11、CPython 3.13、64 ビット）に入れるライブラリの一覧（版とハッシュを固定）
#
# scripts\install.ps1 が、PC に別に入れた Python 3.13 の pip で、導入先の runtime\Lib\site-packages に入れます。
#   py -3.13 -I -m pip install --no-deps --only-binary=:all: --require-hashes
#       --platform win_amd64 --python-version 3.13 --implementation cp --abi cp313
#       --target <導入先>\runtime\Lib\site-packages -r requirements-windows-cp313.txt
#   --no-deps        ：依存ライブラリを自動では足さない。そのため、Windows で要る間接の依存も、下にすべて書いています
#   --require-hashes ：ダウンロードした wheel の SHA-256 が下の値と違えば、何も入れずに止まります
#   --only-binary    ：ビルド済みの wheel だけを使い、PC の上でソースからビルドしません
#
# requirements.txt（開発・テスト用。直接使う5つ）との関係
#   直接使うもの（版は requirements.txt と同じ）：sqlcipher3、keyring、watchdog、pillow、pypdf
#   keyring が Windows で使うもの：pywin32-ctypes、jaraco.classes、jaraco.functools、jaraco.context、more-itertools
#   Windows では使わないもの：SecretStorage と jeepney（条件が sys_platform == "linux"）、
#                             importlib_metadata（Python 3.12 未満だけ）、backports.tarfile（同じく 3.12 未満だけ）
#
# 作り方（2026-10-30。Linux の pip 26.2.2 で作成）
#   1. 空の作業フォルダーへ、Windows・CPython 3.13 用の wheel をダウンロードする
#        pip download --no-deps --platform win_amd64 --python-version 3.13 --only-binary=:all: --implementation cp
#            -d <空のフォルダー> sqlcipher3==0.6.4 keyring==25.7.0 ...（下の10個）
#   2. 各 wheel の .dist-info/METADATA の Requires-Dist を、Windows の条件（sys_platform == "win32"、
#      python_version == "3.13"）で確かめ、必要な依存がすべて下にあり、版の条件を満たすことを確かめる
#      （pip download の依存の解決は、sys_platform を実行している OS（Linux）で判断するため、
#       そのままでは pywin32-ctypes が抜け、Linux 用の SecretStorage 等が入ってしまいます）
#   3. 各 wheel の SHA-256 を計算する（Linux：sha256sum、Windows：Get-FileHash -Algorithm SHA256）
#      PyPI の JSON API（https://pypi.org/pypi/<名前>/<版>/json）の sha256 とも一致することを確かめました
#   4. 確かめ方：別の空のフォルダーへ、この一覧でダウンロードし直す（ハッシュが1つでも違えば失敗します）
#        pip download --no-deps --require-hashes --platform win_amd64 --python-version 3.13
#            --only-binary=:all: --implementation cp -d <別の空のフォルダー> -r requirements-windows-cp313.txt
#   各版の Windows・CPython 3.13・64 ビットで使える wheel は、どれも1つだけでした（下のファイル名）。
#
# 版を上げるときは、requirements.txt と、この一覧の両方を直し、上の手順でハッシュを作り直してください。
# 入手元はすべて PyPI（https://pypi.org/project/<名前>/）。ライセンスは各行の上に書いています。
