# pip0 Web — ファイル整理アシスタント

ファイルを取り込み、仕分け先と名前を確認してから整理済みのコピーを書き出すアプリです。学生の提出コードをもとに、教員がブラウザ向けに再構成した公開用アップデート版です。

- [Web版を開く](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/pip0-web/)
- [使い方](docs/manual.md)
- [学生版との対応](docs/provenance.md)
- [Windows向けの元プロジェクト](https://github.com/shogo-ishikawa/2026_3Q_M3Th3/tree/main/projects/pip0)

## できること

「デモを試す」から架空の資料や画像を使って操作できます。自分のファイルはファイル選択、フォルダー選択、ドラッグ＆ドロップで取り込みます。

| 機能 | 内容 |
| --- | --- |
| 仕分け | ファイル名・種類と、任意で読み取った本文から整理先を提案。一致したルールを表示します |
| 改名 | 初期設定では元の名前を維持。更新日や連番を付ける設定に変更できます |
| 思い出し検索 | 名前や本文の語に加え、「先週」「PDF」「青い画像」などの手掛かりで検索します |
| 重複確認 | 同じサイズの候補についてSHA-256を計算し、内容が一致するファイルをまとめます |
| 書き出し | 選んだファイルを整理済みZIPにまとめるか、対応ブラウザで別フォルダーへコピーします |
| ルール編集 | JSON形式のキーワードと拡張子を編集。設定の保存は明示的に操作した場合だけ行います |

元ファイルの移動や削除は行いません。コピー先に同名ファイルがある場合も上書きしない構成です。

## 読み取りとデータの扱い

通常はファイル名・サイズ・更新日時などの情報を使います。本文と画像の解析は任意です。1MiB以下の対応するテキスト形式を調べ、画像は縮小した画像の代表色を求めます。PDFやOffice文書の本文、画像内の文字は読み取りません。

解析・検索・重複確認は端末内で処理します。取り込んだファイル、本文、索引をサーバーに送信したり、ブラウザの永続ストレージへ保存したりしません。ページを再読み込みした場合は取り込み直してください。自分で保存したルール設定と、ダウンロードしたZIP・整理計画は残ります。

日付の手掛かりはファイルの**更新日時**です。作成日・入手日・最終閲覧日とは区別します。入手経路を自動で取得する機能もありません。不明な情報から送信元や内容を推測しません。

取り込み上限は500ファイル、1ファイル100MiB、合計250MiBです。ZIPは無圧縮で生成するため、出力サイズは元データとほぼ同じです。大量のデータは分けて取り込んでください。

## ローカルで起動する

ダウンロードしたZIPを展開すると`v1.0.0`フォルダーができます。Python 3がある場合は、そのフォルダーで次を実行します。

```bash
python3 -m http.server 8000
```

ブラウザで`http://localhost:8000/`を開きます。Windowsで`python3`がない場合は`py -m http.server 8000`を使います。JavaScriptのモジュールを使うため、HTMLファイルのダブルクリックでは起動できない場合があります。

フォルダーへの直接コピーは、File System Access APIが利用できるChrome・Edgeなどで使えます。利用できないブラウザではZIPを書き出してください。公開URLはHTTPS、ローカル起動はlocalhostを使います。

## コードから学ぶ

まず`core.js`のルールと仕分け処理を読みます。辞書の配列、`for`、`if`、文字列の比較で「どの条件に一致したか」を記録しています。キーワードを追加し、デモの仕分け先がどう変わるか試すところから始められます。

| ファイル | 役割 |
| --- | --- |
| `core.js` | 仕分け・改名・検索の判断 |
| `demo.js` | 架空のデータを作る処理 |
| `io.js` | 読み込み・画像解析・ハッシュ・ZIP・コピー |
| `app.js` | 画面の操作と状態の管理 |
| `styles.css` | 配色とレイアウト |

Pythonで試す場合は、Google Colabで次の例を動かせます。キーワードによる点数付けだけを取り出した短い例です。ファイル名とキーワードを変え、`for`と`if`で結果がどう変わるか確かめてください。

```python
rules = [
    {"folder": "授業・レポート", "keywords": ["レポート", "課題"]},
    {"folder": "予算・会計", "keywords": ["予算", "請求"]},
]
name = "物理レポート.pdf"
for rule in rules:
    score = 0
    for word in rule["keywords"]:
        if word in name:
            score += 2
    if score >= 2:
        print(rule["folder"], score)
```

Windows版の常駐監視、他アプリとの連動、退避と自動復元、機密ファイルのドラッグ警告はWeb版には含みません。元の学生提出版は講義サイトで学内向けに案内しています。

## 検証と配布物の作成

Node.js 24とPython 3.12以降を使います。実行用の追加ライブラリは不要です。

```bash
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tools/build_release.py
```

`dist/pip0-web_v1.0.0.zip`へ配布物を作成します。公開用のブラウザコードと説明書・検証用コードだけを梱包し、Windows版や学生の提出ZIPを混ぜません。

## HTTPSで授業リポジトリへ反映する

例として`/Users/shogo/Dropbox/share_data/open_material/misc/apps/pip0-web/v1.0.0`へ展開した場合は、次のように実行します。引数は授業リポジトリのローカルパスです。

```bash
cd /Users/shogo/Dropbox/share_data/open_material/misc/apps/pip0-web/v1.0.0
bash tools/sync_project.sh /Users/shogo/Dropbox/share_data/open_material/misc/apps/2026_3Q_M3Th3
```

同期先は既存の授業リポジトリの`projects/pip0/web/`です。同じ`projects/pip0/`内にあるWindows版は変更しません。GitHubへの認証はGit側の設定を使います。アクセストークンをソースやスクリプトへ書き込まないでください。
