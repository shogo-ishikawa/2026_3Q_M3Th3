ルールを編集する

keywordsは名前と取得した本文で探す言葉です。extensionsには「.pdf」のように拡張子を指定します。folderが整理先になります。

保存するのはルールだけです。ファイル名・内容・一覧は保存しません。

提案はどう決まる？

キーワードが一致すると2点、拡張子が一致すると1点を加えます。2点以上になった分類のうち最も点数の高いものを提案します。同点ならルールの並び順を使います。十分な手掛かりがなければ「未分類」に残します。

この仕組みは学生版pip0の規則を基にしています。生成AIへファイルを送る処理はありません。

A SMALL GUIDE

整えるための、4ステップ。

まずは少ないファイルで試してみてください。

01 / IMPORT

取り込む

ファイルやフォルダーを選びます。新しく取り込むと、表示中の一覧と提案は置き換わります。最大500件、1件100MiB、合計250MiBまで扱えます。

02 / REVIEW

提案を見る

元の名前と整理先を並べて確認します。種類だけで決めつけず、名前などの手掛かりと提案の理由を表示します。

03 / ADJUST

自分で直す

整理先や名前を書き換えられます。チェックを外したファイルは書き出しません。完全に同じ内容でも、自動では取り除きません。

04 / EXPORT

コピーを書き出す

ZIPまたは新しい保存用フォルダーにコピーします。元のファイルを移動・削除する機能はありません。対応表も一緒に保存します。

読み取れる情報について

通常は名前・拡張子・容量・更新日を使います。「本文と画像も調べる」をオンにすると、1MiB以下のテキスト形式と対応する画像をブラウザ内で解析します。PDFやWord、Excel、PowerPointの本文は解析しません。画像の文字認識もしません。

更新日は撮影日や入手日とは異なります。入手元や以前の使用状況は分かりません。画像の色は大まかな傾向であり、写っているものの意味を認識する機能ではありません。

学生版pip0とのつながり

学生の設計と提出コードを基に、仕分け・改名の提案や手掛かりからの検索をWeb向けに発展させました。学生の提出版は講義サイトから学内向けに案内しています。

学生版はWindows向けの常駐アシスタントです。このWeb版は選んだファイルを扱います。他のアプリの監視や退避ストレージ、機密ファイルをドラッグしたときの警告は備えていません。
