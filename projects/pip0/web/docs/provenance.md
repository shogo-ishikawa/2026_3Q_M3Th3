# 学生版との対応

このアプリは、学生が提出したファイル整理アシスタント「pip0」のコードと設計をもとに、教員が公開用にアップデートしたWeb版です。学生の提出版そのものとは区別して公開しています。学生の氏名・学科・学籍番号は掲載しません。

## 引き継いだ判断と再構成した操作

| 元の処理・設計 | Web版での扱い |
| --- | --- |
| `pip0/rules.py`の仕分け規則 | フォルダー名・キーワード・拡張子を持つルールの配列として再構成。画面から編集できます |
| `pip0/inflow.py`の点数と理由 | キーワード2点、拡張子1点、しきい値2点、同点ではルール順という考え方を継承。該当した理由を表示します |
| `pip0/naming.py`の改名提案 | 変更前後を確認する操作へ再構成。初期設定では元の名前を維持します。更新日付き・連番を任意で選びます |
| `pip0/search.py`の手掛かり検索 | 時期・種類・色・キーワードによる検索と一致理由をブラウザ向けに再実装します |
| `pip0/safe_names.py`の名前の検査 | 不適切なパスや名前を防ぎ、同名の出力を区別する方針を継承します |
| 入手経路を推測しない方針 | ブラウザで得られない送信元やダウンロード履歴は不明として扱います |
| 端末内で処理する方針 | ファイルの解析・検索・重複確認・書き出しを端末内で実行します |

元のコードはPythonを中心にC#のシェルとブラウザ拡張を組み合わせるWindows 11向けの構成です。Web版のJavaScriptは、ブラウザのファイル選択と書き出しに合わせて書き直しています。全機能や全条件での出力一致を示すものではありません。

Web版では日付を選択ファイルの更新日時として扱います。元のダウンロード完了日時と同じ意味にはしません。OSの作業文脈を自動取得する代わりに、実際に取り込んだファイルと取得できた情報から提案します。

## Web版で追加したこと

- 変更前後の確認と出力対象の選択
- 整理先と名前の候補の編集
- 完全に内容が一致するファイルの確認
- 元ファイルを残すZIPとコピーの書き出し
- ブラウザ内で編集できるルール

## Web版に含まない機能

Windowsの常駐監視、前面アプリや会話との連動、退避ストレージとゴーストの自動復元、機密ファイルをドラッグした際の警告、Windowsの暗号化DBや資格情報マネージャーとの連携は移植していません。ファイルの削除も行いません。
