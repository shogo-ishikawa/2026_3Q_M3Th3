# pip0 Web v1.0.0 の検証

## 自動検証

- JavaScript 45件。元の採点規則、説明付き検索、更新日の境界、Unicodeの同名衝突、入力の制限、ZIPのCRCと原本一致、SHA-256の重複確認を検査しました。
- 保存先の代役を使い、既存ファイルを変更しないこと、書き込み後の内容照合、中断・権限エラー・破損時の部分出力の表示を確認しました。
- 配布検証5件。単一バージョンフォルダー、再現可能なZIP、相対モジュールの完全性、Windows版の非混入と非変更、外部送信経路や認証情報の混入を確認しました。
- 共通Pages構築検証5件。ほかの作品を残して公開する構成を確認しました。

## ブラウザで確認した操作

- 15件のデモ読み込みと理由付きの仕分け提案。
- SHA-256で1組の重複を確認。
- 任意の本文・画像解析後、青い画像2件と先週更新されたPDFを検索。一部一致は区別して表示。
- 検証用テキスト3件をファイル選択から取り込み、解析前後で分類が変わることを確認。
- 名前の変更と除外を設定してZIPをダウンロード。展開内容のCRCと対応表をPythonで確認し、14件の選択と新しい名前が反映されることを確認。
- 手動編集後に解析設定を切り替え、確認画面をキャンセルすると名前と除外状態が残ることを確認。
- 親フォルダーを指定する不正なルールを拒否。
- 340 CSSピクセル相当の表示幅でタブが収まり、ページ全体に横方向のはみ出しがないことを確認。ファイル一覧の表は枠内で横スクロールします。実機スマートフォンでは未検証です。

## 確認の限界

クラウドの検証用Chromeでは、フォルダーを直接選ぶ操作が実行環境に拒否されました。実フォルダーへのコピーはブラウザで通し確認していません。コピー処理と内容照合は代役のファイルシステムで検証しています。直接保存が許可されない場合は、画面でZIP保存を案内します。

PDF・Office文書の本文、画像の文字認識、入手経路の取得、常駐監視、Windowsの退避・復元は対象外です。
