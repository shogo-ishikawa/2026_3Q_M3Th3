# pip0 Webの使い方

## 1. デモで試す

「デモを試す」を押すと、架空のレポートや写真を取り込みます。仕分け先の候補と、一致した理由を確認してください。重複確認やZIPの書き出しも実際のデモファイルで試せます。

## 2. 自分のファイルを取り込む

ファイルを選ぶか、画面へドラッグ＆ドロップします。フォルダー選択では、その中のファイルと相対的な階層を読み取ります。取り込み上限は500ファイル、1ファイル100MiB、合計250MiBです。上限やファイル名の検査で取り込めなかった項目は理由を表示します。

ファイルの内容や索引はページを開いている間だけ保持します。再読み込みやタブを閉じる操作で失われるため、残したい整理計画やZIPは先に保存してください。

## 3. 提案を確認する

仕分けはルールのキーワードと拡張子を使います。キーワードの一致は1語につき2点、拡張子の一致は1点です。2点以上になった候補から最も高いものを選び、同点ならルールの上から順に選びます。どのルールにも十分に一致しないファイルは「未分類」に入ります。

最初はファイル名を変えません。必要なら更新日を付ける設定や連番に変更できます。日付別のフォルダー分けも選べます。更新日は作成日やダウンロード日とは異なります。

出力対象のチェックを外したファイルはZIPやコピーに含めません。同じ出力先名になる場合は名前を区別し、別の内容を同じファイルへまとめないようにします。書き出す前に変更前後の一覧を確認してください。

## 4. 本文や画像も調べる

解析は任意です。1MiB以下の対応するテキスト形式を読み、キーワード検索や仕分けに使います。対応する画像では縮小画像から代表色を求めます。

- PDF・Word・Excel・PowerPointの本文やタイトルは読み取りません。名前、拡張子、更新日時などで扱います。
- 画像内の文字の読み取り、人物認識、グラフの意味の理解は行いません。
- 「青い画像」は代表色の判定です。小さな青い部分がある画像をすべて検出する機能ではありません。
- SVGは画像解析に使いません。
- 入手経路は取得しません。ファイル名から送信元を推測することもありません。

ファイルの内容は外部のAIやサーバーへ送りません。内容が取得できなかった場合も、名前から本文や送信元を補いません。

## 5. 思い出し検索と重複確認

「先週のPDF」「今月のレポート」「青い画像」など、更新時期・種類・色・名前や本文の語を組み合わせて探せます。画像の色を使う場合は先に画像解析を実行します。検索結果には一致した手掛かりを表示し、一部の手掛かりだけに合う候補は区別します。

重複確認では、サイズが等しいファイルの内容についてSHA-256を計算します。名前が違っても内容が一致するものを表示します。同じ名前という理由だけで重複にはしません。重複を確認しても自動で削除せず、書き出すものを自分で選びます。

## 6. 整理したコピーを保存する

### ZIPを作る

選択したファイルを`pip0-organised/`の中へ仕分け、ZIPとしてダウンロードします。ZIPは無圧縮です。`_pip0_manifest.json`には出力名と元の相対パスなど、今回の整理内容を記録します。このファイルには元のファイル名も含まれるため、他人に渡す前に内容を確認してください。

### 別フォルダーへコピーする

対応ブラウザでは保存先フォルダーを選び、書き込みを許可します。アプリは保存先の下に新しいフォルダーを作り、その中へコピーします。コピー後の内容をハッシュで確認します。元ファイルの移動や削除、既存ファイルへの上書きは行いません。

中止やエラーが起きた場合は、その時点までに作成したフォルダーが残ることがあります。表示されたフォルダーと処理結果を確認してください。アプリが残ったファイルを自動削除することはありません。

## 7. ルールを変える

ルール編集欄には、フォルダー名・キーワード・拡張子をJSON形式で指定します。正規表現は使いません。まずデモで試し、仕分け先と理由が想定に合うか確認してください。ルール内のキーワードは部分一致です。

```json
[
  {
    "id": "lecture",
    "name": "授業・レポート",
    "folder": "授業・レポート",
    "keywords": ["授業", "レポート", "課題"],
    "extensions": [".pdf", ".docx"]
  }
]
```

設定を保存する操作をした場合だけ、ルールをこのブラウザに保存します。ファイルや本文は一緒に保存しません。

## 学生版との違い

Web版は自分で選んだファイルを扱う道具です。Windowsに常駐する元のアプリとは機能や操作が異なります。元の発想と対応範囲は[学生版との対応](provenance.md)を参照してください。

## ファイル名とフォルダーの制限

パスは8階層まで、各名前は120文字かつUTF-8で255バイト以内で扱います。Windowsで使えない名前や記号、親フォルダーへの指定は取り込み・書き出しの前に拒否します。該当する項目は取り込み結果で確認してください。
