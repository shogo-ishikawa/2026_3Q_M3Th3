# LUMEN — 音と光のアトリエ

指先の動きや音から、光の風景を作るブラウザーアプリです。学生作品「音と視覚のつながりとデジタルアート」を基に、描画と音の解析、操作画面を公開用に発展させています。

対応版：v1.0.0

[アプリを開く](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/sound-visual-art/) · [Colabで計算を試す](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/sound-visual-art/lumen_lab.ipynb) · [使い方](docs/manual.md) · [仕組みと学生版との対応](docs/design.md) · [学生コードからの来歴](docs/provenance.md)

## まずは触ってみる

最初は音を出さずにデモが流れます。画面をなぞると、指先に光が生まれます。上の方では暖色の鋭い光、下の方では寒色の丸い光になり、素早く動かすほど光が強くなります。タッチ操作では複数の指を使えます。

| 場面 | 楽しみ方 |
| --- | --- |
| 光の庭 | 流れる光の中へ花や粒子を描き足す |
| 水の記憶 | 波紋と漂う灯を重ねる |
| オーロラ | 幾重の光の幕と粒子のゆらぎを見る |

設定では配色、光の密度、動き、余韻、画質も調整できます。「画像を保存」で気に入った瞬間をPNG画像として残し、「全画面」で大きく眺めることもできます。

## 音とつなげる

「音源を開く」でファイルを選ぶと、音の大きさや周波数の変化が光へ伝わります。「マイク」は自分で有効にした場合だけ使います。入力音はブラウザー内で解析し、サーバーへ送りません。アプリに録音を保存する機能はありません。

音の出力は初期状態でOFFです。「音を出す」でなぞったときの音を有効にできます。「音源を再生」や実験室の「音を鳴らす」を押した場合も出力をONにします。その後は「音を止める」で出力だけを止め、音源の分析を続けられます。マイクから入った音をそのままスピーカーへ流すことはありません。

音量の表示は機器や録音ごとに変わる相対値です。騒音計のdB値や音圧レベルを測る機能ではありません。音高は周期のある音から基本周波数を推定し、無音や不明瞭な音は未検出として扱います。

## 音と色の実験室

学生版の「同じ音を色・形・数値で表す」という実験も残しています。音の高さと大きさを変え、4パターンを比べたり対応を反転させたりできます。色は青から赤へ、形は丸から星へと変化します。

これは作品として決めた対応です。特定の音に唯一の色が決まることや、人の感じ方が全員同じであることを示すものではありません。対応を変えたときに印象がどう変わるか、自分でも試してみてください。

## コードを読んで発展させる

| ファイル | 担当する処理 | 変更する例 |
| --- | --- | --- |
| `core.js` | 数値の対応、音高推定、デモ信号 | 青から赤への変化幅、音を検出する範囲 |
| `renderer.js` | 粒子、波紋、光の幕 | 光の寿命、形、流れ方 |
| `audio.js` | 音源・マイクの接続と音の再生 | 音の長さ、音量、入力の切り替え |
| `app.js` | 操作画面と各処理の接続 | 操作の追加、パラメーターの組み合わせ |
| `lumen_lab.ipynb` | 学生の対応式を使う公開用のPython教材 | 音の高さ・大きさ・順逆を変え、色・形・数値と短い音を比較 |

まずは公開用の`lumen_lab.ipynb`で入力値を変え、`core.js`と同じ対応式をPythonで計算すると流れを追いやすくなります。リストに形の座標を並べ、繰り返しで点を作り、条件分岐で丸と星を切り替える部分は、Pythonの基礎を作品へつなげる題材になります。

学生の提出原版は学内向けのBoxで配布し、この公開リポジトリやZIPには同梱しません。`lumen_lab.ipynb`は学生の数式を基に作成した発展版の教材です。元コードの既知の問題や公開版で改善した計算は[設計資料](docs/design.md)に記載しています。

## ローカルで動かす

ZIPを展開すると`v1.0.0`フォルダーができます。そのフォルダーで以下を実行し、表示されたアドレスをブラウザーで開きます。追加のJavaScriptライブラリやAPIキーは不要です。

```sh
python3 -m http.server 8000
```

アドレスは`http://localhost:8000/`です。マイクはHTTPSの公開ページかlocalhostで利用してください。ブラウザーやOSがマイクを許可していない場合も、デモとなぞる操作で楽しめます。

ローカルで検査する場合は、Node.jsを使って次のコマンドを実行します。

```sh
node --test tests/*.test.mjs
```
