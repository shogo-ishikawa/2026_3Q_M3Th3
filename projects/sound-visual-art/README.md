# LUMEN — 音と光のアトリエ

指先の動きや音から光の風景を作るブラウザーアプリです。学生作品「音と視覚のつながりとデジタルアート」の発想を引き継ぎ、公開用の体験と教材へ発展させています。

対応版：v1.1.0

[アプリを開く](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/sound-visual-art/) · [Colabで計算を試す](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/sound-visual-art/lumen_lab.ipynb) · [使い方](docs/manual.md) · [仕組みと学生版との対応](docs/design.md) · [学生コードからの来歴](docs/provenance.md)

## まずは触ってみる

最初は無音のデモが流れます。画面をなぞると指先に光が生まれます。速く動かすほど光が強くなり、複数の指でも描けます。

配色が「音の色」のときは上側に暖色の鋭い光、下側に寒色の丸い光が生まれます。他の配色では同じ動きを別の色合いで楽しめます。

| 場面 | 楽しみ方 |
| --- | --- |
| 光の庭 | 花のような光と粒子を重ねる |
| 水の記憶 | 波紋と漂う灯を描く |
| オーロラ | 幾重の光の幕とゆらぎを眺める |

「光のレシピ」では6つの組み合わせから始められます。気に入ったレシピを選び、密度や動き、余韻を少しずつ変えてみてください。

## 光景を楽しむ・残す・共有する

| 操作 | できること |
| --- | --- |
| 鑑賞モード | 操作表示を隠して光の空間に集中する |
| 全画面 | 対応するブラウザーで画面いっぱいに表示する |
| 画像を保存 | その瞬間のキャンバスをPNGで保存する |
| 動画を保存 | 光の映像を音声なしで最大12秒保存する |
| この設定を共有 | 同じ場面や配色で開けるリンクを作る |

共有リンクに入るのは表示設定だけです。音源やマイク音声、なぞった軌跡は含みません。同じ設定で新しい光景を作るための機能です。保存した一瞬を見せたい場合はPNGや動画を使ってください。

## 音とつなげる

「音源を開く」でファイルを選び、「音源を再生」を押すと音の変化が光へ伝わります。「マイク」は自分で有効にした場合だけ使います。音声はブラウザー内で解析します。

音の出力は初期状態でOFFです。「音を出す」でなぞる音を有効にできます。音源の再生や実験室の発音でも出力をONにします。その後は「音を止める」で出力だけを止められます。音源の分析は続きます。マイク入力を直接スピーカーへ返すことはありません。

光のレシピを選んでも音の入力と出力は切り替わりません。動画保存にも音声は入りません。

音量の表示は端末や録音によって変わる相対値です。音高は周期のある信号から基本周波数を推定します。無音や不明瞭な音は未検出として扱います。

## 音と色の実験室

学生版の「同じ音を色・形・数値で表す」実験も残しています。音の高さと大きさを変え、4条件や反転を比べられます。色は青から赤へ変わり、形は丸から星へ近づきます。

これは作品のために決めた対応です。感じ方には個人差があります。対応を変えると印象がどう変わるか試してみてください。

## コードを読んで発展させる

| ファイル | 担当する処理 | 変更する例 |
| --- | --- | --- |
| `core.js` | 色・形への対応と音の解析 | 色の範囲や音を検出する条件 |
| `renderer.js` | 粒子・波紋・光の幕 | 光の寿命や流れ方 |
| `audio.js` | 音源・マイクと再生の接続 | 音の長さや入力の切り替え |
| `looks.js` | 光のレシピと共有設定 | 配色の組み合わせや設定範囲 |
| `recorder.js` | キャンバスの動画保存 | 保存する秒数や描画頻度 |
| `app.js` | 操作画面と各処理の接続 | 操作や設定の組み合わせ |
| `lumen_lab.ipynb` | 公開用のPython教材 | 音を色・形・数値へ変える式 |

まずは`lumen_lab.ipynb`の入力値を変えてみてください。リストに座標を並べ、繰り返しで輪郭を作り、条件分岐で丸と星を選びます。Pythonの基礎をアートへつなげる教材です。

学生の提出原版は学内向けのBoxで配布します。公開するNotebookは学生の数式を基に作成した発展教材です。元コードとの対応や修正点は[設計資料](docs/design.md)と[来歴](docs/provenance.md)に記録しています。

## ローカルで動かす

ZIPを展開すると`v1.1.0`フォルダーができます。その中で次のコマンドを実行します。

```sh
python3 -m http.server 8000
```

ブラウザーで`http://localhost:8000/`を開いてください。追加のJavaScriptライブラリやAPIキーは不要です。マイクはHTTPSの公開ページかlocalhostで利用できます。

Node.jsで検査する場合は次のコマンドを使います。

```sh
node --test tests/*.test.mjs
```
