# LUMENの使い方

対応版：v1.0.0

## 光の中を歩くように

ページを開くと無音のデモが始まります。まずはそのまま眺めてみてください。画面をなぞると、デモの光に自分の光を重ねられます。クリックやタッチでも光が生まれます。

画面の上では暖色の鋭い光、下では寒色の丸い光が中心になります。ゆっくり動かすと穏やかな光、素早く動かすと強い光になります。タッチ画面では複数の指を使い、別々の場所へ同時に描けます。

設定の「自動で描く」をOFFにすると自分の操作を主役にできます。「光をリセット」では描いた光を消し、自動描画も止めます。デモへ戻るときは「デモ」を選ぶか、入力がデモの状態で「自動で描く」をONにします。

## 場面と光を選ぶ

| 設定 | 変わること |
| --- | --- |
| 光の庭 | 粒子と花のような光が流れる場面 |
| 水の記憶 | 波紋と小さな灯が漂う場面 |
| オーロラ | 光の幕が重なる場面 |
| 配色 | 音に対応した色、青と翡翠、夕映えから選択 |
| 光の密度 | 生まれる光の量 |
| 動き | 流れやゆらぎの強さ |
| 余韻 | 光の軌跡が残る長さ |
| 画質 | 滑らかさと描画の負担のバランス |

同じ操作でも場面を変えると印象が変わります。最初は密度と動きを控えめにして、余韻を少し長くすると変化を追いやすくなります。「動き」を0にすると背景の時間による変化が止まりますが、音や手の操作には反応します。

時間の進行を止めて眺めたい場合は「一時停止」を使います。音源は一時停止し、マイク入力も停止します。「再開」で光を再び動かせます。マイクを使う場合は改めて「マイク」を選び、音源は「音源を再生」で続きから再生します。

## 音源ファイルで動かす

1. 「音源を開く」で端末内の音声ファイルを指定します。
2. 読み込みが終わったら「音源を再生」を押します。この操作で音の出力もONになります。
3. 光の変化を見ながら場面や配色を変更します。
4. 「音源を一時停止」で再生を止めます。「デモ」へ切り替えると音源の入力を終了します。

対応する音声形式はブラウザーによって異なります。一般的なWAVやMP3でも、ファイルの形式や圧縮方式によっては読み込めないことがあります。その場合は別の形式に変換して試してください。

読み込める音源は60MiB以下、長さは20分以内です。大きな音源は事前に必要な部分を切り出すと扱いやすくなります。

選んだ音源はブラウザー内で処理します。アプリから外部へアップロードしません。ページを閉じると音源の選択状態は失われます。

再生後に「音を止める」を押すと出力だけをOFFにできます。音の分析は続けられるため、画面だけを使った展示にも向いています。再び聴きたい場合は「音を出す」を選びます。

## 声や周囲の音で動かす

「マイク」を選ぶとブラウザーが利用許可を求めます。許可した場合だけ入力を始めます。「マイクを停止」では入力トラックも停止します。許可を待っている間に「デモ」を選ぶと、アプリ側の待機を取り消せます。マイクの音をスピーカーへ直接返さないため、声を使って描く場合も音を重ねずに楽しめます。

音の高さは周期のある信号から推定します。長く伸ばした声や単音の楽器は変化を追いやすく、息の音、打楽器、複数の音が混ざる音源では安定した高さを検出できないことがあります。その場合は「未検出」として扱います。検出できない状態を0Hzの声と解釈しません。

音の大きさは相対値です。マイクの感度、端末の自動調整、録音の音量によって変わります。同じ声でも別の端末で同じ値になるとは限りません。

マイクが使えない場合は、HTTPSまたはlocalhostで開いているか、ブラウザーとOSの許可を確認してください。許可を取り消したい場合は、ブラウザーのサイト設定を使います。

## 音と色を比べる

「音と色の実験室」では学生版の計算を試せます。音の高さは130〜1000Hz、音の大きさは10〜100%の範囲です。この音量設定は合成音の振幅を操作するための値で、マイクの実測音圧ではありません。

| パターン | 音の高さ | 音の大きさ |
| --- | ---: | ---: |
| 大音・高音 | 880Hz | 95% |
| 大音・低音 | 165Hz | 95% |
| 小音・高音 | 880Hz | 20% |
| 小音・低音 | 165Hz | 20% |

音を変えると色、固定外径の形、1〜100の数値が変わります。「4条件を比較」では音の高さだけを変えた場合と大きさだけを変えた場合を比べられます。「反転する」では同じ入力でも結果の印象が変わります。「音を鳴らす」は出力をONにして、現在の設定で短い合成音を再生します。

色と形を同時に変えると印象の原因を切り分けにくくなります。何が効いているか調べるときは、一度に動かす設定を一つにして比較してください。気に入った対応を見つけたら、`core.js`の数式を自分で変更する題材にもできます。

計算は`math`、`colorsys`、リストなどPythonの標準機能を使います。初心者は変数の値を変えるところから始め、条件分岐で丸と星を選ぶ部分や、繰り返しで点を並べる部分へ進めます。これは公開用に作成した発展版の教材です。学生の提出原版は学内向けのBoxで別に配布します。

## 全画面と画像の保存

全画面では光の風景を大きく表示できます。終了するにはブラウザーの全画面終了操作を使います。全画面APIを使えない環境でも通常の表示で操作できます。

PNG保存では、その時点のキャンバスを画像としてダウンロードします。操作画面や音声は画像に含みません。保存先やファイル名の確認方法はブラウザーの設定に従います。保存した画像に元の音源データを埋め込むことはありません。

## 別のページへ移ったとき

タブを切り替えるなどしてページが表示されなくなると、光の時間変化と音の入力を停止します。再生中の音源は一時停止し、読み込み済みの音源は保持します。マイクは停止し、マイク許可や音源の読み込みを待っている処理も取り消します。

ページへ戻った後は「再開」を押します。音源は「音源を再生」で続きから再生でき、マイクは改めて開始します。ページを閉じたり再読み込みしたりした場合は音源の選択も失われます。

## 表示が重いとき

光の密度と動きを下げると描画の負担を減らせます。高解像度の画面では端末の性能によって滑らかさが変わります。描画では解像度と粒子数に上限を設け、長く操作しても光が際限なく増えないようにしています。

長時間眺める場合は、音量と画面の明るさを自分が心地よい範囲へ調整してください。動きを減らす端末設定を使っている場合は、その設定に配慮した表示から始めます。
