# LUMENの使い方

対応版：v1.1.1

## 光を描く

ページを開くと無音のデモが始まります。そのまま眺めるほか、画面をなぞって光を重ねられます。クリックやタッチでも光が生まれます。複数の指で別々の場所へ描くこともできます。

速くなぞるほど光が強くなります。「音の色」の配色では上側に暖色の鋭い光、下側に寒色の丸い光が生まれます。「青と翡翠」や「夕映え」では色合いが変わります。

自分の操作だけで描きたいときは「自動で描く」をOFFにします。「光をリセット」は描いた粒子や残像を消し、自動描画も止めます。場面の背景は残ります。「デモ」を選ぶと自動で描く状態へ戻れます。

## 光のレシピから始める

「光のレシピ」は場面と光の設定を組み合わせた出発点です。

| レシピ | 選ぶ光景 |
| --- | --- |
| 翡翠の庭 | 翡翠色の庭 |
| 花あかり | 柔らかな色の庭 |
| 月の水面 | 月明かりのような水面 |
| 青い余白 | 青い光と波紋 |
| 光のヴェール | 穏やかなオーロラ |
| 夕暮れの幕 | 夕映え色のオーロラ |

レシピを選ぶと場面や配色、密度、動き、余韻が切り替わります。音源とマイクの選択や音の出力はそのままです。選んだ後に一つずつ調整すると好みの組み合わせを探しやすくなります。

## 場面と光を調整する

| 設定 | 変わること |
| --- | --- |
| 光の庭 | 花のような光と粒子が流れる |
| 水の記憶 | 波紋と小さな灯が漂う |
| オーロラ | 光の幕が重なる |
| 配色 | 光に使う色合い |
| 光の密度 | 生まれる光の量 |
| 動き | 流れやゆらぎの強さ |
| 余韻 | 軌跡が残る長さ |
| 画質 | 滑らかさと描画の負担 |

最初は密度と動きを控えめにし、余韻を少し長くすると変化を追いやすくなります。「動き」を0にすると背景の時間変化が止まります。音や手の操作には反応します。

時間の進行を止める操作は「一時停止」です。音源も一時停止し、マイク入力は終了します。「再開」で光を動かせます。音源は「音源を再生」で続きから再生できます。マイクを使う場合は改めて開始してください。

## 光に集中する

「鑑賞モード」はキャンバス内の操作表示を隠します。「操作に戻る」かEscキーで通常表示へ戻れます。

「全画面」はブラウザーの表示領域を広げる操作です。対応する環境では鑑賞モードと組み合わせられます。全画面を終了するにはブラウザーの終了操作を使います。全画面APIを使えない環境でも通常表示で楽しめます。

## 音源ファイルで動かす

1. 「音源を開く」で端末内の音声ファイルを指定します。
2. 読み込み後に「音源を再生」を押します。音の出力もONになります。
3. 光の変化を見ながら場面や配色を調整します。
4. 「音源を一時停止」で再生を止めます。「デモ」へ切り替えると音源の入力を終了します。

読み込める音源は60MiB以下で20分以内です。対応形式はブラウザーによって異なります。WAVやMP3でも圧縮方式によって読み込めない場合があります。その場合は別の形式で試してください。

再生後に「音を止める」を押すと出力だけをOFFにできます。分析は続くため、光だけを使った展示にも向いています。再び聴くときは「音を出す」を選びます。

音源はブラウザー内で処理します。ページを閉じると選択状態は失われます。

## 声や周囲の音で動かす

「マイク」を選ぶとブラウザーが利用許可を求めます。許可した場合だけ入力を始めます。「マイクを停止」で入力トラックも停止します。許可待ちの間に「デモ」を選ぶとアプリ側の待機を取り消せます。

マイクの音は直接スピーカーへ返しません。声を使って描く場合も入力音を重ねずに楽しめます。

音高は周期のある信号から推定します。長く伸ばした声や単音の楽器は変化を追いやすい音です。息や打楽器、複数の音が混ざる音源では高さを検出しにくくなります。不明瞭な信号は未検出として扱います。

音の大きさは相対値です。マイクの感度や録音の音量によって変わります。騒音計のdB値を測る機能ではありません。

マイクを使えない場合はHTTPSまたはlocalhostで開いているか確認してください。ブラウザーとOSの許可も確認できます。利用許可を取り消す場合はブラウザーのサイト設定を使います。

## 設定を共有する

「この設定を共有」で同じ表示設定を開けるリンクを作ります。リンクをコピーして相手へ渡してください。自動でコピーできない場合は表示された「共有リンク」を選んでコピーできます。

リンクには場面と配色、密度、動き、余韻などの表示設定が入ります。音源ファイルやマイク音声、操作履歴は入りません。相手のブラウザーで新しく描画するため、共有元と画素が一致する機能ではありません。

気に入った一瞬そのものを残す場合は画像や動画として保存します。

## 画像と動画を保存する

「画像を保存」はその瞬間のキャンバスをPNGで保存します。操作パネルや音声は入りません。

「動画を保存」はキャンバスだけを最大12秒収録します。録画中は同じボタンで途中停止できます。音声は入りません。ブラウザーが対応する形式に応じてWebMまたはMP4で保存します。

動画保存を使えない環境ではPNG保存を利用してください。保存先とファイル名の確認方法はブラウザーの設定に従います。

## 音と色を比べる

「音と色の実験室」では学生版の計算を試せます。音の高さは130〜1000Hz、音の大きさは10〜100%の範囲です。この%は合成音の振幅を操作する値です。マイクの実測音圧を表すものではありません。

| パターン | 音の高さ | 音の大きさ |
| --- | ---: | ---: |
| 高い・大きい | 880Hz | 95% |
| 低い・大きい | 165Hz | 95% |
| 高い・小さい | 880Hz | 20% |
| 低い・小さい | 165Hz | 20% |

音を変えると色と輪郭、1〜100の数値が変わります。「4条件を比較」で音の高さだけを変えた場合と大きさだけを変えた場合を比べられます。「反転する」は同じ入力から異なる印象を作る操作です。「音を鳴らす」は出力をONにし、現在の設定で短い合成音を再生します。

印象の違いを調べるときは一度に動かす設定を一つにすると比較しやすくなります。気に入った対応を見つけたら`core.js`の数式も変更してみてください。

## 別のページへ移ったとき

タブを切り替えるなどしてページが表示されなくなると光の時間変化を止めます。再生中の音源は一時停止し、読み込み済みの音源は保持します。マイク入力と許可待ち、音源の読み込み待ちは取り消します。動画の収録も停止します。

ページへ戻った後は「再開」を押します。音源は「音源を再生」で続きから再生できます。マイクは改めて開始してください。ページを閉じたり再読み込みしたりすると音源の選択は失われます。

## 表示が重いとき

「画質」を軽量に切り替え、光の密度と動きを下げると描画の負担を減らせます。高解像度の画面では端末の性能によって滑らかさが変わります。

描画には解像度と粒子数の上限を設けています。動きを減らす端末設定では静止表示から始めます。
