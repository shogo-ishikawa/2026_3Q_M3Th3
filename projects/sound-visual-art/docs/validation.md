# LUMEN v1.0.0の確認記録

確認日：2026年11月13日

## 自動検証

JavaScript 96件、公開Python教材と配布物5件、共通Pages処理5件の計106件が成功しました。

- 学生の元Python関数から独立に作った46条件の真値と、Web版の色・輪郭・数値・形の代表座標が一致しました。元コードの不足する`math`は検証時の名前空間にだけ与えています。
- 別途、音高130〜1000Hzを5Hz刻み、音量10〜100%を1%刻み、順逆両方の31,850条件で色・角の数・数値を照合し、差がないことを確認しました。
- YIN法は80〜1200Hz、複数サンプルレート、倍音を含む単音、無音、直流、雑音、短い波形、不正値で確認しました。FFTの周波数重心と基本周波数を別に扱います。
- 3シーンの描画、時間刻み、粒子・波紋・ポインターの上限、サイズ変更、低負荷設定、Canvas非対応を検査しました。
- 実際のアプリのイベント処理を通し、音源の再生・ミュート・一時停止、マイクの停止と遅い許可の競合、ページ非表示時の資源解放、描画ループが一本であることを検査しました。マイクとCanvasのAPIにはテストダブルを使っています。
- デモがOFFでも音声入力で新しい粒子が生まれ、無音では補充しないことを確認しました。音高を決められない雑音では、周波数重心による色を使い、音高を検出済みとは扱いません。
- 公開Notebookを空の名前空間から上のセル順に実行し、HTML表示と音生成まで確認しました。計算は46条件の元Python真値とも照合し、WAVの形式・長さも確認しています。
- ZIPの単一バージョンフォルダー、再現可能な梱包、ローカルモジュールの参照先、Notebookの空の出力・実行番号、不要なメタデータの不在を検査しました。

## Chromeでの操作

- ギャラリーの「アート」でLUMENだけに絞り込み、作品を開けました。
- 光の庭・水の記憶・オーロラの切り替え、配色と軽量設定、一時停止と再開を操作しました。
- マウスでなぞると光が生まれ、案内が消えることを確認しました。全画面表示と終了も操作しました。
- 自作の440Hz・30秒のWAVを読み込み、画面の推定値が440Hzになることを確認しました。途中停止と再開、音の出力を止めた後も440Hzの分析が継続すること、デモへ戻れることを確認しました。
- 4条件の比較と順逆の切り替えを操作し、低い・小さい音で色`#3d4860`、数値8が表示されることを確認しました。
- PNGを書き出し、1250×597pxの画像を開けました。キャンバスには22,759色が含まれ、空の画像でないことを確認しました。
- 770px・337px相当の幅で確認しました。337pxで見つかった比較カードの横あふれを修正し、設定と比較欄を開いた状態でも横あふれがないこと、場面と軽量設定を選べることを確認しました。

## 確認範囲

実マイクでの収音、スマートフォン実機の複数指操作、全ブラウザーでの全画面API、Google Colabの実画面での再実行は未確認です。ブラウザーの幅を変えた表示確認と実機確認は区別しています。音高推定は単音向けで、和音や雑音から常に正しい音高を得る保証はありません。
