確認日：2026年11月13日

このブラウザ版は、授業で提出された「音と視覚のつながりとデジタルアート」を基にした公開用の発展版です。学生の元の提出版と、教員側で機能を追加した公開版を区別しています。学生の氏名、学籍番号、学科などは掲載しません。

## 元の作品と公開版

学生の提出原版は、大学のアカウントで閲覧するBoxの学内配布資料として扱います。ファイル名や出力を整理した学生配布版であっても、提出NotebookをそのままGitHubの公開リポジトリやダウンロード用ZIPへ含めません。

移植前の照合では、整理済み学生配布版の2つのコードセルの`source`が原提出物と完全一致することを確認しました。整理で変更したのはファイル名、実行出力、実行番号、Colabの出力情報、ウィジェット状態、セル識別子などです。この確認に使ったハッシュと、元の計算から生成した真値を来歴の記録として残しています。

公開するPython資料は、計算の仕組みを説明するために作成した[発展教材 `lumen_lab.ipynb`](../lumen_lab.ipynb)です。学生が提出したNotebookそのものではありません。ブラウザ版の描画や音の処理は移植したJavaScriptを使い、原Notebookを依存ファイルとして読み込みません。

原本のZIPや発表PDFも同梱しません。原本のファイル名と発表資料には個人情報があることを確認しています。学生提出原版と、教員が公開用に作成したアプリ・教材を区別して管理します。

## 比較実験の計算

`p = clamp((周波数 − 130) / 870, 0, 1)`、`v = clamp((音量 − 10) / 90, 0, 1)`とします。逆方向では、それぞれ`1 − p`、`1 − v`へ変えます。音量の%はアプリ内の操作値で、実際の音圧レベルを表すものではありません。

| 表現 | 元の対応 |
| --- | --- |
| 色相 | `(0.64 − 0.62 × p) mod 1` |
| 彩度 | `0.28 + 0.72 × v` |
| 明るさ | `0.30 + 0.70 × v` |
| 角・波の数 | `round(4 + 12 × v)` |
| 形の外径 | 半径0.68に固定 |
| 丸と星の切り替え | `p < 0.35`なら波打つ丸、それ以外は星 |
| 星の内径 | `0.68 × (1 − 0.60 × p)` |
| 数値 | `round(1 + 99 × (p + v) / 2)` |

丸形は0〜2πを両端込みの200点で分け、半径を`0.68 − a/2 + (a/2)cos(nθ)`とします。ここで`a = 0.68 × (0.04 + 0.25p)`、`n`は波の数です。星形は外径と内径を交互に使い、上向きの頂点から始めます。

4つのプリセットは、880Hz・95%、165Hz・95%、880Hz・20%、165Hz・20%です。形の外径を一定にしているのは、音量に合わせて形全体まで大きくすると、形の違いと大きさの違いを分けて比べにくくなるためです。

この対応は作品の表現として決めたルールです。人の聴覚と色や形の対応が、誰にとっても同じだと示すものではありません。逆方向の比較も、その対応の違いを試す操作です。

## 移植時に修正した点

### Pythonの`math`の参照

元のセル0では、星形の角度を求める際に`math.pi`を使っていますが、`import math`がありません。新しいPythonの名前空間で関数を呼ぶと、丸形側は計算でき、星形側は`NameError`になります。学内で管理する提出コードを改変せず、Web版ではJavaScriptの`Math.PI`を使います。公開用Python教材でも必要なimportを記載します。

比較用の真値を作る際は、元関数をPythonの`ast`で抽出し、テストの名前空間へ`np`、`colorsys`と不足している`math`を与えました。元Notebookの内容を書き換えたのではなく、計算を評価するためのテスト側の補助です。描画UIの起動やマイク取得は実行していません。

### 丸め方

Pythonの`round()`は中間値を偶数へ丸めます。JavaScriptの`Math.round()`へそのまま置き換えると一部の条件で結果が変わるため、公開版の比較計算でも偶数への丸めを使います。例えば565Hz・55%の数値は50.5から50へ、130Hz・13.75%の角数は4.5から4へ丸めます。

### 音の高さの分析

元のセル1は、`fftSize = 512`の周波数スペクトルから最大のbinを探して色へ対応させます。これは最も強い周波数帯の指標で、声の基本周波数を推定する方法ではありません。倍音や環境音の影響も受けます。

公開版ではYIN法で繰り返しの周期を推定し、周期性が十分な音の高さを探します。推定が不確かな場合もあり、音楽の和音や雑音を含む音から、常に正しい音高を取り出せるものではありません。分析が成立しない状態を、無理に有効な音高として扱わない構成にしています。

また、粒子数や音の同時発生に上限を設けること、経過時間に合わせて描画を更新すること、マイクと出力音を停止できることなどを、ブラウザで継続して操作するための改善として加えています。元のNotebookに残された操作画面とは、機能や見た目が異なります。
