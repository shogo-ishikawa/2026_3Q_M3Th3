# 学生提出コードから引き継いだもの

対応版：v1.1.0 ／ 確認日：2026年11月13日

このブラウザー版は授業作品「音と視覚のつながりとデジタルアート」を基にした公開用の発展版です。学生の提出版と教員側で機能を追加した公開版を区別しています。氏名や学籍番号、学科などの個人情報は掲載しません。

## 元の作品と公開版

学生の提出原版は大学のアカウントで閲覧するBoxの学内配布資料です。ファイル名と出力を整理した版も学内向けとして扱います。提出NotebookをそのままGitHubや公開ZIPへ含めません。

移植前に学生配布版の2つのコードセルを原提出物と照合し、`source`が完全一致することを確認しました。整理で変更したものはファイル名や実行履歴、Colabの出力情報、ウィジェット状態、セル識別子などです。照合時のハッシュと元の計算から生成した真値を来歴として残しています。

公開するPython資料は計算の仕組みを説明するために作成した[発展教材 `lumen_lab.ipynb`](../lumen_lab.ipynb)です。学生が提出したNotebookそのものではありません。ブラウザー版は移植したJavaScriptで描画と音の処理を行います。原Notebookを依存ファイルとして読み込みません。

原本のZIPと発表PDFには個人情報があるため公開物へ同梱しません。原提出物と公開用のアプリ・教材を分けて管理します。

発表資料の狙いは音の高さと大きさを分け、色・形・数字が同時に変わる様子を直感的に比べることでした。声やなぞる操作に反応する光のアートも紹介されています。公開版もこの二つを出発点にしています。

## 比較実験の計算

正規化した音高を`p = clamp((周波数 − 130) / 870, 0, 1)`、音量を`v = clamp((音量 − 10) / 90, 0, 1)`とします。逆方向では`1 − p`と`1 − v`へ変えます。音量の%はアプリ内の操作値です。実際の音圧レベルではありません。

| 表現 | 元の対応 |
| --- | --- |
| 色相 | `(0.64 − 0.62 × p) mod 1` |
| 彩度 | `0.28 + 0.72 × v` |
| 明るさ | `0.30 + 0.70 × v` |
| 角・波の数 | `round(4 + 12 × v)` |
| 形の外径 | 半径0.68に固定 |
| 丸と星の切り替え | `p < 0.35`なら波打つ丸、それ以外は星 |
| 星の内径 | `0.68 × (1 − 0.60 × p)` |
| 数値 | `round(1 + 99 × (p + v) / 2)` |

丸形は0〜2πを両端込みの200点で分けます。半径を`0.68 − a/2 + (a/2)cos(nθ)`とします。ここで`a = 0.68 × (0.04 + 0.25p)`、`n`は波の数です。星形は上向きの頂点から始めて外径と内径を交互に使います。

4つのプリセットは880Hz・95%、165Hz・95%、880Hz・20%、165Hz・20%です。形の外径を一定にすることで輪郭の違いを比べやすくしています。音量に合わせて形全体まで拡大すると輪郭と大きさの影響が混ざるためです。

この対応は作品の表現として決めたルールです。人の聴覚と色や形の対応が全員同じだと示すものではありません。逆方向の比較も対応の違いを試す操作です。

## 移植時に修正した点

### Pythonの`math`の参照

元のセル0は星形の角度を求める際に`math.pi`を使いますが`import math`がありません。新しいPythonの名前空間で丸形側は計算できる一方、星形側は`NameError`になります。提出コードは学内資料として保持します。Web版は`Math.PI`で計算し、公開Python教材でも必要なimportを記載しています。

比較用の真値は元関数をPythonの`ast`で抽出して作りました。テストの名前空間へ`np`と`colorsys`、不足している`math`を与えています。計算を評価するための補助であり元Notebookの書き換えではありません。描画UIやマイク取得は実行していません。

### 丸め方

Pythonの`round()`は中間値を偶数へ丸めます。JavaScriptの`Math.round()`へそのまま置き換えると一部の結果が変わります。公開版の比較計算も偶数への丸めです。例えば565Hz・55%の数値は50.5から50へ丸めます。130Hz・13.75%の角数は4.5から4になります。

### 音の高さの分析

元のセル1は`fftSize = 512`のスペクトルから最大のbinを探して色へ対応させます。最も強い周波数帯を示す指標です。倍音や環境音の影響を受けるため声の基本周波数とは限りません。

公開版はYIN法で繰り返しの周期を推定します。周期性が十分な音の高さを探す方法です。和音や雑音を含む音の推定には限界があります。分析が成立しない状態を有効な音高として扱わない構成です。

粒子数と同時発音数には上限を設けました。経過時間に合わせた更新や音の停止も加え、ブラウザーで継続して操作しやすくしています。元Notebookとは機能と見た目が異なります。

v1.1.0では光のレシピと表示設定の共有、鑑賞モード、音声なしの動画保存を追加しています。これらは公開版で発展させた機能です。学生版の比較計算とは別のモジュールで扱います。
