# LUMENの仕組みと学生作品との対応

対応版：v1.1.1

## 発想を引き継ぐ

学生の提出Notebookは2つのコードセルから成ります。前半は音の高さと大きさを色・形・数値へ対応させる比較実験です。後半は声やマウス操作に反応するCanvasアートです。LUMENはこの二つを軸に、ブラウザーで直接操作できる体験へ発展させています。

| 学生版の処理 | 引き継ぐ点 | 発展させた点 |
| --- | --- | --- |
| `compute_all_three_targets()` | 音高と音量の正規化、HSVの色、丸と星、1〜100の値 | JavaScriptへ移植して独立した関数に分離 |
| 4つの音の比較 | 880/165Hzと95/20%の組み合わせと反転 | ブラウザーの実験室で操作 |
| `generate_sound_wave()` | 基本波と倍音を組み合わせる発想 | 公開Python教材で波形を生成 |
| `Particle`と`addParticles()` | 上下位置で色と形を変え、速さで光を強める | 複数の指と3場面、描画量の上限に対応 |
| マイクによるオーロラ | 音の変化を色や光へ伝える発想 | 音高推定と開始・停止を改善 |

学生の氏名や学籍番号は公開用の画面とサンプルに使いません。提出原版は学内向けのBoxで配布します。公開する`lumen_lab.ipynb`は学生の対応式をPythonの標準機能で書き直した発展教材です。原提出物と公開版の区別は[来歴](provenance.md)に記録しています。

## 音から色・形・数値へ

実験室は元コードと同じ130〜1000Hzと10〜100%を使います。0〜1へ正規化した音高を`p`、音量を`v`とします。反転時はそれぞれ`1-p`と`1-v`へ置き換えます。

| 対象 | 対応 |
| --- | --- |
| 色相 | `0.64 - 0.62 * p`。青系から赤系へ変化 |
| 彩度 | `0.28 + 0.72 * v` |
| 明るさ | `0.30 + 0.70 * v` |
| 形の波・頂点数 | `4 + 12 * v`を整数へ丸める |
| 星の鋭さ | `0.60 * p` |
| 数値 | `1 + 99 * (p + v) / 2`を整数へ丸める |

輪郭の外側は半径0.68で固定します。`p < 0.35`なら200点の波打つ丸形です。それ以外は外側と内側の点を交互に並べた星形になります。

JavaScriptとPythonは中間値の丸め方が異なります。元のPythonの`round()`に合わせ、比較計算でも中間値を偶数側へ丸めます。HSVから16進色への変換にも元コードの切り捨てを使います。

学生版の前半セルは`math.pi`を使いますが`import math`がなく、星形の経路で実行エラーになります。Web版は`Math.PI`で計算します。公開Python教材でも必要なモジュールを読み込みます。提出原版は学内資料としてそのまま保持します。

色と音の対応は作品のために決めた設計です。感じ方には個人差があります。4条件と反転を比べることで対応の違いを試せます。

## 音を解析する

`audio.js`は音源やマイクをWeb Audio APIへ接続します。解析用データを受け取る`core.js`は時間波形から音の大きさを求めます。周期のある信号についてはYIN法で基本周波数を推定します。信号を少しずつずらしたときの違いから周期を探す方法です。

スペクトルの重心は周波数ごとの強さから求める別の特徴量です。

| 特徴量 | 意味 |
| --- | --- |
| `rms` | 波形の二乗平均平方根。振幅の目安 |
| `level` | 作品の反応に使う0〜1の相対的な大きさ |
| `pitchHz` | 周期から推定した基本周波数。未検出時は`null` |
| `confidence` | 周期を持つ信号としての確かさ |
| `centroidHz` | スペクトルの重心。音の明るさに関わる特徴の一つ |

学生版の後半セルはFFTで最も強い周波数ビンを選んで色へ対応させます。倍音が強い場合や複数音の入力では、最大ビンが基本周波数と一致するとは限りません。

公開版は基本周波数の推定とスペクトルの特徴を分けています。無音や信頼度の低い信号を0Hzの声として扱いません。音高が検出されない場合も音の大きさや周波数重心で表現を変えます。

音量は端末や入力振幅に依存する相対値です。校正した音圧レベルではありません。複数の声や楽器から全ての音高を同時に分離する機能もありません。

## 光を描く

座標はCSSピクセル単位で扱います。表示先の解像度に合わせてキャンバスを調整し、倍率と粒子数に上限を設けます。フレーム間の時間差も制限することで大きな位置飛びを抑えています。

なぞる位置に応じた色と形、速さに応じた光量を学生版から引き継いでいます。「音の色」の配色は上側が暖色、下側が寒色です。他の配色はその色相を別の範囲へ変換します。

| 場面 | 中心となる表現 |
| --- | --- |
| 光の庭 | 粒子と花のような輪郭 |
| 水の記憶 | 波紋と漂う灯 |
| オーロラ | 幾重の光の幕 |

デモは規則的な仮想入力から描画します。マイクの測定値ではありません。音源がなくても作品を楽しめます。実際の音声入力にも粒子の発生経路を設け、デモを止めた状態でも音に反応させます。

光は生成後に減衰し、寿命を終えるとリストから取り除きます。複数の指を別々に追跡し、離した指を追跡対象から外します。

「動き」が0のときは背景の時間変化が止まります。音や手の操作には反応します。「一時停止」は時間の進行を止める操作です。端末の動きを減らす設定では静止表示から始めます。

## 表示設定を持ち運ぶ

`looks.js`は光のレシピと表示設定を扱います。6つのレシピが場面や配色、密度、動き、余韻をまとめます。音源・マイク・出力音の設定はレシピに含めません。

共有URLに入れるのは公開可能な表示設定だけです。許可するキーと値の範囲を決め、数値と種類を検査します。入力音声やファイル名、操作履歴は含めません。既存のURLにクエリーがある場合も共有URLへ引き継ぎません。

相手のブラウザーは設定を読み込んで新しく描画します。画像の画素や特定の一瞬を再現する方式ではありません。その瞬間を残すPNGと動画は別の保存方法です。

## 動画と鑑賞モード

`recorder.js`は自分のキャンバスから映像トラックを作ります。音声トラックは追加しません。対応するMediaRecorder形式を選び、12秒の動画として保存します。表示側から途中停止もできます。

録画の終了時はトラックとタイマーを解放します。連続操作やエラー時にも同じ後始末を行い、二重保存や収録の続行を防ぎます。対応APIがない環境ではPNG保存を利用できます。

鑑賞モードはキャンバス内の操作表示を隠す機能です。画面の大きさは変更しません。全画面APIとは分けて扱い、どちらも利用できる環境では組み合わせられます。

## 画面と処理を分ける

| ファイル | 担当する処理 |
| --- | --- |
| `core.js` | 数値変換、基本周波数とスペクトルの解析、デモ信号 |
| `audio.js` | 音の入出力、音源の読み込み、再生ノードの後始末 |
| `renderer.js` | キャンバスへの描画と光の状態 |
| `looks.js` | 光のレシピと表示設定の検査、共有URL |
| `recorder.js` | キャンバスの映像収録と資源の解放 |
| `app.js` | 操作画面、入力、描画ループ、各処理の接続 |
| `lumen_lab.ipynb` | 色・形・数値の対応式を学ぶPython教材 |

マイクは利用者の操作とブラウザーの許可を経て始めます。スピーカーへ直接接続せず、停止時は入力トラックを止めます。入力の切り替えでは古い非同期処理の結果が新しい状態を上書きしないようにします。

音の出力は初期状態でOFFです。音源の再生と実験室の発音は利用者の操作を受けて出力をONにします。出力をOFFへ戻しても音源の分析は続けられます。

ページが非表示になると光の進行を止め、音源を一時停止します。読み込み済みの音源は保持します。マイクと許可待ち、音源読み込みの途中状態は取り消します。動画の収録も停止します。

入力音声はブラウザー内で処理します。PNGと動画の保存対象はキャンバスだけです。公開用ZIPに利用者の音源や収録結果を含める処理はありません。

## 授業で変更しやすい箇所

まずは`core.js`の正規化と対応式を変えてみてください。変数は調整値、配列は点やレシピの並び、条件分岐は丸と星の切り替え、繰り返しは輪郭を作る点の生成に対応します。

Pythonでは`lumen_lab.ipynb`の入力と返り値から確認できます。`math`と`colorsys`で色や座標を計算し、リストに点を並べてSVGへ表示します。標準の`wave`では0.6秒の合成音を作ります。

例えば音高だけを変えてRGB値を並べる、別の方法で輪郭を描く、反転前後の数値を比べるといった課題へ分けられます。入力・計算・表示を別々の関数にすると変更したコードと作品の変化を結び付けやすくなります。
