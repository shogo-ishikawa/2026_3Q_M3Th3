# AI作曲アレンジ 操作マニュアル

この教材では、音源を用意し、その特徴を分析して伴奏やドラムを重ねます。最初はデモ音源で操作を確かめ、その後に手元の音源やYouTubeの音源で試すと進めやすいと思います。

## 1. Colabを開く

**[AI作曲アレンジをGoogle Colabで開く](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/ai-music-arranger/ai_music_arranger.ipynb)**

PCのブラウザで上のリンクを開き、Googleアカウントでログインします。Colabは、ブラウザからPythonを実行するためのサービスです。PCへPythonをインストールする必要はありません。

自分でコードを変更したり、操作内容を保存したりする場合は、「ファイル → ドライブにコピーを保存」を選んでください。コピーは自分のGoogleドライブに保存されます。

通常のCPUランタイムで利用できます。GPUを使う設定へ変更する必要はありません。画面右上に「接続」が表示されていたら、クリックして実行環境へ接続します。

## 2. Notebookを上から実行する

Notebookは、説明文とコードセルが縦に並んだものです。最初は「ランタイム → すべてのセルを実行」で、必要なセルを順番に実行できます。

個別に進める場合は、コードセル左側の再生ボタン「▶」を押します。実行中はボタンの表示が変わるので、処理が終わってから次へ進んでください。「2. プログラムを読み込む」には、音源の入力・音の計算・画面を担当する3つのコードセルがあります。この3つも、上からすべて実行します。

| 実行するセル | 行うこと | 終わったら |
| --- | --- | --- |
| 1. 環境を準備する | 音声分析、MIDI、操作パネル、YouTube取得に必要なライブラリを準備 | 完了表示を確認して次へ進む |
| 2. プログラムを読み込む | 3つのコードセルで、音源取得・音の計算・操作パネルのプログラムを読み込み | 3つすべてを実行し、エラーが出ていないことを確認 |
| 3. 操作画面を開く | ボタンやスライダーを表示 | 以下の操作をパネル内で行う |

最初の準備には時間がかかることがあります。途中で再生ボタンを何度も押さず、表示が落ち着くまで待ってください。YouTube取得に必要なFFmpegやJavaScript実行環境についても、準備セルで確認・準備します。JavaScript実行環境の準備に失敗した場合でも、デモ音源や手元の音声ファイルで操作を続けられます。

一度パネルが表示されたら、通常の操作でセルを繰り返し実行する必要はありません。「ランタイム → セッションを再起動」を使った場合や、長時間接続が切れていた場合は、1から順番に実行し直します。

## 3. 音源を用意する

処理する音源は、次の3通りから選べます。最初はデモ音源がおすすめです。

### デモ音源

「デモ」タブの「デモ音源を用意」を押します。プログラムが12秒の短いメロディを合成するので、ファイルを持っていなくても動作を試せます。準備が完了したら原曲を再生し、音が聴こえることを確かめてください。デモ音源では、開始位置と長さの入力欄は使いません。

### 手元の音声ファイル

開始位置と長さを指定してから、「PCの音源」タブの「PCの音源を選択」を押します。WAVやMP3などの音声ファイルを選ぶと、読み込みが始まります。読み込みが終わったら、選んだ区間が再生されることを確認します。

大きなファイルをそのまま扱うと、アップロードに時間がかかります。短く切り出した音源を使うと試しやすくなります。アップロードできるファイルの大きさは50MiBまでです。

### YouTube

1. 取得・編集する許可がある動画のURLを用意し、操作パネルの「YouTube」タブを選びます。
2. URL欄へ貼り付けます。
3. 開始位置と長さを指定します。
4. 「YouTubeから取得」を押し、完了表示を待ちます。
5. 原曲を再生して、使いたい区間が読み込まれたことを確認します。

音源を取得する機能はNotebookに含まれています。YouTubeの画面で再生するだけでは、Notebookへ音源は読み込まれません。

| 項目 | 指定する内容 | 例 |
| --- | --- | --- |
| 開始位置 | 動画やファイルの何秒目から使うか | `30`で30秒目から |
| 長さ | 何秒分を読み込むか。3〜60秒 | `20`で20秒分 |

例えば「開始位置30秒、長さ20秒」なら、30秒目から50秒目までを使います。音源の終わりに達した場合、読み込まれる区間は指定より短くなることがあります。開始位置が音源の終わりを超えている場合は、位置を戻して取得し直してください。

YouTubeの動画によっては取得できません。公開状態やネットワーク、YouTube側の制限が原因の場合もあります。取得に失敗しても、音源が自動的にデモへ切り替わることはありません。表示を確認し、別の音源や手元のファイルを選んでください。

開始位置や長さを変えただけでは、読み込んだ音源は変わりません。新しい区間を使いたい場合は、取得・読み込みをもう一度行います。

## 4. 音源を分析する

音源が準備できたら、「音源を解析」を押します。テンポやキーの候補が表示され、アレンジ用の設定へ反映されます。

| 表示・設定 | 意味 |
| --- | --- |
| BPM | 1分間に何拍進むかを表すテンポ。120 BPMなら1拍は0.5秒 |
| キー | 曲の中心に感じられる音の候補。Cはド、Dはレ、Aはラに対応 |
| スケール | 使う音の並び。majorは長調、natural_minorは自然短音階 |
| 伴奏の開始（秒） | 読み込んだ区間の何秒目を、追加する伴奏の最初の拍にするか |

分析結果は候補です。曲によってはBPMが半分・2倍になったり、キーが別の候補になったりします。自動設定された値から一度生成し、耳で聴いて調整してください。

「伴奏の開始（秒）」は、YouTubeの開始位置とは異なります。例えば動画の30秒目から切り出し、切り出した音源の0.3秒目に最初の拍が来る場合、音源の開始位置は30秒、伴奏の開始は0.3秒です。

## 5. アレンジを設定する

最初は自動設定と初期値のまま生成して構いません。操作に慣れたら、一度に変更する項目を一つに絞ると違いが分かりやすくなります。

### 音の並びとリズム

| 設定 | 変わること | 試し方 |
| --- | --- | --- |
| キー | 追加するコード伴奏の基準となる音 | 原曲と調和するか聴き比べる |
| スケール | コード伴奏に使う音の並び | majorとnatural_minorを比較する |
| BPM | 追加する伴奏とドラムの速さ | 拍がずれる場合、推定値の半分・2倍も検討する |
| 伴奏の開始（秒） | 追加する伴奏を鳴らし始める位置 | 原曲の強い拍へ少しずつ合わせる |
| 楽器の音色 | コード伴奏の合成音の響き | 同じ設定のままピアノ系とギター系を比較する |
| ゆらぎの強さ（Humanise） | 音のタイミングや強弱の小さな揺れ | 0から少しずつ増やす |
| 乱数の種（Seed） | 揺れを作るための乱数の初期値 | 同じ値なら同じ条件を再現しやすい |

音色の選択肢は、次の英語表記です。

| 選択肢 | 音色の目安 |
| --- | --- |
| Electric Piano | エレクトリックピアノ |
| Acoustic Grand Piano | グランドピアノ |
| Acoustic Guitar | アコースティックギター |
| Electric Guitar | エレクトリックギター |
| Strings | 弦楽器の合奏 |
| Synth Lead | シンセサイザーの旋律向けの音 |
| Music Box | オルゴール |

**BPMを変更しても原曲の速さは変わりません。** 変わるのは追加する伴奏です。原曲と合わせたい場合は、原曲に近いBPMを使います。異なるBPMをあえて重ねる実験もできますが、原曲全体をテンポ変更する機能ではありません。

拍を合わせても、原曲と同じコード進行になるとは限りません。この教材は、原曲のコードを自動で採譜しているわけではありません。一定のコード進行を基にした伴奏を作ります。

### 重ねる音と音量

| 音の種類 | 内容 |
| --- | --- |
| 原曲 | 読み込んだ音源そのもの |
| コード伴奏 | 複数の音を重ねて作る和音の伴奏 |
| ドラム | バスドラム、スネア、ハイハットのリズム |
| 抽出メロディ | 原曲から推定した音の高さを、簡易音源で鳴らしたもの |

コード伴奏・ドラム・抽出メロディは、それぞれオン・オフできます。音量を0にした音は、WAVのミックスでは聴こえなくなります。

最初は抽出メロディをオフにして、原曲とコード伴奏、ドラムの関係を聴く方法もおすすめです。その後で抽出メロディを加えると、どのような音を拾っていたかを確認できます。

抽出メロディは、声だけを取り出した音声ではありません。音源の中で目立つ音の高さをpYINで推定し、音符に置き換えています。楽器や声が重なる区間では、狙った旋律とは異なる音を拾うことがあります。

## 6. 生成して聴き比べる

「アレンジを生成」を押します。初めてメロディ抽出を使うときは、処理に時間がかかることがあります。完了表示が出てから再生してください。

再生する音は、次の3つを比較します。

1. **原曲**：読み込んだ区間です。
2. **追加パートだけ**：コード伴奏、ドラム、抽出メロディをまとめた音です。
3. **ミックス**：原曲と追加した音を重ねた結果です。

追加した音だけを聴くと、ドラムのパターンや抽出メロディの誤りが確認しやすくなります。ミックスで違和感がある場合は、各パートを一つずつオフにして原因を確かめてください。

音符の図では、横軸が時間、縦軸が音の高さです。青は抽出メロディ、緑はコード伴奏を表します。横に長い線ほど長い音です。ドラムはこの図には表示しません。

音色は、外部の大きな楽器音源をダウンロードせずに鳴らせる簡易音源です。ピアノやギターの録音を再現するものではありませんが、伴奏の違いをすぐに比較できます。

設定を変更した後は、もう一度生成します。アレンジ設定を変更すると、前の結果と保存ボタンが無効になります。音源の取り込みを試みた場合も、古い結果の保存を防ぐため生成結果を無効にします。取り込みに失敗した場合、前の音源は保持されるので、その音源で生成し直すこともできます。

## 7. 結果を保存する

生成が終わったら、保存ボタンからファイルをダウンロードします。Colabの作業用ファイルは、セッションが終了すると消えることがあります。残したい結果は自分のPCへ保存してください。

| 保存ボタン | ファイル | 用途 |
| --- | --- | --- |
| ミックスWAVを保存 | `mixed.wav` | 原曲と追加した音を重ねた結果を、そのまま再生する |
| MIDIを保存 | `arrangement.mid` | 生成・抽出した音符を、MIDI対応ソフトで編集する |
| 結果をZIPで保存 | `arrangement_results.zip` | ミックス・追加パートのWAV、MIDI、設定をまとめて残す |

ZIPには `mixed.wav`、`accompaniment.wav`、`arrangement.mid`、`settings.json`、`README.txt` が入ります。`accompaniment.wav` は、原曲を含まない追加パートだけの音声です。ZIPを展開すると、それぞれのファイルを取り出せます。

MIDIには、原曲の録音そのものは含まれません。音の高さ・長さ・強さなどの情報が入っているため、再生するソフトによって音色が変わります。元の音と同じ響きを残したい場合は、WAVを使ってください。

設定ファイルには、アレンジに使った設定や区間の情報を記録します。YouTubeのURLやアップロード元のファイル名は記録しません。後で同じ音源から再現したい場合は、自分用のメモに取得元を残してください。

ミックスには原曲の音声が含まれます。結果を他の人へ配布する際も、その音源の利用条件に合わせてください。

## 困ったとき

| 状況 | 確認・対処 |
| --- | --- |
| 操作パネルが表示されない | 1〜3のセルを順番に実行します。準備セルでエラーが出ていたら、先にその表示を確認します |
| 接続が切れた／変数がないというエラー | ランタイムが新しくなっている可能性があります。1から実行し直します |
| YouTubeから取得できない | URLと公開状態を確認します。動画による制限がある場合は、手元のファイルかデモ音源で続けます |
| FFmpegやJavaScript実行環境がないと表示される | 環境の準備セルを実行し直し、その結果を確認します |
| YouTube取得だけ急に動かなくなった | 準備セルでyt-dlpを更新した後に、プログラムの読み込みと操作パネルを実行し直します |
| 音が出ない | プレーヤーの再生、PCの音量、ミュート、各パートの音量を確認します。デモ音源でも試します |
| 音源が空／区間が見つからない | 開始位置が音源の長さを超えていないか確認します。開始位置0秒でも試します |
| 処理が長い | 初回の分析には準備時間がかかります。まず10〜20秒程度で試し、不要なら抽出メロディをオフにします |
| テンポが合わない | BPMと拍の開始位置を確認します。BPMは半分・2倍に推定される場合があります |
| 和音が原曲と合わない | キーやスケールを変えて比較します。原曲と同じコード進行を推定する機能ではありません |
| メロディが変／音符が出ない | 単音がはっきり鳴る区間を選びます。無音や複数の楽器が重なる音源では抽出できない場合があります |
| MIDIを開いたら音が違う | 再生ソフトの音源が使われるためです。響きを含めて再生する場合はWAVを使います |
| 保存ボタンが使えない | 音源や設定を変えた場合は、新しい条件でもう一度生成します |

YouTube取得は、yt-dlpの本体と補助パッケージをまとめて更新する構成です。JavaScript実行環境はDeno 2.3以降、またはNode.js 22以降を使用します。通常はNotebookの準備セルで確認できます。環境を独自に変更した場合は、[yt-dlp公式の案内](https://github.com/yt-dlp/yt-dlp/wiki/EJS)も確認してください。

## 授業・グループワークで試す

同じ音源・同じ区間を使い、設定を一つだけ変えて結果を記録しましょう。

| 実験 | 記録すること |
| --- | --- |
| ドラムのオン・オフ | 拍が分かりやすくなったか、原曲とずれていないか |
| majorとnatural_minorの比較 | どの音や和音が変化したか、印象がどう変わったか |
| 原曲の音量を0にする | 追加した音だけで、何が生成されているか |
| Humaniseを0と小さな値で比較 | タイミングや強弱の違いが聴き取れるか |
| 音源の区間を変える | メロディが明瞭な区間と、複数の音が重なる区間で抽出結果がどう変わるか |

「良くなった」「変になった」だけで終わらず、どの設定がどの音へ影響したかを説明できると、次に直したいコードも見つけやすくなります。
