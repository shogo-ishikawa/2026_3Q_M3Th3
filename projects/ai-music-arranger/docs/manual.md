# AI作曲アレンジ 操作マニュアル

まずはデモ曲で音を出し、設定を一つずつ変えてみましょう。慣れたらYouTubeやPCの音源でも試せます。

## 準備する

**[Colabで開く](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/ai-music-arranger/ai_music_arranger.ipynb)**

Googleアカウントでログインし、**1 → 2** の ▶ を順に押します。最初の準備には数分かかることがあります。処理が終わってから次へ進んでください。セル2は1回の実行でプログラムをまとめて読み込みます。CPUのままで使えます。

自分の変更を残す場合は「ファイル → ドライブにコピーを保存」を選びます。以前のコピーは自動更新されないので、最新版を試すときは上のリンクから開き直してください。

## セル3：音源を選ぶ

### YouTubeを使う

1. `input_source` を **「URLがあればYouTube」** のままにします。
2. `youtube_url` に動画URLを貼り付けます。
3. セル3の ▶ を押します。

取得が終わると、使う音源の再生欄と推定BPM・キーが表示されます。まず再生して、選んだ区間が合っているか確かめてください。

| 入力欄 | 指定すること |
| --- | --- |
| `start_seconds` | 何秒目から使うか。初期値は0秒 |
| `duration_seconds` | 何秒分を使うか。3〜60秒、初期値は20秒 |

例えば開始位置30、長さ20なら、30秒目から50秒目までを使います。区間を変えたらセル3を再実行します。

### YouTubeのフリー音源を使う前に

**「無料」「著作権フリー」「No Copyright」と書かれていても、自由に使えるとは限りません。** 動画の説明欄から制作者の公式配布ページを開き、曲ごとの条件を確認しましょう。

| 確認すること | 見るポイント |
| --- | --- |
| 配布元 | 制作者本人や正規の配布サイトか。第三者の転載だけで判断しない |
| 使える範囲 | 編曲、Web公開、商用利用、音声だけの再配布が認められているか。YouTube動画への使用に限られていないか |
| クレジット | 曲名・作者名・配布元などの記載が必要か。指定文があればそれを使う |
| 入手方法 | 公式ダウンロードや作者の配布リンクを優先する。取得方法もYouTubeの利用規約に従う |

曲の利用許可と、YouTubeから自動取得してよいかは別の話です。オーディオライブラリの曲も、曲に表示された利用条件を確認してください。曲名・作者・配布URL・利用条件・確認日を自分のメモに残しておくと、公開するときに確かめられます。この教材の設定ファイルには元のURLを保存しません。

**原曲を重ねたミックスWAVや、それを含む結果のZIPを公開・配布するときは、音声ファイルの配布や編曲が認められているか確認しましょう。** 原曲の音量を0にした場合や、抽出した旋律をMIDI・追加パートWAVで出す場合も、元の曲の条件を確認してください。曲の権利と録音の権利は別なので、録音が入っていないだけで自由に公開できるとは限りません。

クレジットは配布元の指定を優先します。CC BY 4.0の曲では、作者などの表示に加え、ライセンスへのリンクと変更したことの記載が必要です。次の例を、使った曲の条件に合わせて書き換えてください。

```text
音楽：〈曲名〉／〈作者名〉
配布元：〈公式配布ページのURL〉
利用条件：〈ライセンス名とURL〉
変更内容：一部を切り出し、伴奏とドラムを追加
```

公式の案内：[YouTubeオーディオライブラリ](https://support.google.com/youtube/answer/3376882?hl=ja) ／ [YouTube利用規約](https://www.youtube.com/static?template=terms) ／ [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja)

### フリー音源でもYouTubeから取れないとき

フリー音源でも接続確認や音声配信先の制限で取得に失敗することがあります。

YouTubeオーディオライブラリの曲は、公式のMP3を使って続けられます。

1. [YouTube Studio](https://studio.youtube.com/) を開き、左の「オーディオ ライブラリ」を選びます。
2. 曲名やアーティスト名で検索します。例えば `If I Had a Chicken`、`Kevin MacLeod` で探せます。
3. 曲の日付にカーソルを合わせ、「ダウンロード」からMP3を保存します。
4. Notebookのセル3で `input_source` を「PCの音源」にして実行し、保存したMP3を選びます。

読み込んだ後は、同じセル4で解析結果を使ってアレンジできます。[YouTube公式のダウンロード案内](https://support.google.com/youtube/answer/3376882?hl=ja)も参照できます。

### デモ曲を使う

`youtube_url` を空欄にするか、`input_source` を「デモ音源」にします。`demo_song` で曲を選んでセル3を実行してください。次の4曲から選べます。

| `demo_song` の選択肢 | 長さとテンポ |
| --- | --- |
| オリジナル（ポップ） | 12秒・120 BPM |
| オリジナル（ゆったり） | 12秒・80 BPM |
| きらきら星（冒頭） | 9.6秒・100 BPM |
| 歓喜の歌（冒頭） | 16秒・120 BPM |

デモでは曲に合わせたテンポとキーを使います。開始位置と長さの入力欄は使いません。

### PCの音声ファイルを使う

`input_source` を「PCの音源」にしてセル3を実行します。ファイル選択が表示されたら、50 MiB以下のWAVやMP3などを1つ選びます。開始位置と長さはYouTubeと同じように指定できます。

## セル4：アレンジを作る

最初は初期設定のまま ▶ を押してください。生成後は **原曲・追加パート・ミックス** の3つを再生できます。

設定を変えた後は、セル4をもう一度実行します。入力欄を変えただけでは音は変わりません。

### よく使う設定

| 入力欄 | 変わること |
| --- | --- |
| `instrument` | 伴奏の音色。ピアノ系、ギター系、弦楽器など |
| `add_chords` | コード伴奏を加えるか |
| `add_drums` | ドラムを加えるか |
| `add_melody` | 原曲から推定したメロディを音符として加えるか |
| `original_gain` | 原曲の音量。0にすると追加パートだけ聴ける |
| `chord_gain` / `drum_gain` / `melody_gain` | それぞれのパートの音量 |
| `humanise` | 音のタイミングや強弱の揺らぎ。0〜1で指定 |
| `seed` | 揺らぎを作る乱数の種。同じ値で比較できる |

### テンポやキーを手動で変える

自動設定がオンの間は、セル3で調べた値を使います。手動で指定したい項目だけチェックを外します。

| チェックを外す項目 | 変更する入力欄 |
| --- | --- |
| `auto_tempo` | `bpm`：追加する伴奏の速さ |
| `auto_key_scale` | `root`：基準音、`scale`：音の並び |
| `auto_beat` | `beat_offset`：伴奏を鳴らし始める位置（秒） |

長調と短調を比べるなら `auto_key_scale` をオフにします。`root` をCに固定し、`scale` のmajor（長調）とnatural_minor（自然短音階）を切り替えてみてください。

BPMを変えても原曲の速さは変わりません。推定が合わないと感じたら、BPMの半分・2倍や伴奏の開始位置を試してください。

抽出メロディは声だけを分離した音声ではありません。音の高さを推定して鳴らすため、複数の楽器が重なる曲では違う音を拾うこともあります。原曲と聴き比べながら調整しましょう。

## セル5：結果を保存する

`save_format` で形式を選び、▶ を押します。**最後にセル4で生成した結果** が保存されます。

| 選択肢 | 保存するもの |
| --- | --- |
| ZIP一式 | ミックス・追加パートのWAV、MIDI、設定をまとめたファイル |
| ミックスWAV | 原曲と追加パートを重ねた音声 |
| 追加パートWAV | 追加した音だけの音声 |
| MIDI | 音の高さ・長さ・強さなどの演奏情報 |

そのまま聴きたい場合はWAV、音符を対応ソフトで編集したい場合はMIDIを選びます。MIDIには原曲の録音は入りません。セッション終了前に、残したい結果をPCへ保存してください。

公開・配布する場合は、[元の曲の利用条件とクレジット](#youtubeのフリー音源を使う前に)を確認してください。結果のZIPにも短い案内を同梱しています。

## 困ったとき

| 状況 | 次にすること |
| --- | --- |
| URLを入れてもデモが鳴る | `input_source` を「URLがあればYouTube」に戻してセル3を実行 |
| 音源やURLの入力欄が見当たらない | このページ上のリンクから最新版を開き直す。以前のドライブのコピーはそのまま残る |
| フリー音源でもYouTube取得に失敗する | 上の手順で公式配布のMP3を保存し、「PCの音源」から読み込む |
| YouTubeの取得を始めた後に失敗する | 表示された理由を確認。音源ファイルを持っている場合は「PCの音源」から読み込める |
| 開始位置を変えても同じ音が出る | セル3を再実行 |
| 設定を変えても音が変わらない | 自動設定のチェックを確認し、セル4を再実行 |
| 音が出ない | 再生ボタン、PCのミュート、各パートの音量を確認 |
| 処理が長い | まず10〜20秒で試す。`add_melody` をオフにすると音高抽出を省ける |
| 接続が切れた／変数がない | 1から順に実行し直す |

取り込みに失敗した場合も、前の音源は残ります。URLや設定を直してセル3を実行し直せます。
