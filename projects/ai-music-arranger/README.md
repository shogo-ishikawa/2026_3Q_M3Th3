# AI作曲アレンジ

YouTubeやPCの音源からテンポと音の高さを分析し、コード伴奏・ドラム・抽出メロディを重ねるColab教材です。音楽の専門知識がなくても、設定を一つずつ変えながら音の違いを試せます。

2026年度3Q（月3木3クラス）の学生2名による作品をもとに、公開用に整理・改良しました。学生が考えた「音源の取得 → 分析 → 伴奏の生成 → 再生・保存」という流れを受け継いでいます。

**[Google Colabで開く](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/ai-music-arranger/ai_music_arranger.ipynb)** ／ **[操作マニュアル](docs/manual.md)**

## 最初に試す

1. Colabを開き、必要に応じて「ファイル → ドライブにコピーを保存」を選びます。通常のCPUランタイムで使えます。
2. **1 → 2-a → 2-b → 2-c** の左の ▶ を順に押します。
3. **セル3** の `input_source` は「デモ音源」のまま、セル3の ▶ を押します。原曲の再生欄と推定BPM・キーが表示されます。
4. **セル4** の ▶ を押します。原曲・追加パート・ミックスを聴き比べられます。
5. 保存する場合は **セル5** で形式を選び、▶ を押します。

YouTubeを使う場合は、セル3の `input_source` を「YouTube」に変え、`youtube_url` へ動画URLを入力します。開始位置と長さを指定して、セル3を実行してください。

コードは `@title` で折りたたみ、Colab標準フォームの入力欄を表示する構成です。コードを読む場合はセルのメニューから「コードを表示」を選べます。フォームの値を変えた後は、そのセルを実行して反映します。アレンジ設定を変えた後はセル4を再実行してから保存してください。

## できること

| 機能 | 内容 |
| --- | --- |
| 音源の準備 | YouTubeのURL、PCの音声ファイル、プログラムが作るデモ音源から選択 |
| 区間の指定 | YouTube・PC音源の開始位置と長さを秒で指定。長さは3〜60秒、初期値は20秒。デモは12秒固定 |
| 音源の分析 | セル3でテンポとキーの候補を推定。セル4では推定値と手動設定を切り替え可能 |
| メロディの抽出 | pYINで目立つ音の高さを追い、音符データへ変換 |
| アレンジ | スケールに合わせたコード伴奏、ドラム、抽出メロディを個別に追加 |
| 聴き比べ | 原曲、追加パート、原曲と重ねたミックスを再生 |
| 音符の表示 | 抽出メロディとコード伴奏の高さ・長さを図で確認 |
| 保存 | ミックス・追加パートのWAV、生成した音符のMIDI、設定を含むZIPを保存 |

「AI作曲アレンジ」という作品名を継承しています。現在の処理は音声分析と規則に基づく伴奏生成で、大規模な生成AIやLSTMの学習、新しいメロディの自動作曲は含みません。

## 音を聴くときのポイント

テンポやキーの推定結果を手掛かりに、原曲と聴き比べて調整してください。BPMを変えると変化するのは**追加する伴奏のテンポ**で、原曲の速さは変わりません。

メロディ抽出はボーカルだけを分離する処理ではありません。声や楽器が一つずつはっきり鳴る区間で試すと、結果を確認しやすくなります。音色はプログラムで合成した簡易音源です。

## Colabでの利用について

YouTube取得にyt-dlpとFFmpegを、分析にPythonのライブラリを使うため、Colabを主な実行環境にしています。v1.0.1では入力・生成・保存をColab標準フォームにまとめました。操作に追加ウィジェットの描画を必要としません。

YouTube取得の可否は動画の公開状態や接続先の制限にも左右されます。取得に失敗した際は案内を表示し、前の音源を保持します。手元のファイルやデモ音源を選んで続けることもできます。取得・編集する許可がある音源を利用してください。
