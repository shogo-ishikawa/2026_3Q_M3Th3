# AI作曲アレンジ

YouTubeや手元の音源を読み込み、テンポや音の高さを分析して、コード伴奏・ドラム・抽出したメロディを重ねるColab教材です。音楽の専門知識がなくても、設定を一つずつ変えながら音の違いを試せます。

2026年度3Q（月3木3クラス）の学生2名による作品をもとに、公開用に整理・改良しました。学生が考えた「音源の取得 → 分析 → 伴奏の生成 → 再生・保存」という流れを受け継いでいます。

**[Google Colabで開く](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/ai-music-arranger/ai_music_arranger.ipynb)** ／ **[詳しい操作マニュアル](docs/manual.md)**

## 最初に試す

1. 上のリンクからColabを開き、Googleアカウントでログインします。自分の変更を保存したい場合は「ファイル → ドライブにコピーを保存」を選びます。
2. 「ランタイム → すべてのセルを実行」を選びます。個別に実行する場合は、「1. 環境を準備する」のセル、「2. プログラムを読み込む」の3つのコードセル、「3. 操作画面を開く」のセルの順番に進みます。通常のCPUランタイムで利用できます。
3. 操作パネルで「デモ音源を用意」を押します。最初はYouTubeのURLや音声ファイルを用意しなくても試せます。
4. 「音源を解析」を押し、まずは自動設定された値のまま「アレンジを生成」を押します。
5. 「原曲」「追加パートだけ」「ミックス」を聴き比べます。次にドラムや伴奏の有無、音量、音色を変えてみましょう。
6. 気に入った結果をWAV・MIDI、または設定を含むZIPとして保存します。

音が出ないときやYouTubeから取得できないときは、[マニュアルの「困ったとき」](docs/manual.md#困ったとき)を確認してください。

## できること

| 機能 | 内容 |
| --- | --- |
| 音源の準備 | YouTubeのURL、PCの音声ファイル、プログラムが作るデモ音源から選択 |
| 区間の指定 | YouTube・PC音源の開始位置と長さを秒で指定。長さは3〜60秒、初期値は20秒。デモは12秒固定 |
| 音源の分析 | テンポとキーの候補を推定し、伴奏用の設定へ反映 |
| メロディの抽出 | pYINで目立つ音の高さを追い、音符データへ変換 |
| アレンジ | スケールに合わせたコード伴奏、ドラム、抽出メロディを個別に追加 |
| 聴き比べ | 原曲、追加した音だけ、原曲と重ねたミックスを再生 |
| 音符の表示 | 抽出メロディとコード伴奏の高さ・長さを、図で確認 |
| 保存 | ミックスと追加音のWAV、生成した音符のMIDI、再現用の設定を保存 |

「AI作曲アレンジ」という作品名を継承していますが、現在の処理は音声分析とルールに基づく伴奏生成です。大規模な生成AIやLSTMを学習する機能、新しいメロディを作曲する機能は含めていません。

## 音を聴くときのポイント

テンポやキーの推定は、合っているとは限りません。推定結果を手掛かりに、元の音源と聴き比べて調整してください。また、BPMを変えると変化するのは**追加する伴奏のテンポ**です。元の音源の速さは変わりません。

メロディ抽出はボーカルだけを分離する処理ではありません。声や楽器が一つずつはっきり鳴る区間で試すと、結果を確認しやすくなります。初期設定の音色はプログラムで合成した簡易音源で、実際の楽器の録音とは異なります。

## なぜColabで動かすのか

YouTubeからの音源取得にはyt-dlpとFFmpegを、音源の分析にはPythonのライブラリを使います。この機能を維持するため、実行環境はColabを中心にしています。GitHubではNotebookとマニュアルを公開し、上の「Google Colabで開く」から操作できます。

YouTube取得の可否は、動画の公開状態やYouTube側の制限にも左右されます。取得できない場合に、自動で別の音源へ置き換えることはありません。手元のファイルやデモ音源を選んで続けられます。取得・編集する許可がある音源を利用してください。
