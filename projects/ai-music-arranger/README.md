# AI作曲アレンジ

好きな音源に伴奏やドラムを加えて、音の変化を楽しむColab教材です。YouTubeのURL、PCの音声ファイル、デモ曲から始められます。2026年度3Q（月3木3クラス）の学生2名が作った作品をもとに、操作と説明を整えました。

**[Colabで開く](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/ai-music-arranger/ai_music_arranger.ipynb)** ／ **[操作マニュアル](docs/manual.md)**

## まずは音を出してみる

1. **1 → 2** の ▶ を順に押して準備します。
2. **セル3** の `demo_song` で曲を選び、▶ を押します。URLが空欄ならデモ曲を読み込みます。表示された再生ボタンで聴いてみましょう。
3. **セル4** の ▶ を押します。原曲とアレンジを聴き比べてみましょう。
4. 残したい結果は **セル5** で形式を選び、▶ を押して保存します。

### YouTubeの曲を使う

セル3の `youtube_url` に動画URLを貼り付けて ▶ を押します。`input_source` の初期値は **「URLがあればYouTube」** なので、URLがあればYouTubeから取得します。使う区間は `start_seconds`（開始位置）と `duration_seconds`（長さ）で指定できます。

YouTubeオーディオライブラリの曲なら、公式にダウンロードしたMP3を「PCの音源」から読み込めます。[フリー音源でも取得できないときの手順](docs/manual.md#フリー音源でもyoutubeから取れないとき)をまとめています。

### デモ曲を変える

`demo_song` から選べます。オリジナル曲のほか「きらきら星」「歓喜の歌」も用意しました。デモはプログラムで音を作るので、音源ファイルの用意やダウンロードは不要です。YouTube URLを残したままデモを使いたいときは `input_source` を「デモ音源」にします。

## こんなふうに遊べます

- ドラムを外して、リズムの印象を比べる。
- ピアノをギター系の音に変える。
- 長調と短調で、和音の響きがどう変わるかを聴く。
- 原曲の音量を0にして、追加された音だけを確かめる。

設定を変えたらセル4をもう一度実行します。BPMは追加する伴奏の速さを変える設定です。原曲の速さは変わりません。

コードは折りたたんでいます。読みたいときはセルのメニューから「コードを表示」を選んでください。

音源の取り込みがうまくいかないときは[マニュアルの対処方法](docs/manual.md#困ったとき)を確認できます。取得・編集が認められた音源を使ってください。
