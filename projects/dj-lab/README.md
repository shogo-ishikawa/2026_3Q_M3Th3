# LOOP ROOM — DJループスタジオ

16個のループ用パッドと、短い効果音を鳴らすサンプラーで演奏するブラウザアプリです。学生が制作したDJアプリの「音源を予約し、拍の頭で一緒に鳴らす」という仕組みをもとに、教員が公開用に整理・改良しています。

[ブラウザで開く](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/dj-lab/) · [使い方と仕組み](docs/manual.md) · [元作品から引き継いだ内容](docs/source-review.md)

## まずはデモで演奏する

デモを選び、「デモでミックスを始める」を押します。音源ファイルやアカウントの用意は必要ありません。音が鳴り始めると、パッドを見渡しやすい演奏モードへ切り替わります。紹介画面へ戻るときは「紹介も表示」を押してください。

| デモ | テンポ | 雰囲気 |
| --- | --- | --- |
| House | 120 BPM | 四つ打ちのリズムを軸に、パートを重ねる |
| Lo-fi | 90 BPM | ゆったりしたリズムと柔らかい音色 |
| Techno | 132 BPM | タイトなリズムと電子的なフレーズ |

各デモはドラム・ベース・コード・メロディ各4種類、合計16ループです。3つのデモ全体では48ループを用意しました。各ループは8拍分で、同じデモ内の音源はテンポと調をそろえています。演奏モード内でもデモを選んで読み込めます。

まずはループを切り替え、次にサンプラーでフィルやスクラッチ風の音を加えてみましょう。パートミックスでリズムを引き、押している間だけ効くエフェクトを戻してからDROPへ移ると、音の展開を作れます。

## できること

- 元作品と同じ16キー、マウス、タッチでループを操作
- 即時・1拍・4拍・8拍から切り替えのタイミングを指定
- 16種類の短いサンプル音を、即時または次の拍で発音
- 6種類の組み合わせから、イントロ・ブレイク・盛り上がりを作る
- リズムとメロディのバランスをフェーダーで変化させる
- フィルター・エコー・低音カットを、押している間だけ加える
- 音源ごとのループ／ワンショット、音量、左右の位置、ミュートを調整
- 手持ちの音源を読み込み、拍数を指定してテンポへ同期
- ミックスを録音し、音声ファイルとしてダウンロード
- 音源と設定を、利用中のブラウザに保存・復元

デモとサンプル音は、プログラムで合成したオリジナルです。読込、合成、再生、録音、保存はブラウザ内で行い、音声を外部サーバーへ送る機能はありません。

## 利用上のポイント

BPMは停止中に40〜200の範囲で変更します。テンポ同期は再生速度を変える方式のため、音程も変わります。自分で読み込んだ音源は初期状態では原速です。拍数が分かる短いループを使うと、同期の仕組みを確かめやすくなります。

音源は1ファイル25 MiB・120秒まで、デコード後の合計は128 MiBまでです。サンプラーは同時に最大8音を扱い、同じボタンを連打した場合は前の音を置き換えます。「全停止」または `0` はループ、予約、サンプル音、押しているエフェクトをまとめて止めます。

録音は1回10分までで、対応形式はブラウザによって異なります。アプリの出力を記録するため、マイクの許可は必要ありません。ブラウザ内の保存は1つの配置を記録し、次の保存で置き換えます。他の端末へ自動では移らず、サイトデータの削除やプライベート閲覧の終了などで失われる場合があります。v1.0.0で保存した配置も読み戻せます。

## ダウンロードして起動する

配布ZIPを展開すると、`v1.1.0` フォルダーができます。ブラウザのモジュール機能を使うため、`index.html` のダブルクリックでは起動せず、ローカルサーバー経由で開いてください。Python 3が入っていれば、展開したフォルダー内で次のコマンドを実行できます。

Windows:

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

macOS / Linux:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

その後、ブラウザで `http://localhost:8000/` を開きます。ZIPには同じ操作を行う `start_windows.bat` と `start_mac.command` も含めています。起動スクリプトをOSから開けない場合は、上のコマンドを使ってください。Pythonが見つからない場合はPython 3の導入が必要です。サーバーはターミナルで `Ctrl+C` を押すと終了します。

## コードを見ながら学ぶ

| ファイル | 主な役割 |
| --- | --- |
| `app.js` | ボタン・キー・表示と音声処理をつなぐ |
| `core.js` | キー配列、拍や再生位置などの計算 |
| `engine.js` | 音源の予約・再生・停止とエフェクト |
| `demo.js` | 3つのデモのリズムや音色を合成 |
| `sampler.js` | 短いドラムや効果音を合成 |
| `storage.js` | 音源と設定をブラウザ内へ保存 |

まずはデモを聴き、次に `demo.js` や `sampler.js` の音符・パターン・音色を一つ変えてみましょう。コードの変更と音の違いを結びつけやすいと思います。BPMや拍数の計算をPythonで確かめる例は[操作説明](docs/manual.md)にあります。

開発時の検査と配布ZIPの生成:

```bash
npm test
python3 tools/build_release.py
```
