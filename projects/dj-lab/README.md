# LOOP ROOM — DJループスタジオ

16個のパッドで、リズム・ベース・コード・メロディを重ねるブラウザアプリです。学生が制作したDJアプリの「音源を予約し、拍の頭で一緒に鳴らす」という仕組みをもとに、教員が公開用に整理・改良しています。

[ブラウザで開く](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/dj-lab/) · [使い方と仕組み](docs/manual.md) · [元作品から引き継いだ内容](docs/source-review.md)

## まずはデモで遊ぶ

「デモでミックスを始める」を押すと、自作の合成音源を読み込んで演奏が始まります。音源ファイルやアカウントの用意は必要ありません。パッドを押して別のフレーズへ切り替え、フィルターやエコーで音の変化を試してみましょう。

デモの16音源は同じテンポ・調に合わせています。4種類ずつのドラム、ベース、コード、メロディがあり、初期設定では各パートを1音源ずつ重ねます。「同じパートは1音源」を外すと、同じ行の音源も同時に鳴らせます。

## できること

- パッドをマウス・タッチ・元作品と同じ16キーで操作
- 即時・1拍・4拍・8拍から、切り替えのタイミングを指定
- 音源ごとのループ／ワンショット、音量、左右の位置、ミュートを調整
- 手持ちの音源を読み込み、拍数を指定してテンポへ同期
- マスター音量、低音・高音、フィルター、エコーを調整
- ミックスを録音し、対応する音声形式でダウンロード
- 音源と設定を、利用中のブラウザに保存・復元

音源の読込、合成、再生、録音、保存はブラウザ内で行います。音声を外部サーバーへ送る機能はありません。デモはプログラムで合成したオリジナル音源です。

## 利用上のポイント

BPMは停止中に40〜200の範囲で変更します。テンポ同期は音源の再生速度を変えるため、音程も変わります。自分で読み込んだ音源は初期状態では原速です。拍数が分かるループを使うと、同期の仕組みを確かめやすくなります。音源は1ファイル25 MiB・120秒まで、デコード後の合計は128 MiBまでです。

録音の対応形式はブラウザによって異なります。録音機能はアプリの出力を記録するので、マイクの許可は必要ありません。ブラウザ内の保存は1つの配置を記録し、次の保存で置き換えます。他の端末へ自動では移らず、サイトデータの削除やプライベート閲覧の終了などで失われる場合があります。

## ダウンロードして起動する

配布ZIPを展開すると、`v1.0.0` フォルダーができます。ブラウザのモジュール機能を使うため、`index.html` のダブルクリックでは起動せず、ローカルサーバー経由で開いてください。Python 3が入っていれば、展開したフォルダー内で次のコマンドを実行できます。

Windows:

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

macOS / Linux:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

その後、ブラウザで `http://localhost:8000/` を開きます。ZIPには同じ操作を行う `start_windows.bat` と `start_mac.command` も含めています。起動スクリプトをOSから開けない場合は、上のコマンドを使ってください。Pythonが見つからない場合はPython 3の導入が必要です。サーバーはターミナルで `Ctrl+C` を押すと終了します。

## コードを見ながら学ぶ

| ファイル | 主な役割 |
| --- | --- |
| `app.js` | ボタン・キー・表示と音声処理をつなぐ |
| `core.js` | キー配列、拍や再生位置などの計算 |
| `engine.js` | 音源の予約・再生・停止とエフェクト |
| `demo.js` | デモのリズムや音色を数式で合成 |
| `storage.js` | 音源と設定をブラウザ内へ保存 |

まずはデモを聴き、次に `demo.js` の音符やパターンを変えると、コードの変更と音の違いを結びつけやすいと思います。BPMや拍数の計算をPythonで確かめる例は[操作説明](docs/manual.md)にあります。

開発時の検査と配布ZIPの生成:

```bash
npm test
python3 tools/build_release.py
```
