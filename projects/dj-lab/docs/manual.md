# LOOP ROOMの使い方と仕組み

## 音を重ねてみる

1. 「デモでミックスを始める」を押します。デモは120 BPMで、各音源は8拍分です。
2. 気になるパッドを押します。「予約中」の音源は、指定した拍の区切りで再生が始まります。再生中のパッドを押すと、同じ区切りで停止します。
3. 「フィルター」や「エコー」を少しずつ動かし、変化を聴き比べます。「全停止」で演奏と予約を止められます。

4行はドラム・ベース・コード・メロディです。初期設定では、同じ行の別パッドへ切り替えると先の音源が止まります。「同じパートは1音源」を外せば、同じ行も含めて重ねられます。パッドの状態は色だけでなく、文字でも表示します。

## 拍に合わせて切り替える

「切り替えるタイミング」は、パッド操作をいつ実行するかを決めます。

| 設定 | 実行するタイミング |
| --- | --- |
| 即時 | 操作後すぐ |
| 1拍 | 次の拍の頭 |
| 4拍 | 次の4拍の区切り |
| 8拍 | 次の8拍の区切り |

8拍は元作品の操作を引き継いだ初期設定です。予約を取り消したい場合は、同じパッドをもう一度押します。停止中にも開始を予約でき、「再生」を押すと予約した音源がそろって始まります。再生中に区切りの設定を変えても、すでに入れた予約の時刻は変わりません。

BPMは1分間の拍数です。120 BPMでは1拍が0.5秒、8拍が4秒になります。BPMは停止中に変更してください。変更後もデモの拍数が合うよう、同期を有効にした音源の再生速度を調整します。

## 自分の音源を使う

パッドの設定ボタンから音源を選び、ファイルを読み込みます。利用できる形式はブラウザの音声デコーダーに依存します。うまく読めない音源は、WAVなど別の形式へ変換して試してください。

音源は1ファイル25 MiB・120秒まで読み込めます。デコード後の音声データ合計は128 MiBまでです。長い曲全体より、繰り返し使いたい短い部分を用意すると扱いやすくなります。

自分の音源は、最初は原速で再生します。一定の長さで繰り返す素材なら、含まれている拍数を指定し「テンポに合わせる」を有効にします。例えば4秒の8拍ループは120 BPM相当です。同期は再生速度を変える方式なので、テンポを上げると音程も上がります。曲の拍や先頭位置を自動で検出する機能ではありません。

「指定した拍数からBPMを算出」は、音源の拍数が分かっているときに使います。拍数は1・2・4・8・16・32拍から選び、`BPM = 拍数 × 60 ÷ 音源の長さ（秒）` で計算します。16拍を選ぶと、元作品の「4小節・16拍と仮定する」計算と同じになります。任意の曲から正しいBPMを推定する操作ではありません。

設定では音量、左右の位置、ミュート、ループ再生を選べます。ループを外すと1回だけ再生します。同じパッドの発音は1つに管理し、連打によって音源が無制限に重ならないようにしています。

## 音を整えて録音する

マスターの低音・高音は音域ごとの強さ、フィルターは高い音の通し方、エコーは遅れて返る音の量を変えます。音源をたくさん重ねると音量が大きくなるので、メーターを見ながらマスター音量を調整してください。

「録音」を押してからパッドやエフェクトを操作し、停止後に表示されるリンクから音声を保存します。録音するのはアプリで鳴らした音で、周囲の会話やマイク入力は入りません。保存形式は対応状況に応じて選ばれ、ブラウザによってWebMやMP4などになります。録音に対応しない場合も演奏は利用できます。

「保存」は、音源と配置・設定を今のブラウザ内へ記録します。「復元」はその保存内容を読み戻します。保存できるのは1つの配置で、次に保存すると置き換わります。保存内容を置き換える前に、残したい演奏は録音としてダウンロードしておきましょう。容量不足などで保存・復元に失敗した場合はメッセージが表示され、現在の配置を保ちます。ブラウザ内保存はバックアップや端末間の共有を行う機能ではありません。

## キーボード

| 行 | パッドに対応するキー |
| --- | --- |
| ドラム | `1` `3` `5` `7` |
| ベース | `Q` `E` `T` `U` |
| コード | `A` `D` `G` `J` |
| メロディ | `Z` `C` `B` `M` |
| 再生・全停止 | `P` |
| 全音源と予約を停止 | `0` |

入力欄を編集している間は、パッドのショートカットが作動しません。スマートフォンではパッドとボタンをタップして同じ操作ができます。

## コードで確かめる

パッドは配列、音源ごとの状態はオブジェクトで管理しています。`for` で16個のパッドを順に処理し、`if` で再生中か予約中かを判定します。`engine.js` は音を鳴らす時刻をWeb Audioの時計で予約し、`app.js` は画面表示や入力を扱います。画面の描き直しと発音の時刻を分けるのがポイントです。

次のPythonはGoogle Colabでも試せます。BPMや拍数を変え、アプリの表示と比べてみましょう。

```python
def loop_seconds(bpm, beats):
    return 60 * beats / bpm

for bpm in [90, 120, 150]:
    seconds = loop_seconds(bpm, 8)
    print(f"{bpm} BPMの8拍: {seconds:.2f}秒")

# 4秒・8拍の素材を150 BPMに合わせる速度
source_bpm = 60 * 8 / 4
playback_rate = 150 / source_bpm
print(f"再生速度: {playback_rate:.2f}倍")
```

その後、`demo.js` のパターンや音符を一つ変えて聴き比べると、数値と音のつながりを確認できます。

録音は1回10分までです。10分で自動終了し、保存用リンクを表示します。
