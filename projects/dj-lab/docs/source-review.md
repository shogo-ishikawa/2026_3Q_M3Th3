# 元作品と公開版の関係

LOOP ROOMは、講義で提出されたDJアプリをもとに教員が公開用に整理・改良したものです。学生が提出したバージョンそのものとは、操作や機能が異なります。

提出物の音声処理はHTML内のJavaScriptが担い、PythonはそのHTMLを書き出してブラウザで開く起動用コードでした。公開版はその操作と処理構造を引き継ぎ、複数のJavaScriptファイルに整理しています。

| 元作品で確認した実装 | 公開版での扱い |
| --- | --- |
| `discConfigs` による4行×4音源と16キー | 16パッドと元のキー配列を継承。行をドラム・ベース・コード・メロディとして案内 |
| `isSelected` を切り替え、8拍の先頭で同時発音 | 予約操作と8拍の初期設定を継承。即時・1拍・4拍も選択可能に変更 |
| `P` による開始・停止、`0` による全音源停止 | 同じキーを継承し、画面のボタンとタッチ操作も追加。停止時には発音・予約をまとめて解除 |
| `playDiscAudioBuffer` と `onended` で音源を再生・解放 | 予約時刻を音声時計で管理し、予定した発音の取消やノードの解放を扱う処理へ整理 |
| 音源から作る波形ピーク、円形波形、針による再生位置 | パッドの円形表示と選択音源の波形、マスター出力のモニターへ発展 |
| IndexedDBへ音源とBPMを保存・読込 | 音源と設定をブラウザ内に保存する構成を継承 |
| 音源を16拍と仮定し、長さからBPMを計算 | 拍数を選ぶ形に拡張し、16拍指定で元の計算を継承。一般の曲の自動拍検出ではないことを画面と説明書で明示 |

元作品では同じ音源のワンショットを重ねて鳴らせました。公開版は1パッドの発音を1つに管理し、ループの開始・停止や同じパート内の切り替えを中心とした操作に変えています。「同じパートは1音源」を外すと、異なるパッドを最大16音源まで重ねられます。

公開版では、オリジナルの合成デモ、音源ごとの音量・左右の位置・ミュート、テンポ同期、マスターの音質調整・フィルター・エコー、録音とダウンロードを追加しました。

v1.1.0では、House・Lo-fi・Technoの3つのデモ、合計48ループへ増やしています。初版のHouse音源は識別子と合成結果を保ち、v1.0.0で保存した配置から復元できるようにしています。さらに16種類の短いサンプル音、パートミックス、押している間だけ効くエフェクト、6種類の演奏用の組み合わせを追加しました。これらは元作品の操作を発展させるために新しく実装した機能です。

追加サンプラーは同時8音まで、同じサンプルの押し直しは再発音として扱います。元作品の無制限な重ね打ちをそのまま再現したものではありません。ループと短いサンプルの音は同じマスター出力へ送り、録音にも含めます。

公開コード・説明書には学生の氏名、学科、学籍番号、提出ファイルの個人名を含むパスを記載していません。提出物に同梱されていた音源や発表資料は再配布せず、デモは新たにプログラムで合成しています。
