# 動作確認と対応範囲

## 確認する内容

- Python・Numba・Numba並列のSHA-256照合をPython標準hashlibと比較します。
- 文字数1〜32、候補の先頭・中央・末尾、範囲外、符号付き64ビット整数の境界を確認します。
- 候補生成、辞書・変形・形式のヒント、探索の打切り、平均と全候補の推定を確認します。
- 配布Notebookの5セルを上から実行し、デモの探索からZIP保存まで確認します。
- Notebookの出力・実行番号を残さず、フォームから操作できる構成を検査します。
- 既存のくじびきラボと共通Pagesの確認も維持します。

## 未確認の環境

GPU実機での性能と、Colabブラウザ上での入力・ダウンロード操作は未確認です。GPUの確認用テストは含めています。GPUのある環境ではPASSWORD_LAB_TEST_GPU=1を指定して実行できます。

実行時には各方式で既知の正解と不正解を確かめ、失敗した方式は理由を表示して使用しません。GPUが利用できない場合もPythonまたはNumbaで続けられます。

## 推定の範囲

SHA-256単発照合の実測速度を使います。固定長と文字集合が既知で、一様に生成した文字列を総当たりする仮定です。人が考えた文字列の強度、PBKDF2の探索時間、実サービスへのログイン時間には流用しません。

測定は小さな同一バッチを3回走査した中央値です。初回コンパイルなどの準備は別に表示します。長時間運転や別の計算機で同じ速度になる保証はありません。
