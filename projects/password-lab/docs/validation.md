# 検証の入口

現在の動作確認は[動作確認の記録](verification.md)にまとめています。

- Python・Numba・Numba並列は、同じSHA-256をPython標準hashlibと照合します。
- 探す側の情報、未知長の列挙順、全体の時間・件数上限、推定の候補数を検証します。
- 配布Notebookを上から実行し、3モードと保存内容を確認します。
- Web版は入力からWorkerへの条件伝達、実照合、任意のGPU処理を確認します。

実GPUの確認は、模擬テストやCPUでの動作と区別します。推定の前提は[測定値と推定値の読み方](model-notes.md)を参照してください。
