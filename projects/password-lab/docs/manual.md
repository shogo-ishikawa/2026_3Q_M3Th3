# パスワードラボの使い方

長さや文字種を少し変えて、探索の難しさがどう変わるか試してみましょう。**実際に使っているパスワードは入力せず、実験用の文字列を使ってください。**

## 1. 準備する

[Colabで開き](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/password-lab/password_lab.ipynb)、セル1を実行します。

GPUを使う場合は「ランタイム → ランタイムのタイプを変更」で選び、セル1のgpu_enabledを有効にします。GPUがない場合やライブラリを準備できない場合もCPUで続けられます。

Numbaは初回にPythonの処理を機械語へ変換します。最初の実行だけ時間がかかることがあります。

## 2. 文字列を用意する

セル2のsource_modeで、デモ・自動生成・自分で入力から選びます。自分で入力する場合は実行後に入力欄が出ます。

デモの数字4桁は数字だけ、「単語＋数字」は数字と小文字を使います。自動生成と自分で入力ではチェックした文字種を使います。入力文字列に含まれる文字が選択した集合の外にある場合、総当たりとその推定は対象外になります。

自動生成では、選んだ文字種を合わせた集合から各文字を一様に選びます。必ずすべての文字種が入るという意味ではありません。最初は短い数字列から試すと違いをつかみやすくなります。

## 3. 探し方と速さを比べる

セル3で各方法の時間・件数の上限を指定します。それぞれ独立した探索なので、途中で見つかっても他の方法を試します。

| 方法 | 何を試すか |
| --- | --- |
| 辞書 | 教材に用意した短い単語リストなど |
| 単語の変形 | 大文字化や数字の追加 |
| 形式のヒント | 一部の文字や文字種を知っている仮定 |
| 総当たり | 選んだ文字と長さで作れる組み合わせ |

例えばsakura?d?d?d?dは「sakura＋数字4文字」、?d?d?d?dは「数字4文字」です。?lは小文字、?uは大文字、?sは記号を表します。?そのものを固定文字にしたい場合は??と書きます。

辞書や形式のヒントは予想が合えば候補を絞れます。どんな文字列にも最速になる方法ではありません。この教材の小さな辞書は、実際の出現頻度や漏洩パスワードを再現していません。

| 表示 | 読み方 |
| --- | --- |
| 発見 | 実際に試した候補の中に正解があった |
| 打切り | 時間や件数の上限に達した |
| この候補群では未発見 | 用意した候補を調べ終えたが見つからなかった |
| 対象外 | 指定した文字集合などでは扱えなかった |

「未発見」「打切り」は、破れないことを意味しません。

同じセルでPython・Numba・Numba並列・利用可能なGPUも比較します。同じ候補範囲を3回ずつ全走査し、その中央値を使います。初回の変換・準備時間は別に表示します。総当たりには実測で最も速かった方式を使い、ほかの探し方はPythonの標準hashlibで実行します。

総当たりは小さなバッチごとに処理します。発見後もそのバッチを最後まで計算するため、表示する件数には余分な照合が含まれます。時間上限もバッチ単位で確認するため、指定時間を少し超える場合があります。

GPUはライブラリ・ドライバー・ランタイムの条件により使えない場合があります。その場合は理由を表示してCPUを使います。小さい問題では、分担や準備の負担により並列化した方が遅くなる場合もあります。

## 4. 推定時間と保存方式を考える

使える文字がC種類、長さがL文字なら、組み合わせはCのL乗通りです。

各文字を一様に生成し、長さと文字集合が分かっている条件で、候補数をN、速度をr件/秒とすると、次の時間を見積もれます。

- 平均的に見つかるまで：(N + 1) / (2 × r) 秒
- 全候補を調べるまで：N / r 秒

数字4文字なら1万通りです。人が考えた単語や規則的な文字列には、この平均を実際の安全性として当てはめられません。辞書などによる発見結果も併せて見てください。

表示値は測定した計算機・候補範囲・実装に依存します。長時間の処理、他の計算機、他の照合方式で同じ速度になる保証はありません。

セル4では、同じ文字列でSHA-256とPBKDF2を別に測ります。PBKDF2は計算を繰り返し、1回の推測の負担を増やす方式です。教材で選ぶ反復回数は実サービス向けの推奨値ではありません。SHA-256の速度をPBKDF2の探索時間へ流用しません。

## 5. 保存して次の実験へ進む

セル5からCSVとJSONをZIPで保存します。入力文字列・照合用ハッシュ・形式のヒント・探索候補は含めません。Notebookのコピーや画面出力は、このZIPとは別に残ることがあります。

## 実際のパスワードとの違い

この教材はSHA-256の照合を使う、独立した実験です。他人のアカウントや外部サービスへのログインは行いません。実際の保存方式にはソルトや計算を重くする仕組みがあり、オンラインには試行制限もあります。実サービスが何秒で破られるかを示すものではありません。
