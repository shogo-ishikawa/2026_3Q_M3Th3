# FACEGATE

顔を登録し、カメラや写真を使って照合を試せるアプリです。顔の検出、登録者との照合、表情ラベルの分類を別々の処理として動かし、類似度や撮影条件も確認できます。

**[ブラウザで使う](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/face-recognition-lab/)** ／ [使い方](docs/manual.md) ／ [アプリ一式（ZIP）](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/face-recognition-lab/dist/facegate_v1.0.0.zip)

## まず試す

1. ブラウザ版を開き、モデルを読み込みます。初回は約85 MBを読み込むため、通信と準備に時間がかかります。
2. 本人の同意を確認し、名前と顔を登録します。カメラを使えない場合は写真から試せます。
3. 照合を始め、類似度と判定を確認します。登録とは別に撮った写真でも比べてみましょう。
4. しきい値、顔の向き、明るさを変え、結果の変化を確かめます。

ブラウザ版の画像処理は、開いている端末の中で行います。顔画像や特徴量を照合用サーバーへ送信しません。ページと学習済みモデルの読み込みには通信を使います。

## できること

| 機能 | 内容 |
| --- | --- |
| 顔の登録 | カメラや写真から顔の特徴量を作り、名前と対応させる |
| 顔の照合 | 登録した特徴量とのコサイン類似度を比べ、しきい値で判定する |
| 表情の分類 | FER+の8ラベルへの分類結果を表示する |
| 撮影条件の確認 | 明るさ・ピント・顔の向きなどの目安を表示する |
| 動作チャレンジ | 指示に合わせて顔を動かし、検出結果の変化を確かめる |
| 記録と分析 | 記録を明示的に始めたときの結果をCSVに書き出し、Colabで可視化する |

カメラの判定は複数フレームで安定化させます。写真1枚の結果と、時間方向に確認した結果の違いも見られます。動作チャレンジは検出の実験であり、写真や動画を使ったなりすまし全般への耐性を保証する機能ではありません。

表情ラベルは、画像の見た目をモデルが分類した結果です。本人が申告した気持ちと比べることで、表情の分類と気持ちの違いも確かめられます。

## データはどこに残るか

ブラウザ版では、登録内容と記録は最初はメモリ内だけで扱います。顔写真は保存しません。「この端末に登録を保存」を選んだ場合にだけ、特徴量・名前・設定をこのブラウザへ保存します。ログは自動保存せず、必要な場合にCSVへ書き出します。

特徴量も、名前と組み合わせると登録した人を照合できるデータです。共用端末では保存を選ばず、使い終わったら全データを削除してください。CSVにも名前などが含まれるため、共有前に内容を確認してください。

## Python版とColab

学生作品のPython版も[local/](local/)に収録しています。Windowsでは`local/起動.bat`を実行すると、同じPC内のPythonサーバーと専用の画面が立ち上がります。詳しい導入方法は[ローカル版の説明](local/README.md)を参照してください。ブラウザ版とPython版は登録データを別々に持ち、自動同期しません。

[Colabで分析する](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/face-recognition-lab/face_recognition_lab.ipynb)では、リスト・辞書・`for`・`if`・関数を使い、しきい値と誤判定の関係を調べます。最初のデータは仕組みを学ぶための合成データです。実測の精度を表すものではありません。自分で書き出したCSVの時系列も、日本語グラフで表示できます。

## コードを変更する

ZIPは`v1.0.0/`というフォルダーに展開します。Macで管理するときは、例えば次の場所に置けます。

```text
/Users/shogo/Dropbox/share_data/open_material/misc/apps/FaceGate/v1.0.0
```

ZIPにはブラウザ版のモデルと実行ライブラリも含めます。展開したフォルダーで次を実行すると、表示されたURLからブラウザ版を手元で開けます。

```bash
python3 tools/serve.py
```

Python版は別に`local/起動.bat`から起動します。こちらのPython環境の導入とモデル取得には、初回に通信が必要です。

変更したソースをHTTPSでGitHubへ送る場合は、展開した`v1.0.0/`で次を実行します。モデルや個人の登録データは送信対象から外します。

```bash
bash tools/sync_project.sh
```

既定では`v1.0.0/`の隣の`repository/`を使います。既に管理用のチェックアウトがある場合は、引数へその場所を指定できます。作業中の変更があるチェックアウトには上書きしません。新しいブランチをGitHubへ送った後、表示された案内に従ってPull Requestを作り、内容を確認して反映します。

| 内容 | 場所 |
| --- | --- |
| ブラウザの画面と操作 | `index.html`・`styles.css`・`app.js` |
| 画像の処理と照合 | `engine.js` |
| ブラウザへの保存と入力検査 | `browser-store.js` |
| Python版 | `local/` |
| Pythonの分析教材 | `face_recognition_lab.ipynb` |

[設計と開発](docs/design.md)に処理の分担を、[出典](docs/sources.md)にモデルと参考資料をまとめています。導入に使うバージョンと配布条件は、[配布モデルと実行ライブラリ](THIRD_PARTY_NOTICES.md)も参照してください。

実施した確認と未確認の範囲は[検証記録](docs/validation.md)を参照してください。
