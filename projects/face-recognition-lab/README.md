# FACEGATE

学生作品「FACEGATE」を基に、高速な顔照合と複数人の同時処理を加えたブラウザ発展版です。カメラや写真から顔を登録し、照合候補・類似度・撮影条件を確認できます。分析モードでは表情ラベルの分類も試せます。

**[学生の元提出版をダウンロード](original/facegate-submitted.zip)** ／ [ブラウザ発展版を使う](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/face-recognition-lab/) ／ [使い方](docs/manual.md) ／ [発展版一式（ZIP）](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/face-recognition-lab/dist/facegate_v1.1.0.zip)

学生への配布には、提出されたZIPを変更せずに保存した元提出版を使います。ブラウザ発展版と、`local/`の公開用に調整したPython版は、元提出版から区別しています。元提出版の確認用ハッシュと扱いは[配布の説明](original/README.md)を参照してください。

## まず試す

1. ブラウザ発展版を開き、モデルを読み込みます。顔照合の初回準備は約50 MB、表情分析を初めて使うときは約35 MBを追加で読み込みます。
2. 本人の同意を確認し、名前と顔を登録します。カメラを使えない場合は写真から試せます。
3. 照合を始め、類似度と判定を確認します。登録とは別に撮った写真でも比べてみましょう。
4. しきい値、顔の向き、明るさを変え、結果の変化を確かめます。

ブラウザ版の画像処理は、開いている端末の中で行います。顔画像や特徴量を照合用サーバーへ送信しません。ページと学習済みモデルの読み込みには通信を使います。

## できること

| 機能 | 内容 |
| --- | --- |
| 顔の登録 | 最大100人、1人につき最大12個の特徴量を登録する。向きや明るさの異なるサンプルも残せる |
| 高速な顔照合 | 表情分析を省いて照合に計算を集中。対応環境ではWorkerへ処理を分ける |
| 複数人の照合 | 一度に最大50顔を処理し、顔ごとに照合候補・判定・記録を分ける |
| 表情の分類 | 分析する顔を選び、FER+の8ラベルへの分類結果を表示する |
| 撮影条件の確認 | 明るさ・ピント・顔の向きなどの目安を表示する |
| 動作確認 | 選んだ顔が指示に合わせて動くかを試す実験。本人照合とは別に結果を表示する |
| 記録と分析 | 記録を明示的に始めたときの各顔の結果をCSVに書き出し、Colabで可視化する |

カメラは最初に一致候補を示し、異なる複数フレームで確認してから判定を確定します。新規設定の既定値は3フレームです。顔が小さい、撮影条件が悪い、候補が似通っている、同じ登録が複数の顔の候補になる場合は、無理に確定せず保留します。処理人数の上限と処理時間を表示するため、使用する端末に合わせて調整できます。

最大50顔は処理上限です。50人全員をどの距離・照明でも正しく照合できることを表すものではありません。多人数では顔が小さくなりやすく、解像度や撮影距離によって照合できる人数が変わります。

表情ラベルは、画像の見た目をモデルが分類した結果です。本人が申告した気持ちと比べることで、表情の分類と気持ちの違いも確かめられます。

## 写真・動画、マスクなどへの対応

動作確認は、顔を追いながら指示した動きを確かめる実験です。通常のRGBカメラから実際の奥行きを測る機能はなく、写真・動画の提示を確実に除外して「立体の生身の顔だけ」を受け入れる機能ではありません。

マスクやサングラスで隠れた部分を画像生成で補完する処理や、照合しやすくするためにしきい値を自動で下げる処理は入れていません。この組合せで精度を保てる検証がないためです。見えている情報から照合し、条件が足りない場合は保留します。

## データはどこに残るか

ブラウザ版では、登録内容と記録は最初はメモリ内だけで扱います。顔写真は保存しません。「この端末に登録を保存」を選んだ場合にだけ、特徴量・名前・設定をこのブラウザへ保存します。ログは自動保存せず、必要な場合にCSVへ書き出します。

特徴量も、名前と組み合わせると登録した人を照合できるデータです。共用端末では保存を選ばず、使い終わったら全データを削除してください。CSVにも名前などが含まれるため、共有前に内容を確認してください。

## 元提出版、参考Python版、Colab

| 配布物 | 位置付け |

参考Python版はWindowsで`local/起動.bat`を実行すると、同じPC内のPythonサーバーと専用の画面が立ち上がります。導入方法は[Python版の説明](local/README.md)を参照してください。ブラウザ版と各Python版は登録データを別々に持ち、自動同期しません。

[Colabで分析する](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/face-recognition-lab/face_recognition_lab.ipynb)では、リスト・辞書・`for`・`if`・関数を使い、しきい値と誤判定の関係を調べます。最初のデータは仕組みを学ぶための合成データです。実測の精度を表すものではありません。自分で書き出したCSVの時系列も、日本語グラフで表示できます。

## コードを変更する

発展版一式のZIPは`v1.1.0/`というフォルダーに展開します。Macで管理するときは、例えば次の場所に置けます。

```text
/Users/shogo/Dropbox/share_data/open_material/misc/apps/FaceGate/v1.1.0
```

ZIPにはブラウザ版のモデルと実行ライブラリも含めます。展開したフォルダーで次を実行すると、表示されたURLからブラウザ版を手元で開けます。

```bash
python3 tools/serve.py
```

参考Python版は別に`local/起動.bat`から起動します。Python環境の導入には初回に通信を使います。同梱のモデルが使える場合は、そのモデルを共用します。

変更したソースをHTTPSでGitHubへ送る場合は、展開した`v1.1.0/`で次を実行します。モデルや個人の登録データは送信対象から外します。元提出版のZIPを変更して送信しないでください。

```bash
bash tools/sync_project.sh
```

既定では`v1.1.0/`の隣の`repository/`を使います。既に管理用のチェックアウトがある場合は、引数へその場所を指定できます。作業中の変更があるチェックアウトには上書きしません。新しいブランチをGitHubへ送った後、表示された案内に従ってPull Requestを作り、内容を確認して反映します。

| 内容 | 場所 |
| --- | --- |
| ブラウザの画面と操作 | `index.html`・`styles.css`・`app.js` |
| 画像の処理 | `engine.js` |
| 推論の呼び出し・Worker | `inference-client.js`・`inference-worker.js` |
| 顔ごとの追跡と照合 | `tracking.js` |
| ブラウザへの保存と入力検査 | `browser-store.js` |
| 元提出版 | `original/` |
| 参考Python版 | `local/` |
| Pythonの分析教材 | `face_recognition_lab.ipynb` |

[設計と開発](docs/design.md)に処理の分担を、[出典](docs/sources.md)にモデルと参考資料をまとめています。導入に使うバージョンと配布条件は、[配布モデルと実行ライブラリ](THIRD_PARTY_NOTICES.md)も参照してください。
