# 学生の元提出版

[元提出版をダウンロード](facegate-submitted.zip)

学生へ配布する元の作品です。提出されたZIPをそのまま保存しています。コード、説明書、起動ファイル、ZIP内の構成や圧縮データを変更していません。起動手順はZIP内のREADMEを参照してください。

`manifest.json`にファイルサイズとSHA-256を記載しています。公開用の名前は`facegate-submitted.zip`です。

## ブラウザの発展版との関係

このディレクトリの外にあるブラウザ版は、学生作品を基に機能追加した発展版です。そこで加えた修正や機能追加は、この提出ZIPには反映していません。

`local/`は公開用に調整したPython版の参考実装です。学生の元提出版を配布するときは、このZIPを使ってください。
