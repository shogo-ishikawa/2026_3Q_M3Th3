# シフトスタジオの使い方

勤務できる日時と必要人数をもとにシフトを作ります。初めはデモで試してください。結果を見てから条件を変えると仕組みをつかみやすくなります。

## 1. スタッフを登録する

表示名は勤務表に使う名前です。画面でスタッフを追加すると固定IDが自動で付きます。勤務可能設定や過去実績はこのIDで対応させます。表示名は後から変更できます。

| 項目 | 意味 |
| --- | --- |
| 勤務量の比率 | `1`が標準です。`2`は約2倍の時間を目指し`0.5`は約半分を目標にします |
| 最低・上限時間 | 今回作成する期間の合計勤務時間を指定します |
| 週の上限日数 | 月曜から日曜までの各週に働ける日数です |
| 担当できる役割 | 担当できる仕事の種類です。複数ある場合はカンマで区切ります |

比率は配分の目標です。勤務可能な日時や時間の上下限によっては比率どおりに配分できません。均等にするために必須条件を緩めることはありません。

## 2. シフト枠を作る

1行を1つの勤務枠として日付と時間帯と必要人数を入力します。画面で追加した枠にも固定IDが付きます。必要な役割を指定すると担当できるスタッフだけを割り当てます。

担当者を固定する場合はスタッフIDをカンマで区切って入力します。勤務可能日時や上限などの条件は固定した人にも適用します。

終了時刻には `24:00` を使えます。日をまたぐ勤務は `22:00–24:00` と翌日の `00:00–02:00` のように分けてください。連続した枠を同じ人が担当する場合は勤務枠の間の休息を0にします。休息を11時間にすると同じ人には連続した2枠を割り当てません。

## 3. 勤務できる枠を選ぶ

「勤務可能」の表で各スタッフが働ける枠を選びます。未登録の組み合わせには割り当てません。

| 設定 | 扱い |
| --- | --- |
| 不可 | 割り当てません |
| 可 | 割り当てる候補にします。CSVでは`1`です |
| 希望 | 配分の評価が同じ案では優先します。CSVでは`2`です |

人数不足になった場合は該当する枠を確認してください。必要人数分の勤務可能者がいても時間や日数の上限によって配置できないことがあります。

勤務可能表は14枠ずつ表示します。枠が多い場合は前後のページに切り替えてください。

## 4. 過去実績と作成条件を設定する

過去実績は1勤務を1行としてスタッフIDと日付と時間帯を入力します。今回の最初の勤務枠が始まる時刻までに終了した実績を使ってください。同じ記録を重複して入れないようにします。

「過去分も含めて均等にする」を有効にすると過去と今回の合計を勤務比率へ近づけます。無効にした場合は今回の勤務時間で配分を評価します。比べる過去実績の期間は全員でそろえると分かりやすくなります。

| 条件 | 意味 |
| --- | --- |
| 勤務枠の間の最低休息 | 前の枠の終了から次の枠の開始までに空ける時間です。同じ日の別枠にも適用します |
| 連続して働く日数 | 連勤の上限です |
| 1日の勤務時間 | 同じ日付の勤務を合計した上限です |
| 探索時間の上限 | 条件を満たす割り当てを探す時間です。詳しくは後述します |

過去実績を均等化に含めない場合も休息や連勤などの検査には使います。今回と過去の境界で週の上限日数や1日の上限時間を超えないかも確認します。今回の最低・上限時間には過去分を足しません。

## 5. 結果を確認する

「シフトを作成する」を押すと探索を始めます。入力を変えた後は再作成してください。変更前の結果は無効になります。

| 結果 | 意味と次の操作 |
| --- | --- |
| 条件OK・最良を確認 | 必須条件を満たす勤務表ができました。設定した評価で最良と確認できています |
| 条件OK・最良は未確認 | 必須条件を満たす勤務表はあります。時間が尽きたため最良かどうかは未確認です |
| 条件上作成できない | 必須条件を同時に満たす案がありません。理由を確認して条件を修正してください |
| 時間内に見つからず未判定 | 完成した案はまだありません。作成不可能とは限らないため探索時間や対象期間を見直してください |
| 入力に不備がある | 表示された項目や行番号を確認して入力を直してください |

必要人数が不足した途中結果は出力しません。勤務表と時間のグラフで担当と配分を確認してください。

## 探索時間の選び方

初めは5秒で試してください。秒数は待ち時間ではなく探索の上限です。最良の案と確認できた時点で終了します。

| 上限 | 使い分けの目安 |
| --- | --- |
| 1秒 | 条件を変えながら短く試します |
| 5秒 | 初めに試す基本の設定です |
| 15秒・30秒 | 人数や枠が多いときや条件が複雑なときに試します |

時間を延ばすと答えを見つけたり配分を改善したりする余裕が増えます。今ある案が最良かどうかも調べます。ただし発見や改善を保証する設定ではありません。すでに最良と分かっている案も改善しません。同じ入力から毎回違う案をランダムに作る機能ではありません。

「条件上作成できない」と確認できた場合は条件の修正が必要です。「未判定」の場合は時間を延ばすか対象期間を短くして再実行してください。どちらの場合も必須条件は勝手に変えません。

計算は端末のCPUで行います。画面操作とは別に処理を進めるため探索中も操作できます。速さは端末によって異なります。計算サーバーや外部GPUへ入力を送る処理はありません。

## なぜ探索が必要なのか

6人から2人を選ぶ方法は15通りあります。10枠で別々に選ぶと単純計算では `15^10 = 576,650,390,625` 通りになります。これは条件で候補を絞る前の例です。実際に調べる数や処理時間の見積もりではありません。

このアプリは固定した担当者を先に配置します。残りは選択肢の少ない枠から考えます。勤務可能日時や上限に反する候補は外しながら進めます。行き詰まった場合は前の割り当てに戻って組み替えます。今ある案よりよくなる見込みがない候補は途中で調べるのをやめます。

たとえばAは月曜と火曜に働けるものとします。Bが働けるのは月曜だけです。2人とも週1日が上限で各日1人ずつ必要なときに月曜をAにすると火曜が不足します。月曜をBに変えると火曜にAを入れられます。全体を見て組み替えることで見落としていた案を探せます。

通常の作成では合計勤務時間の偏りを小さくします。4時間を2回働く場合と8時間を1回働く場合は同じ8時間です。勤務回数をそろえる方式とは結果が異なることがあります。

比率がA：B＝2：1とします。過去の勤務がAは8時間でBは0時間の場合に今回16時間分を追加すると合計は24時間です。目標はAが16時間でBは8時間になります。今回は2人とも8時間ずつ働く配分が目安です。枠の長さや勤務可能日時によっては目標どおりになりません。

「最良」とは設定した評価でこれ以上よい案がないと確認できた状態です。入力していない個人の事情までは評価しません。

## 決まった担当を固定する

残したい枠の「この枠の担当を固定」にチェックします。「固定を反映して再作成」を押すと複数の枠をまとめて反映できます。チェックした時点では条件は変わりません。反映前は「選択を戻す」で取り消せます。入力条件を変えた場合も未反映の選択は解除されます。

固定後に勤務可能日時などを変えると担当を維持して残りを組み替えます。同じ条件で再作成した場合は同じ案になることもあります。固定した人にも必須条件を適用します。

一部の人だけが固定されている枠は変更しない限りその指定を引き継ぎます。枠全員を固定する場合はチェックを入れてください。固定を解除する場合はチェックを外して反映します。

「全枠の固定を解除して再作成」で一度に解除できます。「シフト枠」タブの「固定する担当をすべて解除」は入力条件だけを変更します。その後に「シフトを作成する」を押してください。反映した固定は設定の保存やExcel出力にも含まれます。

## 欠勤時の代替案を探す

完成した勤務表の「欠勤時の代替案」でスタッフと欠勤する日を選びます。その日を指定すると全枠で勤務不可にします。1つの枠だけを指定することもできます。複数人が欠勤する場合は続けて追加してください。

元の担当をできるだけ維持するため次の順に案を比べます。

1. 担当を変更する枠が少ない案
2. 枠数が同じ場合は延べ交代人数が少ない案
3. 変更が同じ場合は勤務時間の偏りが小さい案
4. 配分の評価も同じ場合は希望枠に入れる人数が多い案

交代数は各枠で元の担当から外れる人数を合計して数えます。同じ人が2枠から外れる場合は2人分の交代と数えます。表示順だけが変わった枠は変更に含めません。

「欠勤する人の固定だけ外す」を有効にすると欠勤する本人の固定を該当する枠で解除します。ほかの人の固定は維持します。無効にした場合は本人の固定もそのまま使うため作成できないことがあります。

最低勤務時間や連勤などの必須条件は変えません。期間中ずっと欠勤する人に最低時間を指定している場合は条件を見直してください。

代替案が見つかったら変更前後の担当を確認してください。「この案を採用」で反映し「元のシフトに戻る」で取り消せます。採用するまでは元の入力を保持します。採用後は欠勤した日時の勤務不可設定と必要な固定解除が入力へ反映されます。

時間内に最良と確認できなかった場合は変更が最小かどうか未確認と表示します。条件を満たす代替案がない場合は未完成の勤務表を出力しません。

## スタッフ別に勤務表を見る

スタッフを選ぶとその人が担当する枠だけを表示します。同じ枠で働く人も確認できます。勤務時間のグラフはチーム全員分です。表示の切り替えは入力条件や完成した勤務表を変更しません。

CSV・Excelは全員分を出力します。「表示を印刷」は表示中の勤務表と集計を印刷します。

## CSV・Excelを取り込む

「入力用テンプレート」を保存して見出しを変えずに入力してください。CSVは選択中の表に取り込みます。Excelのブックはスタッフ・シフト枠・勤務可能・過去実績・設定をまとめて扱います。取り込み後も画面で編集できます。

表同士はIDで対応します。スタッフ表が`A`で枠が`M1`なら勤務可能の表には`A,M1,1`と入力します。

| 表 | 列名 |
| --- | --- |
| スタッフ | `id,name,weight,minHours,maxHours,maxDays,skills` |
| シフト枠 | `id,date,start,end,required,skill,fixed` |
| 勤務可能 | `staffId,slotId,preference` |
| 過去実績 | `staffId,date,start,end` |

日付は `2026-11-16` の形式で時刻は `09:00` の形式にすると確実です。CSVはUTF-8で保存してください。カンマを含む値は二重引用符で囲みます。役割が複数ある場合は `"レジ,調理"` のようにします。Excelの日付・時刻形式のセルにも対応しています。数式を含むセルは場所を示して取り込みを止めます。数式の代わりに値を入力してください。

CSV出力では数式として解釈される可能性のある文字列に先頭のアポストロフィを付けます。このアプリで読み込むと元の文字列へ戻します。

スタッフ表の例です。

```csv
id,name,weight,minHours,maxHours,maxDays,skills
A,スタッフA,1,0,24,4,レジ
B,スタッフB,0.5,0,16,3,レジ
```

シフト枠と勤務可能の例です。

```csv
id,date,start,end,required,skill,fixed
M1,2026-11-16,09:00,13:00,1,レジ,
```

```csv
staffId,slotId,preference
A,M1,2
B,M1,1
```

CSVは表ごとに順番に取り込めます。表同士のIDや必須条件は「シフトを作成する」で検査します。ファイルのIDを使う場合は関連する表にも同じIDを指定してください。

## 保存と印刷

作業途中は「設定を保存」でJSONファイルを手元に残せます。次回は「保存した設定を開く」で再開してください。未入力の項目がある下書きも保存できます。

完成したシフトはCSV・Excelで保存できます。Excelには入力表と完成シフトと勤務集計を含めます。CSV・Excelは表示の絞り込みにかかわらず全員分を出力します。印刷する勤務表は現在の表示に従います。

入力ファイルや実績をサーバーへ送信することはありません。共有するときは保存したファイルの内容と共有先を確認してください。

## 前回の結果を実績として使う

「過去実績」の「以前の完成シフトを履歴に追加」から前回のCSV・Excelを取り込めます。スタッフIDを同じまま使ってください。今回の枠は実績より後の日付に設定します。

同じID・日付・開始・終了の記録は重複して追加しません。Excelからは「完成シフト」の今回分を読み込みます。画面にある過去実績はそのまま残ります。
