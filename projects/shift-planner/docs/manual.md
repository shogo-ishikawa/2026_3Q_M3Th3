# シフトスタジオの使い方

スタッフの勤務可能日時と必要人数を入力すると、条件を守る割り当てを探します。最初はデモを読み込み、結果を確認してから条件を変えると、仕組みがつかみやすくなります。

## 1. スタッフを登録する

スタッフIDは、ほかの表から人を指定するときに使う短い識別子です。たとえば `A`、`B` のように重複しない値を使います。表示名は勤務表に表示されます。

| 項目 | 意味 |
| --- | --- |
| 勤務量の比率 | `1`が標準、`2`なら標準の約2倍、`0.5`なら約半分を目指します |
| 最小・最大勤務時間 | 今回作成する期間に入れる合計時間の下限と上限です |
| 週の上限日数 | 月曜日から日曜日までの各週に、何日まで勤務できるかを指定します |
| 担当できる役割 | 担当できる仕事の種類です。複数の場合はカンマで区切ります |

比率は希望する配分です。勤務可能日時や上限のために、その比率へ一致できない場合もあります。最小・最大時間などの必須条件を緩めて配分を合わせることはありません。

## 2. シフト枠を作る

日付、開始時刻、終了時刻、必要人数を入力します。各枠にも重複しないIDを付けます。必要な役割を指定した枠には、その役割を担当できるスタッフだけを割り当てます。

担当者を固定したい場合は、固定するスタッフIDをカンマで区切って指定します。固定した人にも、勤務可能日時や上限の検査が適用されます。固定だけを理由に条件を無視することはありません。

勤務枠は同じ日付の中で設定してください。終了時刻には `24:00` を使えます。日をまたぐ勤務は、たとえば `22:00–24:00` と翌日の `00:00–02:00` に分けて入力します。分割した枠同士も、休息時間などの条件の対象になります。

## 3. 勤務可能な組み合わせを登録する

「スタッフID」と「枠ID」の組み合わせで、誰がどの枠へ入れるかを指定します。登録していない組み合わせは勤務不可です。希望の強さは、`1`が勤務可能、`2`が希望です。

全員がすべての枠へ入れるわけではありません。シフトが作成できない場合は、まず該当枠に必要な人数分の勤務可能者がいるか確認してください。

## 4. 過去実績と全体の条件を設定する

過去実績には、スタッフID、日付、開始・終了時刻を入力します。今回の最初の勤務枠が始まる時刻までに終了した実績を使います。同じ実績を重複して入れないでください。

「過去実績も含めて配分する」を有効にすると、過去と今回の勤務時間を足した量が、スタッフごとの比率に近付くように探索します。無効にすると、今回の勤務時間を基準に配分します。個人別集計では、今回と過去の時間を分けて確認できます。

過去実績は、配分の設定にかかわらず、今回との境界で勤務の重複・休息・連勤・週の上限日数・1日の上限時間を検査するために参照します。今回の最小・最大勤務時間には過去分を足しません。

| 全体の条件 | 意味 |
| --- | --- |
| 勤務間の休息時間 | 同じスタッフの勤務と次の勤務の間に空ける時間です |
| 最大連勤日数 | 続けて勤務できる日数の上限です |
| 1日の最大勤務時間 | 同じ日付の勤務を合計した上限です |
| 探索時間 | 条件を満たす割り当てと、より偏りの少ない割り当てを探す時間の上限です |

これらは利用する職場の条件に合わせて入力する項目です。

## 5. 作成結果を確認する

「シフトを作成」を押すと探索を始めます。入力を変更すると、それまでの結果は無効になります。変更後はもう一度作成してください。

| 結果 | 次にすること |
| --- | --- |
| 最適な案が見つかった | 必須条件を満たし、設定した評価方法で最適な案と確認できた結果です。勤務表と個人別集計を確認します |
| 条件を満たす案が見つかった | 必須条件を満たす案です。探索時間内では、配分が最適かどうかまでは確認できていません |
| 条件上作成できない | 必須条件を同時に満たす割り当てがありません。表示された理由を参考に、勤務可能者、必要人数、上限などを変更します |
| 制限時間内に判定できない | 完成した案を見つける前に探索を終えました。不可能と確定した意味ではありません。時間を延ばす、期間や条件を見直すなどして再実行します |
| 入力に不備がある | 行番号や項目を確認し、入力を直してから再実行します |

必要人数が不足した途中結果は、完成シフトとして表示・出力しません。時間や日数の偏りは、グラフと個人別集計でも確認できます。勤務量は時間で評価するため、長さが異なる枠を単純な回数だけで均等にする方式とは結果が異なります。

## CSV・Excelで取り込む

入力テンプレートをダウンロードし、見出しを変えずに入力してください。CSVは選んでいる入力表へ読み込みます。Excelのブックは、スタッフ・シフト枠・勤務可能・過去実績・設定をまとめて扱います。取り込み後も画面で編集できます。

表同士は名前でなくIDで対応します。たとえば、スタッフ表に`A`、シフト枠に`M1`を登録したら、勤務可能の表には`A,M1,1`と入力します。

| 表 | 列名（テンプレートの見出し） |
| --- | --- |
| スタッフ | `id,name,weight,minHours,maxHours,maxDays,skills` |
| シフト枠 | `id,date,start,end,required,skill,fixed` |
| 勤務可能 | `staffId,slotId,preference` |
| 過去実績 | `staffId,date,start,end` |

日付は`2026-11-16`、時刻は`09:00`の形式が確実です。CSVはUTF-8で保存してください。カンマを含む値は二重引用符で囲みます。たとえば複数の役割は`"レジ,調理"`のようにします。Excelの日付・時刻形式のセルも読み込めます。数式を含むセルは、該当位置を表示して取り込みを止めます。数式を使わず、値を入力してください。

CSV出力では、表計算ソフトが数式と解釈しうる文字で始まる文字列に、先頭のアポストロフィを付けて保存します。このアプリで再読み込みすると元の文字列へ戻します。

スタッフ表の例です。

```csv
id,name,weight,minHours,maxHours,maxDays,skills
A,スタッフA,1,0,24,4,レジ
B,スタッフB,0.5,0,16,3,レジ
```

シフト枠と勤務可能の例です。

```csv
id,date,start,end,required,skill,fixed
M1,2026-11-16,09:00,13:00,1,レジ,
```

```csv
staffId,slotId,preference
A,M1,2
B,M1,1
```

## 保存・共有・印刷

作業を続けるための保存では、入力条件を手元に保存し、次回読み込みます。完成したシフトはCSV・Excelで保存できます。Excelには入力表に加え、完成シフトと勤務集計を含めます。「表示を印刷」では入力欄を省き、現在表示している勤務表と集計を印刷します。スタッフで絞り込んでいる場合、印刷する勤務表もその表示に従います。CSV・Excelは表示の絞り込みにかかわらず、全員分を出力します。

処理はブラウザ内で行い、入力ファイルや勤務実績をサーバーへ送信しません。共有するときは、自分で保存したファイルの内容と共有先を確認してください。

## 次回のシフトに実績を引き継ぐ

「過去実績」タブの「以前の完成シフトを履歴に追加」で、このアプリから出力した完成CSV・Excelを読み込めます。スタッフIDを同じまま使い、今回の枠を実績より後の日付に設定してください。同じID・日付・開始・終了の実績は重複追加しません。Excelからは「完成シフト」の今回分を読み込みます。既存の過去実績は画面の入力に残ります。

CSVは各表を順番に取り込めます。入力途中の設定もJSONで保存・再読込できます。表同士のIDの対応や必須条件は「シフトを作成する」で確認します。勤務可能表は14枠ごとに切り替えて表示します。

画面で追加したスタッフ・勤務枠には固定IDが自動で付きます。表示名は自由に変更できます。勤務可能設定や履歴との対応を保つため、画面からID自体は変更しません。CSV・Excelで既存のIDを使う場合は、関連する表でも同じIDを指定してください。

## 探索時間は、どう選ぶ？

最初は5秒を目安にします。これは待ち時間ではなく、探索に使う時間の上限です。設定した評価方法でこれ以上よい案がないと確認できれば、上限より前に終了します。

| 上限 | 使い分けの目安 |
| --- | --- |
| 1秒 | 入力や条件を変えながら、短く試します |
| 5秒 | 最初に試す基本の設定です |
| 15秒・30秒 | 人数や枠が多い、上限や役割などの条件が重なる場合に、探索の余裕を増やします |

時間を延ばすと、条件を満たす案を見つけたり、勤務時間の偏りを改善したり、最良であることを確認したりできる可能性があります。ただし、答えの発見や改善を保証するものではありません。すでに最良と確認できた案の評価は、時間を延ばしても改善しません。同じ入力から、毎回違う案をランダムに作る機能でもありません。

「条件上作成できない」と確認できた場合は、時間の延長ではなく条件の修正が必要です。「時間内に判定できない」場合は、探索時間を延ばすか、対象期間を分けて再実行します。どちらの場合も、必要人数や勤務上限を勝手に緩めることはありません。

計算は利用している端末のCPUで行うため、同じデータでも端末によって処理時間が異なります。画面操作とは別の処理で探索を進め、途中で中止することもできます。入力やファイルを計算サーバーへ送る仕組みや、外部GPUを使う仕組みはありません。

## なぜシフトの作成に探索が必要？

6人から2人を選ぶ方法は15通りあります。10枠でそれぞれ選ぶと、条件を何も考えない単純計算では `15^10 = 576,650,390,625` 通りです。この数は、実際の候補数や処理時間を示すものではなく、選択が積み重なると組み合わせが増えることを表す例です。

このアプリでは、すべてを順番に試すのではなく、固定担当を先に割り当て、候補の組み合わせが少ない枠から考えます。勤務可能日時や上限に反する候補は外し、行き詰まったら前の割り当てに戻ります。さらに、途中の案が今ある案よりよくなり得ないと分かれば、その先は調べません。

たとえば、Aは月曜・火曜に勤務可能、Bは月曜だけ勤務可能で、両者とも週1日までとします。各日1人が必要なとき、月曜をAにすると火曜が不足します。しかし、月曜をB、火曜をAに組み替えれば、全体の条件を満たせます。その場でよさそうな人を選ぶだけでは見落とす案も、組み替えることで見つけられます。

勤務量は合計時間で評価します。4時間を2回と8時間を1回は、どちらも8時間です。過去実績を考慮する場合は、今回と過去の合計を比率に近づけます。たとえばA：B＝2：1で、過去はAが8時間・Bが0時間、今回は16時間分の勤務が必要なら、全体24時間の目標はAが16時間・Bが8時間です。今回の目安は、A・Bとも8時間になります。枠の長さや勤務可能日時のために、目標と一致しない場合もあります。

「最良」とは、入力した条件と勤務時間の評価方法で、これ以上よい案がないと確認できたという意味です。入力していない個人の事情まで評価した結果ではありません。

## 気に入った枠を固定し、残りを調整する

完成した勤務表では、維持したい枠の「この枠の担当を固定」にチェックし、「固定を反映して再作成」を押します。複数の枠を選んでからまとめて反映できます。チェックした時点では入力条件はまだ変わらず、反映ボタンを押すまで固定は確定しません。入力条件を別に変更すると、未反映の選択は解除されます。

固定した担当者にも、勤務可能日時・時間や日数の上限・休息などの必須条件を適用します。固定を反映した後で勤務可能な枠や必要人数などを変更すれば、その固定を守りながら残りを組み替えます。条件を変えずに再作成した場合、同じ勤務表になることがあります。

一部の担当者だけをすでに固定してある枠は、変更しない限りその指定を引き継ぎます。枠全員を固定したい場合はチェックを入れます。固定を外す場合はその枠のチェックを外して反映するか、「全枠の固定を解除して再作成」を使います。未反映の選択を取り消す場合は「選択を戻す」を押します。「シフト枠」の入力タブにある「固定する担当をすべて解除」は入力条件だけを変更するため、その後に「シフトを作成する」を押してください。固定済みの状態は、設定の保存やExcel出力にも含まれます。

## スタッフ別に勤務表を見る

完成後のスタッフ選択で、勤務表をその人が担当する枠だけに絞り込めます。その枠に一緒に入るスタッフも表示します。勤務時間のバランスはチーム全員分を残し、全体との比較に使います。表示の切り替えは入力条件や勤務表そのものを変更しません。

CSV・Excelは常に全員分を出力します。「表示を印刷」は表示中の勤務表を印刷するため、スタッフ別の勤務表を確認したい場合にも使えます。
