# シフトスタジオ / SHIFT STUDIO

学生が提出した「アルバイトシフト自動作成」をもとに公開用の機能を追加したブラウザアプリです。勤務できる日時と必要人数を入力すると条件を守るシフトを探します。

[ブラウザで使う](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/shift-planner/) ／ [使い方](docs/manual.md) ／ [学生版との対応](docs/source-review.md)

## できること

- スタッフや勤務枠などを画面で編集できます。CSV・Excelからも取り込めます。
- 勤務時間の上下限や週の上限日数を守ります。1日の上限時間や連勤と休息も指定できます。
- 担当できる役割や担当者の固定を指定できます。
- 勤務量の比率や過去実績を考慮して配分を調整できます。
- 欠勤時は元の担当をできるだけ維持する代替案を探せます。
- 勤務表と集計を確認してCSV・Excelへ出力できます。スタッフ別の表示や印刷もできます。

必要人数が不足した途中結果は完成シフトとして出力しません。作成不可能と確認できた場合と時間内に判定できなかった場合を区別します。均等化は必須条件を満たす範囲で目指す目標です。全員を必ず同じ時間数にする設定ではありません。

## まず試す

デモを選んで「シフトを作成する」を押してください。通常の作成例に加えて過去実績を含む例や人数不足の例を試せます。自分の条件を使う場合は画面の入力を編集するかテンプレートから取り込みます。

欠勤が出た場合は完成した勤務表の「欠勤時の代替案」を使います。欠勤する人と日または枠を追加してください。変更する枠の少なさを優先して探します。変更内容を確認してから採用できます。

計算とファイルの読み込みはブラウザ内で行います。入力内容はサーバーへ送信しません。必要な作業は保存機能で手元に残してください。デモには架空のスタッフを使っています。

## ZIPで手元に置く

[最新版のZIP](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/shift-planner/dist/shift-planner_v1.2.0.zip) を展開すると `v1.2.0/` ができます。Python 3が使える環境でフォルダー内の `start_windows.bat` または `start_mac.command` を実行してください。ブラウザで `http://localhost:8000/` を開くと使えます。終了は起動した端末で `Ctrl+C` です。

Macでは `/Users/shogo/Dropbox/share_data/open_material/misc/apps/shift-planner/v1.2.0/` のようにバージョン別のフォルダーへ置けます。`.command` を実行できない場合は端末でフォルダーを開いて次を実行してください。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

JavaScriptのモジュールとWeb Workerを使うためローカルサーバーから開く必要があります。HTMLのダブルクリックでは起動しません。Excel用ライブラリもZIPに含めています。

## コードを読む

| ファイル | 役割 |
| --- | --- |
| `app.js` | 入力画面と結果表示・保存と読み込み |
| `solver.js` | 必須条件の検査・担当の探索・完成表の再検証 |
| `worker.js` | 画面操作と別に探索を実行 |
| `absence.js` | 欠勤条件の準備と元の案からの変更比較 |
| `io.js` | CSV・Excelの入出力 |
| `plan-tools.js` | 完成案の担当固定と表示の絞り込み |
| `demo.js` | 架空の入力例 |
| `tests/` | 条件の競合・配分・入出力などの検証 |

初めは `timeToMin` で文字列を分数へ変える処理を読んでみてください。勤務可能な人を絞る条件分岐や担当を組み替える探索へ進むと学生版からの発展を確認できます。[学生版との対応](docs/source-review.md) に考え方をまとめています。

リポジトリのこのディレクトリで検証とZIP作成を実行できます。

```sh
npm test
python3 tools/build_release.py
```

GitHub Pagesへの公開にはリポジトリ共通のGitHub Actionsを使います。[HTTPSのリポジトリ](https://github.com/shogo-ishikawa/2026_3Q_M3Th3) へ変更を反映すると検証と公開処理が実行されます。
