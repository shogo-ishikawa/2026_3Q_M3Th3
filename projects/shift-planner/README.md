# シフトスタジオ / SHIFT STUDIO

学生が提出した「アルバイトシフト自動作成」をもとに、公開用に整理・改良したブラウザアプリです。勤務できる日時と必要人数を入力し、条件を守るシフトを探索します。

[ブラウザで使う](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/shift-planner/) ／ [操作マニュアル](docs/manual.md) ／ [学生版との対応](docs/source-review.md)

## できること

- スタッフ、日付・時間帯・必要人数、勤務可能な枠、過去の実績を画面で編集し、CSV・Excelから読み込みます。
- 勤務時間の下限・上限、週の上限日数、1日の上限時間、連勤上限、勤務間の休息時間を守ります。
- 担当できる役割と担当者の固定を指定できます。
- 同じ勤務量を目指す設定に加え、勤務量の比率を変えたり、過去の実績を含めて偏りを減らしたりできます。
- 作成した勤務表と個人別の集計を確認し、CSV・Excelで保存、印刷できます。

必要人数を満たさない途中の割り当てを完成シフトとして出力しません。「条件を満たす案が見つかった」「条件上作成できない」「制限時間内に判定できない」を区別します。勤務量の均等化は、必須条件を満たしたうえで目指す最適化です。厳密な同時間数を必ず保証する設定ではありません。

## まず試す

ブラウザで開き、デモを選んで「シフトを作成」を押します。通常の作成例、過去実績を含む例、条件を満たせない例を試せます。実際のデータを使うときは、デモの行を編集するか、入力テンプレートに合わせて取り込みます。

入力内容はサーバーへ送信しません。作業を残すときは、画面の保存機能で手元にファイルを保存してください。公開デモには架空のスタッフ情報を使っています。

## ZIPで手元に置く

[最新版のZIP](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/shift-planner/dist/shift-planner_v1.0.0.zip) を展開すると `v1.0.0/` ができます。Python 3を利用できる環境で、このフォルダーの `start_windows.bat` または `start_mac.command` を実行し、`http://localhost:8000/` を開きます。終了は起動した端末で `Ctrl+C` です。

Macでは `/Users/shogo/Dropbox/share_data/open_material/misc/apps/shift-planner/v1.0.0/` のようにバージョンごとのフォルダーへ置けます。`.command` が実行できない場合は、端末でフォルダーを開いて次を実行してください。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Web WorkerとJavaScriptのモジュールを使うため、HTMLを直接ダブルクリックする方法ではなく、上記のローカルサーバーから開きます。Excel用ライブラリもZIPに含みます。

## コードを読む

| ファイル | 役割 |
| --- | --- |
| `app.js` | 入力画面、結果の表示、保存と読み込み |
| `solver.js` | 条件の検証、割り当ての探索、完成シフトの再検証 |
| `worker.js` | 画面操作を止めずに探索を実行 |
| `io.js` | CSV・Excel入出力 |
| `demo.js` | 架空の入力例 |
| `tests/` | 条件の競合、均等化、入出力などの検証 |

まず `timeToMin` で文字列を数値に変える処理を読み、勤務可能な人を絞る条件分岐と、割り当てをやり直す探索を追うと、学生版からの発展を確認できます。探索の考え方は [学生版との対応](docs/source-review.md) にまとめています。

リポジトリのコードを取得した環境では、次のコマンドで検証とZIP作成を実行できます。

```sh
npm test
python3 tools/build_release.py
```

GitHub Pagesへの公開は、リポジトリ共通のGitHub Actionsで行います。このディレクトリのファイルを更新し、[HTTPSのリポジトリ](https://github.com/shogo-ishikawa/2026_3Q_M3Th3) へ反映すると、共通の検証と公開処理が実行されます。
