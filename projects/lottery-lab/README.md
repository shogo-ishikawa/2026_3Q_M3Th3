# くじびきラボ

スロット風の演出で、期待値と結果の違いを体験する確率実験です。学生の元モデルと、メーカー公表値へ平均を合わせたモデルを切り替え、収支のばらつきや損失のほかの使い道を比べられます。

**[ブラウザで遊ぶ](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/lottery-lab/)** ／ **[操作マニュアル](docs/manual.md)** ／ **[Python版をColabで開く](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/lottery-lab/lottery_lab.ipynb)**

## まずは引いてみる

1. ブラウザ版を開き、抽選モデルと設定を選びます。初期値は公表値に合わせたモデル・設定1です。
2. 「1回回す」を押します。3つのリールは自動でもSTOPでも止まります。
3. 「いまの結果を、数字で見る」で期待値との差、仮の円換算、同じ条件で5000試行した結果を確認します。

初期ポイントは50点、1回につき3点です。仮想ポイントなので、マイナスになっても指定回数まで続けられます。

## 2つのモデル

- **公式値に合わせたモデル**：BIG・REG確率と1回3 ptの場合の理論出玉率を公表値へ合わせます。ブドウ確率だけを計算で補正した仮定モデルです。
- **学生の簡略モデル**：元の提出作品の確率・配当を保っています。全体の出玉率は実機と異なります。

どちらも実機の完全再現ではありません。補正した小役確率や、結果の分布まで公式の値という意味ではありません。[モデルの計算と出典](docs/probability-models.md)をまとめています。

## 何度も試してみる

- **役を集める**：引いた役がコレクションに残ります。
- **前の結果と比べる**：直近のチャレンジを振り返れます。
- **全設定を比べる**：設定1〜6を繰り返し試し、平均収支と結果の幅を見られます。
- **数字で振り返る**：理論上の期待収支と今回の差、5000試行による結果の珍しさを見られます。
- **お金の使い道を考える**：1 ptあたりの金額を仮定し、差し引きの損失を昼食や本などの予算例と比べます。
- **仕組みを変える**：Python版で確率や配当を書き換えられます。

ブラウザ版はインストールやログインなしで動きます。コレクションと履歴は使っているブラウザに保存します。CSVに出すと結果を手元に残せます。

ダウンロード版はZIPを展開し、`v1.1.0/index.html` をダブルクリックして開けます。
