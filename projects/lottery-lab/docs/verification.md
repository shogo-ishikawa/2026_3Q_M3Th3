# 公開版の確認記録

対象：v1.0.1。確認日：2026年11月10日（日本時間）。

## v1.0.1の更新

Colab冒頭の実装に関する説明を削り、操作手順を中心にしました。公開は共通のGitHub Actionsへ統一し、登録した全作品を同じ成果物へまとめます。ゲーム本体の抽選や保存の処理はv1.0.0を引き継いでいます。

## v1.0.0で確認済みの動作

| 対象 | 確認したこと |
| --- | --- |
| JavaScriptの抽選 | 元作品の確率と配当、累積確率の境界、収支と回数の整合、マイナスポイントでの継続、seedによる再現、1000回での停止 |
| JavaScriptの画面処理 | 実際のapp.jsをDOMスタブで実行。連打時の二重実行防止、完走直後の保存、再読込と再挑戦での履歴保持、設定変更、直近5件、保存できない場合の継続、CSV内容 |
| 比較 | 1試行の結果が通常抽選と一致すること、全試行の集計、プラスの割合、平均推移、設定間で同じ乱数列を使うこと、比較が通常プレイの記録を変えないこと |
| Python | 確率・配当・収支・履歴・負残高・入力検証・再現性・繰り返し比較 |
| Notebook | nbformat検証、全3コードセルの実行、1000回×50試行×6設定の比較、折りたたみ、出力と実行番号が残っていないこと |
| 配布 | 単体HTMLを生成。ZIPの展開先がv1.0.0であることと、ソース・説明書の収録内容を確認 |

JavaScriptは14件、Pythonは5件のテストが合格しました。完走時の履歴保存処理を除いた一時コピーでは回帰テストが失敗することも確認しています。ブラウザ版とPython版は乱数の実装が異なるため、同じseedでの抽選列の一致は検証条件にしていません。

## v1.0.0での確認範囲

実ブラウザによる描画、モバイル画面、効果音、Google Colab実ランタイムは未確認です。この環境の共有プレビューは別作品で使用中のため切り替えず、画面の操作処理はDOMスタブで確認しました。ローカルファイルのブラウザ確認も環境のURL制限で実行できませんでした。

この接続ではGitHub Pages設定へアクセスできないため、初回公開には管理者によるPagesの設定が必要です。設定方法は開発ガイドに記載しています。

## 公開するデータ

提出Notebookと発表資料は作品の意図を確認するために参照しました。氏名、学籍番号、添付元のファイル名、実行出力は公開ファイルへ含めていません。ブラウザで集めた役と集計結果は、そのブラウザ内だけに保存します。外部への送信処理はありません。
