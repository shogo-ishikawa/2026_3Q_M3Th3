# くじびきラボ 操作マニュアル

**[ブラウザ版を開く](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/lottery-lab/)**

## 最初の1回

設定を選び、「くじを引く」を押してみましょう。引いた役と獲得ポイントが表示されます。手早く進めたいときは「10回」「100回」を使えます。

最初は50点を持ち、1回引くごとに3点を使います。例えばブドウなら8点もらえるので、その回は差し引き5点増えます。仮想ポイントを使う実験なので、マイナスになっても続けられます。

## 1000回チャレンジを繰り返す

1000回まで引くと結果を履歴に保存します。「もう一度遊ぶ」か「新しく始める」を押し、同じ設定でもう一度試してみましょう。途中でやり直すこともできます。設定を変えた場合も、その時点の結果を残して新しいチャレンジが始まります。

| 見るもの | 分かること |
| --- | --- |
| 所持ポイント | 今持っているポイント |
| 収支 | 初期ポイントからどれだけ増減したか |
| ポイント推移 | どのあたりで増減したか |
| 当選回数 | それぞれの役を何回引いたか |
| コレクション | これまでに引いた役 |
| 前のチャレンジ | 直近の結果との違い |

コレクションと直近5回の履歴は、このブラウザに保存します。途中のくじを再開する機能はないので、途中の結果も残したいときは「新しく始める」かCSV保存を使ってください。別の端末やブラウザへは引き継がれません。ブラウザの保存データを削除すると記録も消えます。

## 全設定を比べる

比較画面では、設定1〜6を同じ条件で繰り返し試せます。まずは「1000回のくじ引きを50試行」のまま実行してみましょう。

| 表の項目 | 読み方 |
| --- | --- |
| 平均収支 | 各試行の収支を足し、試行数で割った値 |
| 最小〜最大 | 今回の試行で出た収支の最小値・最大値 |
| プラスの割合 | 最終収支が0より大きかった試行の割合 |
| 理論上の平均収支 | 当選確率と配当から計算した平均 |

同じ試行番号では、全設定に同じ乱数列を使います。設定による確率の違いを比べやすくするためです。ブラウザ版は「比べてみる」を押すたび、新しい乱数で実験します。Python版では乱数の種（seed）を指定し、同じ結果を再現できます。

平均が高い設定でも、1回のチャレンジで必ずポイントが増えるわけではありません。最小〜最大も今回の結果の幅です。試行数を変えて、もう一度比べてみましょう。

## 音・確率表・保存

音は切り替えボタンでオン・オフにできます。音が不要な場所ではオフのままで遊べます。

確率表では、設定ごとの当選確率と配当を確認できます。抽選は毎回独立です。しばらく当たらなくても、次の1回の確率が上がる仕組みではありません。

結果を残したいときは「今回の記録をCSVに」を押します。表計算ソフトでも開けます。

## Pythonで仕組みを試す

**[Colabで開く](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/lottery-lab/lottery_lab.ipynb)**

Googleアカウントでログインし、セル1 → セル2の ▶ を順に押します。セル3では全設定を繰り返し比較できます。追加インストールやGPUは不要です。

| 入力欄 | 変わること |
| --- | --- |
| `setting` | 抽選に使う設定。1〜6 |
| `games` | 何回引くか。1〜5000 |
| `initial_points` | 最初に持つポイント |
| `play_cost` | 1回引くために使うポイント |
| `seed` | 乱数の種。同じ値なら同じ結果 |

条件を変えたら、そのセルをもう一度実行します。違う結果を見たいときはseedを変えてください。

リンクからそのまま実行できます。変更したコードや設定を次回も残したい場合だけ「ファイル → ドライブにコピーを保存」を選びます。コピーには公開版の更新は自動反映されません。

ブラウザ版とPython版では乱数の作り方が異なるため、同じseedでも結果は一致しません。当選確率と配当は共通です。

## 困ったとき

| 状況 | 次にすること |
| --- | --- |
| ポイントがマイナスになった | 元作品と同じく、指定回数まで続ける実験です。そのまま遊べます |
| 同じ条件なのに結果が違う | 当選は乱数で決まります。Python版で再現したいときはseedもそろえます |
| コレクションや履歴が残らない | ブラウザの保存制限やプライベート閲覧を確認。残したい結果はCSVで保存します |
| Colabで変数がないと言われる | セル1を実行してからセル2・3へ進みます |
| Colabで設定を変えても結果が変わらない | 入力欄を変えた後、そのセルの ▶ を押します |
