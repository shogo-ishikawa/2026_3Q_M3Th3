# 開発方針案

この文書は実装前の検討記録です。初版ではWebを解説と短い聴き比べに絞り、音源分離・分析・加工はColabにまとめました。現在の機能と操作は[README](../README.md)と[使い方](manual.md)を参照してください。

## 目標

「音が高い」「明るい音色」「音が大きい」という表現を、聴き比べとグラフを使って区別できる教材にします。元作品の音源分離・周波数分析を引き継ぎ、聴いた音と表示結果が対応する操作を中心にします。

発表にあった「歌声よりドラムのスペクトル重心が高かった」という結果は、教材の入口に向いています。ただし、保存された結果を確認した段階で、同じ音源を再解析した結果ではありません。打楽器の高周波成分や分離結果を実際に聴き、理由を調べられる構成を目指します。

## 検討した方向

| 方向 | 利点 | 初版での扱い |
| --- | --- | --- |
| 音色を聴き比べる音響実験室 | 元作品の発見を中心に、利用者自身が条件を変えて確かめられる | 主題にする |
| 音源分離とミキサー | 曲を分解して聴く楽しさがあり、操作の入口になる | 観察するための機能として使う |
| ノイズ抑制・音の加工 | 処理による変化と副作用を比較できる | 発展実験にする |

既存のAI作曲アレンジが伴奏を作り変える作品であるのに対し、こちらは音色と周波数成分の観察を受け持ちます。曲のよさ、好み、ジャンルを数値だけで自動判定する機能は初版に含めません。

## 入口にするデモ

最初は音源ファイルやモデルを準備しなくても試せるようにします。

| デモ | 変えるもの | 予想する変化 |
| --- | --- | --- |
| 440 Hzの純音と、同じ基本周波数に倍音を加えた音 | 倍音の量 | 基本周波数が同じでも音色とスペクトル重心が変わる |
| 同じ波形を弱く・強くした音 | 振幅 | 波形の大きさが変わり、スペクトル重心はほぼ変わらない |
| ベース風・打楽器風の合成音を混ぜた音 | 各パートの音量とミュート | 曲を支える低い成分と、明るく聞こえる成分を聴き分ける |

設計の確認として、1秒・44.1 kHzの440 Hz純音と、440・880・1320 Hzを振幅比1:0.5:0.25で混ぜた音を計算しました。RMSをどちらも0.1にそろえた全区間の振幅スペクトルでは、重心はそれぞれ440.0 Hzと約691.4 Hzになりました。これは合成条件を確認する計算で、元の楽曲の解析結果や聴覚実験ではありません。実装時の短時間分析では窓関数などによる差も扱います。

## 音楽を使う実験

1. デモまたは利用条件を確認した手元の音源を読み込みます。
2. 原曲の好きな区間を選び、音を聴きます。
3. ColabではDemucsでパートに分け、同じ区間で原曲と各パートを切り替えます。
4. 音と対応する波形、周波数スペクトル、スペクトログラム、重心の時間変化を見ます。
5. 必要ならフィルターなどを適用し、加工前後を同じ区間で聴き比べます。

Web版は軽い合成音と可視化を入口にします。Demucsの実行はColabに置き、重いモデルの準備をしなくても基本の体験ができるようにします。元作品にあるYouTube取得はColab側の入力候補として残しますが、デモと音声ファイルだけでも一連の操作が完了する構成を基本とします。取得の失敗や利用条件は、解析結果とは分けて案内します。

## 表示する指標

| 表示 | 初学者向けの意味 | 解釈で守ること |
| --- | --- | --- |
| 波形 | 音の振れ幅が時間とともにどう変わるか | デジタル値の振幅。校正された音圧や聴感上の大きさと同一視しない |
| 周波数スペクトル | 低い成分・高い成分がどの程度含まれるか | 振幅スペクトルかパワースペクトルかを明記する |
| スペクトログラム | それぞれの周波数成分がいつ現れるか | 同じ区間・周波数範囲・色の基準で比較する |
| スペクトル重心 | 周波数成分の分布の重心。音色の明るさに関わる指標 | 音名や基本周波数の測定値として扱わない |
| RMS | 波形の大きさの目安 | 再生用の音量調整と解析用の値を分ける |

基本周波数の推定を追加する場合は、純音や単独の歌声など、扱える対象を限定します。ドラムや複数音が重なった音へ機械的に1つの音名を付ける構成にはしません。

## 比較を成立させる条件

- 原曲とパートは同じ時間軸・同じ区間で再生し、前後の操作で位置をそろえます。
- 無音や微小な分離成分を平均に含める規則をそろえ、有効な時間の割合も示します。パートごとの無音を切り詰めて位置がずれる処理は行いません。
- 解析する周波数範囲とグラフの表示範囲をそろえます。平均だけでなく時間変化や分布も見られるようにします。
- 指標の計算は加工前を基本とします。試聴用の音量合わせや各パートの保存時の倍率を、解析値や元の音量比に混ぜません。
- 分離結果はAIの推定であり、ほかの音の混入や人工的な成分が残る可能性を表示します。
- 簡易ゲートは任意の加工とし、余韻や弱い楽器音が消える変化も比較します。重心が上がったことを品質向上の根拠にしません。

## 分離モデルと初版の範囲

標準はボーカル・ドラム・ベース・その他の4パートです。「その他」を伴奏全体とは呼びません。伴奏全体を再生する場合は、ボーカル以外のパートを合成して示します。

6パートモデルはギター・ピアノを追加する発展候補です。Demucs公式は6パート版を実験的なモデルとし、ピアノの分離について混入や人工的な成分を指摘しています。6本のグラフを並べること自体を初版の目標にしません。

最初の完成条件は、デモを読み込んで同じ区間を聴き比べ、耳で感じた違いと周波数の違いを対応させられることです。続いてColabのファイル入力と4パート分離を整えます。一般公開する段階では、操作説明・デモ・保存内容・個人情報除去を確認します。
