# 音の実験室（構想）

音源をパートに分け、耳で聴いた印象と周波数のグラフを比べる教材を計画しています。学生作品にあった「歌声よりドラムのスペクトル重心が高かった」という発見を出発点にします。

目標は、音の高さと音色の明るさの違いを、自分で音を変えながら確かめられることです。同じ高さでも倍音を加えると音色が変わる例から始め、実際の音楽へ進みます。

## 利用者が試すこと

| 実験 | 確かめること |
| --- | --- |
| 同じ高さの音に倍音を加える | 音の高さと音色の違い |
| 原曲と分離したパートを聴き比べる | 声・ベース・ドラムなどに含まれる周波数成分 |
| 同じ曲の区間やパートを切り替える | 波形・スペクトル・音の明るさがいつ変わるか |
| フィルターや簡易ゲートの前後を比べる | 音の加工で残るもの、失われるもの |

## Web版とColab版の役割案

| 版 | 主な役割 |
| --- | --- |
| Web版 | 合成音やデモをすぐ聴き、つまみの操作とグラフの変化を確かめる |
| Colab版 | 手元の音源をDemucsで分離し、同じ区間を詳しく比較する |

初版は合成音の聴き比べと4パート分離を中心にします。6パート分離とノイズ抑制の比較は発展機能の候補です。
