# 音の実験室

同じ高さの音でも、丸く聞こえたり、明るく聞こえたりするのはなぜでしょうか。音を聴き、波形や周波数のグラフを見比べる教材です。

学生作品にあった「歌声よりドラムのスペクトル重心が高かった」という発見を出発点に、**音の高さ・音色の明るさ・音の大きさ**を区別して考えます。

**[Colabで実験する](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/sound-analysis-lab/sound_analysis_lab.ipynb)** ／ [Webで音の見方を知る](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/sound-analysis-lab/) ／ [使い方](docs/manual.md) ／ [コード一式（ZIP）](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/sound-analysis-lab/dist/sound-analysis-lab_v1.0.0.zip)

## まずは合成音で試す

音源を用意しなくても、正弦波（tone）・倍音（harmonics）・合成バンド（band）のデモから始められます。音の高さを保ったまま倍音を増やし、耳で感じた音色とスペクトル重心の変化を確かめてみましょう。

| 版 | できること |
| --- | --- |
| Web版 | 波形や周波数の見方を読み、合成音の倍音を変えて聴き比べる |
| Colab版 | デモや自分の音源を読み込み、パートの分離、グラフ、同じ区間の試聴、加工前後の比較を行う |

Web版は音の見方を知る入口です。曲を使った分析はColabで進めます。

## Colabの6つのセル

| セル | 操作 |
| --- | --- |
| 1 | 必要なライブラリを準備する |
| 2 | デモ・手元の音声ファイル・YouTubeから入力し、全体または区間を選ぶ |
| 3 | パートを用意する。合成デモは既知のパートを使い、実音源は必要に応じてDemucsで分離する |
| 4 | 波形・平均スペクトル・スペクトログラム・重心とRMSの時間変化を見て、同じ区間を聴く |
| 5 | ローパスフィルターや簡易ゲートを任意で適用し、前後を比べる |
| 6 | 図・表・分析条件をZIPで保存する |

最初はデモのまま上から実行してください。実音源の分離にはモデルの取得と計算時間が必要です。GPUを使える場合はColabのランタイム設定で選べますが、CPUでも分離できます。

## この教材で大切にすること

スペクトル重心は、周波数成分の分布を表す指標です。歌っている音名や基本周波数そのものではありません。高い周波数の成分が多い打楽器の重心が、歌声より高くなることもあります。

原曲・パート・加工前後は同じ区間と音量基準で比べます。AIによる分離は推定なので、別の楽器の音が混ざったり、元にない成分が生じたりします。簡易ゲートも音を変える加工であり、必ずきれいになる処理ではありません。

YouTubeからの取得機能は残していますが、配信側の変更や接続制限で使えない場合があります。デモと手元の音声ファイルだけでも一連の実験を進められます。利用する音源の条件は配布元で確認してください。

保存ZIPには図・CSV・分析条件を入れます。音声は追加を選んだ場合だけ含め、入力URLや元ファイル名は分析結果へ記録しません。詳しい指標と比較条件は[測定値の読み方](docs/model-notes.md)を参照してください。
