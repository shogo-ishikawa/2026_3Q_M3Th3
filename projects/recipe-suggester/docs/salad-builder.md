# 材料を選んで作るサラダ

対応版：v3.6.0 ／ 確認日：2026年11月13日

「生野菜サラダ（ドレッシングなし）」の詳細では、使う野菜と1皿分の量を選べます。レタスやトマトを独立した料理として共通DBに増やすのではなく、選んだ材料からひとつのサラダを組み立てます。従来のサラダやドレッシング付きメニューも引き続き選べます。

## 野菜と量の選び方

野菜は1種類以上選び、食べる可食部の量をgで入力します。ごみになる部分や器の重さは含めません。

| 選べる野菜 | 入力する量の状態 |
| --- | --- |
| レタス | 生で洗って水気を切った可食部 |
| キャベツ | 生で洗って水気を切った可食部 |
| きゅうり | 生で洗って水気を切った可食部 |
| トマト | 生で洗って水気を切った可食部 |
| にんじん | 生の皮を除いた可食部 |
| 紫キャベツ | 生で洗って水気を切った可食部 |
| ブロッコリー | 塩を加えずにゆで、湯切りした後の花序 |

ブロッコリーは既存の生の材料と区別して登録しています。生の重量を、ゆでた後の欄に入力しないでください。電子レンジ調理や油炒めの値も同じではありません。

野菜を選ばないままドレッシングだけを登録することはできません。1種類は1000g以下、野菜の合計は2000g以下に制限します。

## ドレッシング

なし、和風、フレンチ、レモンオイル、ごま、マヨネーズから選びます。「なし」以外は使う量をgで入力します。下記は配合を示す基準で、そのまま1皿へ全量を入れる意味ではありません。選んだg数に合わせて各材料を同じ倍率で増減します。

| 種類 | 家庭用配合の基準 | 最初に表示する量 |
| --- | --- | ---: |
| なし | 調味料を加えない | 0g |
| 和風 | しょうゆ5ml、米酢5ml、植物油3ml、砂糖1g | 15g |
| フレンチ | オリーブ油10ml、米酢10ml、砂糖1g、塩0.5g、黒こしょう0.05g | 15g |
| レモンオイル | オリーブ油6ml、レモン汁6ml、塩0.3g、黒こしょう0.05g | 12g |
| ごま | すりごま4g、マヨネーズ5g、しょうゆ3ml、米酢4ml、砂糖1g、水2ml | 20g |
| マヨネーズ | マヨネーズ | 10g |

ドレッシングは300g以下に制限します。完成した市販ドレッシングの商品表示を一律に使う仕組みではありません。実際に市販品を使った場合は、手入力のメニューで商品表示に合わせて記録できます。

## 記録・栄養・買い物

選んだ材料とドレッシングの全量が「1皿」です。その半分を食べた場合は、記録する量を0.5皿とします。材料のg数を減らすことと、食べた皿数を減らすことを重ねて行うと二重に減るので、どちらかで調整してください。

栄養は選んだ材料から6成分を計算します。ドレッシングを変更すると、調味料由来のエネルギーや食塩、登録アレルゲンも変わります。不明な栄養値は0に置き換えません。例えばレモン汁に含まれる微量の食物繊維は、このDBでは不明のままです。

組み合わせは今回の記録だけに使うことも、自分のメニューとして保存することもできます。保存したマイメニューは通常の材料・アレルギー条件で判定されます。アプリが持つ食材の情報に基づく判定であり、製造や調理中の混入を保証するものではありません。

記録には選択時点の材料、量、栄養、作り方を保存します。後で別の組み合わせを作っても、過去のサラダの内容は変わりません。予定として登録した場合は、買い物の人数を掛けた必要量を集計し、在庫を差し引きます。ゆでブロッコリーの買い物量も調理済み可食部の重量です。

## 成分値と重量換算

生野菜と調味料は既存の食材プロフィールを使います。新しいゆでブロッコリーは文部科学省の[食品番号06264「ブロッコリー・花序・ゆで」](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=6_06264_7)を参照しました。可食部100g当たりは30kcal、たんぱく質3.9g、脂質0.4g、炭水化物5.2g、食物繊維4.3g、食塩相当量0gです。一般成分の欄を使い、利用可能炭水化物など別の列とは区別します。

mlとgが混在する調味料は、既存プロフィールと同じ重量換算を用います。植物油は1ml=0.913g、オリーブ油は0.910g、しょうゆは1.181g、米酢と水は1gです。レモン汁も既存DBの1ml=1gという近似を引き継ぎます。これにより、和風ドレッシングの基準配合14.644gを15gとして使う場合は、各材料を`15 ÷ 14.644`倍にします。

## コードを変更するとき

`salad-builder.js`の`SALAD_COMPONENTS`に野菜、`SALAD_DRESSINGS`にドレッシングの選択肢を置いています。`buildSaladRecipe(config, data)`は入力を検査し、1人分のマイメニューを返します。画面操作や記録の保存は呼び出し元が担当します。

```js
const recipe = buildSaladRecipe({
  components: [
    {id: 'lettuce', amount: 50},
    {id: 'tomato', amount: 80},
  ],
  dressingId: 'wafu',
  dressingAmount: 15,
}, data);
```

共通DBの野菜や既存レシピを上書きせず、選んだ材料だけを持つ新しい料理を返します。組み合わせを増やす際は、調理前後の重量と成分表の状態、調味料の単位、原料由来のアレルゲンも確認してください。
