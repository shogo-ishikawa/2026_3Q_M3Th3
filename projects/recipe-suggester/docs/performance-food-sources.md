# 飲み物・プロテイン・補食の出典

確認日：2026年11月13日 ／ 対応版：v3.5.0

## 収録したもの

`performance-foods.js`に29品を追加しています。酒類10品、プロテイン飲料5品、清涼飲料水5品、補食9品です。既存の通常のコーラやスポーツドリンクは残し、別の商品例として重ねて追加していません。

酒類は食品成分表の一般値、商品名を記した飲料と補食はメーカー・販売元の公式表示を参照しています。推奨する食事や飲酒量を示す一覧ではなく、実際に飲食したものを記録するための例です。

酒のエネルギーにはアルコール由来の分も含まれるため、たんぱく質・脂質・炭水化物だけから計算し直しません。原表の微量記号と未測定成分は単一点の値にできないものとして`null`、原表の数値0と推定値(0)は0を保っています。

## 料理名と出典の扱い

一覧には店舗名を入れず、テイクアウト・惣菜・市販品・外食などの表記で料理を選べるようにしています。出典には参照した具体的な商品と公式URLを残します。出典の商品を参考にした記録例で、同じ料理でも量や栄養は異なります。料理名を一般的な表記へ変えても、元の基準量と栄養は変更していません。

| アプリの料理名 | 栄養値の参照商品 |
| --- | --- |
| サラダチキン（プレーン・市販品110g） | ローソン サラダチキン プレーン（110g） |
| サラダチキン（ハーブ・市販品110g） | ローソン サラダチキン ハーブ（110g） |
| サラダチキン（スモーク・市販品110g） | ローソン サラダチキン スモーク（110g） |

過去に保存した料理名は記録時点のまま保ち、新たに選んだ料理から現在の表記を使います。

### 範囲表示と商品改定

- ソイ粉末ココア味は食物繊維0.57〜1.51g、食塩相当量0.63〜1.45g、ホエイ粉末リッチショコラ味は食塩相当量0.31〜0.76gという表示です。範囲の中央や上限を採用せず、該当成分は不明にしています。
- ベイクドチョコ、ベイクドビター、1本満足バーなども、範囲表示の成分を同様に扱います。
- ザバスの200ml乳飲料は食物繊維0〜0.7gのため不明です。清涼飲料水の食物繊維は表示がなく、0へ補いません。
- カナダドライは確認時の製品ページの表示を使います。過去のニュースリリースや他容量の古い数値を組み合わせません。
- 名称が同じでも原材料や栄養は変わる場合があります。購入した商品の表示が違うときは手入力で登録します。

## 粉末と完成した飲料の量

ソイ・ホエイの粉末は28gに水200mlを加える例と、普通牛乳200mlを加える例を分けています。牛乳割は粉末の表示値に既存の普通牛乳の成分表換算値を加えます。粉末の範囲表示がある成分は、牛乳の量が分かっていても合計を不明のまま残します。200mlはこの記録例の割り材量で、商品の推奨配合や完成容量を示すものではありません。

粉末と液体を合わせた容量は量っていないため、これらは1杯で入力します。200ml入りの既製プロテイン飲料は表示された液量で入力できます。

## 購入する単位と食べる量

バーは1本、サラダチキンは110g入り1袋、ゼリーは215g入り1袋を基準にします。カロリーメイトのブロックは4本80g入り1箱を購入品として持ち、画面では4本を基準にします。2本と入力すると栄養は半分、買い物では0.5箱分です。袋や箱を自動で整数へ切り上げる処理ではありません。

購入品の素材IDは完成品を表します。バーを原料のチョコレートや大豆へ分解したり、サラダチキンを生の鶏肉へ置き換えたりして買い物に加えません。粉末の調製例だけは購入する粉末gと割り材mlを別に持ちます。

## 原材料と確認状況

商品に付けた原材料の説明は、公式ページで確認できる主な原料や注意点の要約です。全原材料をアプリの食材辞書へ登録したものではありません。サラダチキンは公式の商品説明と栄養表示を参照し、全原材料が掲載されていない部分を推測して補っていません。アレルゲンの参考一覧も全品目の保証には使いません。

これらの例は`allergensKnown: false`、`ingredientsKnown: false`で、利用者が持つ商品の原材料を確認済みとは扱いません。買う商品と量が分かるため`shoppingKnown: true`を持ち、買い物へは数量を反映しつつ確認の注意を残します。酒類はこの確認状況とは別に、お酒の分類を基に自動献立から外します。

商用商品の食材単体の栄養は`null`とし、メニューの`manualNutrition`に確認した表示値を置いています。基準量から食べた量への倍率は既存の計算を使います。原材料が分かること、栄養の表示が分かること、買い物の数量が分かることを別に扱うためです。
