## 食材とアレルゲン

消費者庁の資料を、選択肢と説明の参考にしています。

- [食物アレルギー表示に関する情報](https://www.caa.go.jp/policies/policy/food_labeling/food_sanitation/allergy/)
- [アレルゲンを含む食品に関する表示について（2026年4月1日）](https://www.caa.go.jp/policies/policy/food_labeling/food_sanitation/allergy/assets/food_labeling_cms204_260401_03.pdf)
- [食品表示基準Q&A・2026年4月1日改正の新旧対照表](https://www.caa.go.jp/policies/policy/food_labeling/food_labeling_act/assets/food_labeling_cms201_260401_33.pdf)

2026年4月の改正で、カシューナッツが表示義務の対象へ移り、ピスタチオが表示推奨の対象に加わりました。アプリの選択肢は、表示義務の対象9品目と表示推奨の対象20品目の計29品目を参考にしています。

| 区分 | 品目 |
| --- | --- |
| 表示義務の対象 | えび、カシューナッツ、かに、くるみ、小麦、そば、卵、乳、落花生 |
| 表示推奨の対象 | アーモンド、あわび、いか、いくら、オレンジ、キウイフルーツ、牛肉、ごま、さけ、さば、大豆、鶏肉、バナナ、ピスタチオ、豚肉、マカダミアナッツ、もも、やまいも、りんご、ゼラチン |

表示制度の対象以外にも、食物アレルギーの原因になる食品はあります。アプリの29品目を、すべての原因食品を網羅する一覧としては扱いません。登録済みの個別食材も追加で除外できます。

アプリの食材辞書は、ここで使うレシピの材料と調味料を整理したものです。市販品の原材料データベースや検査結果ではありません。加工食品・調味料は商品によって配合が異なるため、実際に使う商品の表示と調理環境を確認してください。

## 食品群と食事の記録

- 農林水産省：[「食事バランスガイド」の適量と料理区分](https://www.maff.go.jp/j/syokuiku/kenzensyokuseikatsu/about_b_guide.html)
- 農林水産省：[「食事バランスガイド」について](https://www.maff.go.jp/j/balance_guide/index.html)

主食・副菜・主菜・牛乳／乳製品・果物という区分を、食事を振り返る際の参考にしました。アプリ内の集計はグループが登場した回数であり、公式資料の「つ（SV）」の計算とは異なります。

栄養素・エネルギー・塩分の計算や、個人の必要量に応じた献立の最適化は行いません。記録された範囲で、料理と食材の種類が偏っていないかを考える補助として使います。

## レシピと調理手順

材料・分量・手順は、この教材用に整理した家庭料理の例です。特定のレシピサイトの文章や写真を転載したものではありません。調理時間は目安で、試作して得た実測値ではありません。

レシピを増やすときも、材料と手順の対応、調味料を含む食材情報、人数を変えた分量を確認します。食材や市販品を置き換える場合は、表示されている登録情報をそのまま当てはめないでください。
