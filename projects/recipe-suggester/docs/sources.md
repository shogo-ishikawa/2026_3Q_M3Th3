# 出典とデータの考え方

更新日：2026年11月13日 ／ 対応版：v3.3.0

## 出発点になった学生作品

- [AI献立スマートシェフ（学生の公開アプリ）](https://cish25155-prog.github.io/SmartChef/)
- 提出された作品と発表資料、および「レシピも見たい」「これまでに食べた内容を参考に提案してほしい」という意見

Meal Palette（旧・献立ノート）は学生の着眼点を引き継ぎ、教員が公開教材として機能を追加した版です。ジャンルや除外条件を使う献立づくりに加え、食事カレンダー、概算栄養、数量在庫、手入力メニューなどを実装しています。学生の元の公開版へのリンクも残しています。

提出資料に含まれる氏名・学科・学籍番号や、個人の食事記録を公開用のレシピデータへ移していません。アプリを使う人が登録する記録やマイDBはブラウザー内に保存します。

## 食材とアレルゲン

消費者庁の公式資料を選択肢と説明の参考にしています。

- [食物アレルギー表示に関する情報](https://www.caa.go.jp/policies/policy/food_labeling/food_sanitation/allergy/)
- [アレルゲンを含む食品に関する表示について（2026年4月1日）](https://www.caa.go.jp/policies/policy/food_labeling/food_sanitation/allergy/assets/food_labeling_cms204_260401_03.pdf)
- [食品表示基準Q&A・2026年4月1日改正の新旧対照表](https://www.caa.go.jp/policies/policy/food_labeling/food_labeling_act/assets/food_labeling_cms201_260401_33.pdf)

2026年4月の改正でカシューナッツが表示義務の対象へ移り、ピスタチオが表示推奨の対象に加わりました。アプリは表示義務の対象9品目と表示推奨の対象20品目の計29品目を参考にしています。

| 区分 | 品目 |
| --- | --- |
| 表示義務の対象 | えび、カシューナッツ、かに、くるみ、小麦、そば、卵、乳、落花生 |
| 表示推奨の対象 | アーモンド、あわび、いか、いくら、オレンジ、キウイフルーツ、牛肉、ごま、さけ、さば、大豆、鶏肉、バナナ、ピスタチオ、豚肉、マカダミアナッツ、もも、やまいも、りんご、ゼラチン |

表示制度の対象以外にも原因食品はあります。29品目で食物アレルギーを網羅するとは考えず、登録済みの食材を追加で除外できるようにしています。

食材辞書は教材のレシピに使う材料と調味料を整理したものです。市販品の原材料DBや検査結果ではありません。加工品の原料関係は`derivedFrom`で示し、除外判定では原料とアレルゲンを引き継ぎます。栄養値の似た食品からアレルゲンを推定することはありません。

商品の配合や製造・調理環境は登録情報と異なる場合があります。実際に使う商品の表示と調理環境も確認してください。

## 栄養値と比較の目安

食材の栄養値には文部科学省の「日本食品標準成分表（八訂）増補2023年」を使い、代表食品の値をアプリのg・ml・個などの単位に換算しています。食品番号との対応、更新版の出典、体積から重量への換算、不明値の扱いは[栄養値の出典と換算方法](nutrition-sources.md)にまとめています。

料理の概算は`食材1単位の栄養 × 材料の数量 ÷ レシピの基準人数`を合計して求めます。カレンダーは1人分を基準に食べた量を掛け、買い物は予定の材料を指定人数分にまとめます。

食べた料理の分析値ではありません。品種、部位、商品の配合、調理方法、計量の違いなどで結果は変わります。手入力した商品表示などの値を使うこともできます。不明な成分は`null`として残し、0に置き換えません。

比較の目安には、厚生労働省の[「日本人の食事摂取基準（2025年版）」](https://www.mhlw.go.jp/stf/newpage_44138.html)を使います。18歳以上の年代、基準表の性別区分、活動量を利用者が選んだ場合に、参照体位に対する参考値を作ります。公式表の値と比率からの換算、対象外の組み合わせは[食事摂取基準の出典](dietary-reference-sources.md)にまとめています。

手動の比較値も利用できます。その初期値は表示を試すための参考値で、個人に必要な摂取量を求めたものではありません。妊娠・授乳中、18歳未満、治療用の自動設定は扱いません。

記録完了の確認が済んだ日を最近の平均に使い、不明な成分がある日はその成分の平均から除きます。成分ごとの対象日数を示し、未記録の食事を0と推測しません。提案は記録を参考にした順位付けで、全成分を満たす厳密な最適化や栄養状態の診断ではありません。

## 食品群と食事の記録

- 農林水産省：[「食事バランスガイド」の適量と料理区分](https://www.maff.go.jp/j/syokuiku/kenzensyokuseikatsu/about_b_guide.html)
- 農林水産省：[「食事バランスガイド」について](https://www.maff.go.jp/j/balance_guide/index.html)

主食・副菜・主菜・牛乳／乳製品・果物という区分を、料理の組み合わせを振り返る参考にしました。アプリの食品群や登場回数は公式資料の「つ（SV）」の計算とは異なります。栄養集計は別途、食材の成分と数量から計算します。

集計するのは「食べた」として登録した食事です。「これからの予定」は摂取量に含めません。DBから料理を削除した場合も過去の記録が残るよう、記録時点の栄養・材料・作り方を保存します。

## レシピと調理手順

収録メニューは711品、材料と調味料は268種類です。v3.1.0では定番の主菜・小鉢と市販食品の記録例を159品、v3.2.0では食堂や外食でもなじみのある定番87品を追加しました。v3.3.0では軍艦と巻物15品、酒・飲み物・補食の記録例29品を加えています。既存IDと保存済みの食事は引き継ぎます。

学食、食堂、レストラン、居酒屋などの公式メニューから、料理の種類や構成で足りない部分を確認しました。参照先と反映方針は[メニューの調査と分類](menu-research.md)にまとめています。一般的な料理名を参考にしたもので、店舗の分量や栄養値を写したDBではありません。

メニューの材料・分量・手順は教材用に整理した料理の例です。特定のレシピサイトの文章や写真を転載していません。家庭で作る例に加え、菓子や肉まんなど一般的な調理済み食品の記録例も用意しています。店舗やメーカーの固有商品を分析したデータではありません。

ご飯とおにぎりは別の大分類にし、麺、パスタ、カレーライス、ピザ、チャーハン、飲み物、みそ汁、間食も種類ごとに探せるよう整理しています。v3.2.0では主菜・副菜を「食材カテゴリ → 調理法 → 個別メニュー」で探せるようにしました。唐揚げや刺身を最上位へ並べず、肉や魚介などの食材からたどります。枝豆や冷奴、ひじき煮、サラダ、煮物なども副菜の食材と調理法から選べます。複数の食材カテゴリから同じ料理へ進める場合も、一覧のメニューは重複させません。v3.2.0の階層整理では既存のレシピID、分量、栄養と保存形式を保ちました。v3.3.0は寿司の新規記録の基準量を整理しますが、過去の食事の量や栄養は記録時点の内容を保持します。追加品はソースに表示用の食材カテゴリ・調理法を持たせ、保存済みの食事を書き換えずに探せるようにしています。基準の1人分と表示量を持ち、入力したg・ml・個数などを栄養と材料の倍率へ換算します。

v3.3.0の調理法は、唐揚げ、フライ、カツ、コロッケなどを「揚げ物」へまとめます。食材から調理法へ進み、個別の料理名で選ぶ流れは保ちます。寿司は握りと軍艦を1貫、細巻と太巻を切った1切れ、盛り合わせを1皿として区別します。材料は酢飯や海苔、調味料も含む家庭向けの例です。

料理の種類や食材カテゴリ、調理法、和食・洋食などのジャンル、手作り・即席・レトルトなどの調理や提供の形態は別に管理します。調理や提供の形態は、栄養面の評価やアレルギー情報の確認状況を示すものではありません。お刺身は魚介や部位の違いを分け、刺身用と加熱用の登録も区別しています。

カップ麺やレトルト食品は、銘柄を指定しない記録例です。レトルトのカレーライスや丼にはご飯を含め、具だけの登録と混同しないよう名称と基準量を示しています。市販品の栄養には食品成分表の代表値、または明示した参考配合からの概算を使います。特定商品の栄養や全原材料を確認したデータではありません。詳しい対応は[栄養値の出典](nutrition-sources.md)にまとめています。

プロテイン、清涼飲料水、補食の商品例ではメーカーの公式表示を参照し、商品名、味、基準量、出典URL、確認日を残しています。具体的な参照先は[酒・飲料・補食の出典](performance-food-sources.md)をご覧ください。これは商品の栄養表示を記録に使う例で、全原材料を収録したDBではありません。範囲で示される成分や不明値は単一点へ置き換えず、商品変更時は購入した包材の表示を優先します。

ソイとホエイ、粉末と調製済み飲料を分け、水割りと牛乳割りは別に扱います。牛乳割りには牛乳の栄養とアレルゲンを加えます。粉末のgを液体のmlへ加えて完成容量とせず、配合を1杯の基準にします。酒の一般例は食品成分表を使い、飲んだ量の記録専用として献立の候補へ入れません。

原材料やアレルギー情報が未確認の市販品は自動提案から外しますが、食べたものとして記録できます。買う商品の構成が分かる場合は買い物にも反映し、ハンバーガーなどは完成品の個数で集計します。原材料の確認が必要な旨は残すため、商品量が表示されたことをアレルギー情報の確認済みと解釈しないでください。

調理時間は目安で、試作による実測値ではありません。調理済み品の温め方や盛り付け手順は、原材料から作る完全なレシピとは区別しています。

レシピを増やすときは材料と手順の対応、調味料を含む情報、計量する食品の状態を確認します。使う商品や食材を置き換えた場合に、登録済みの栄養やアレルゲンをそのまま当てはめないでください。

## Colab教材との関係

`meal_planner.ipynb`はレシピや食材をリスト・辞書で扱い、条件によって候補を絞るPythonの基礎教材です。カレンダー、栄養のグラフ、マイDB、数量在庫など、ブラウザー版の全機能を再現するものではありません。

`recipe_suggester.ipynb`は20品のレシピと参考価格を使う初期教材として残しています。任意の生成AIモードを含む説明もその教材に対応しており、ブラウザー版の機能や検証結果とは分けて記載します。
