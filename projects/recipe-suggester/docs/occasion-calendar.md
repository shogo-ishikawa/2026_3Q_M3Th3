# 献立の日付と家族の行事

献立の「旬の食材や行事の料理を優先する」がオンのとき、献立の日付に合う料理を夕食に提案します。夕食を献立に含めない日は昼食が対象です。「家族の記念日・行事を登録」で、実際に祝う日と行事を選べます。「毎年同じ月日に祝う」は初回の日付以降の同じ月日に適用されます。2月29日の登録はうるう年の2月29日に適用します。

| 行事 | 献立で使う日 |
| --- | --- |
| お正月、成人の日 | 1月1～3日、1月の第2月曜日 |
| バレンタイン、ひな祭り、ホワイトデー | 2月14日、3月3日、3月14日 |
| 卒業祝い、入学祝い | 3月、4月1～15日は季節の候補として少し優先。学校・家庭の実際の式日は個別に登録 |
| こどもの日、七夕 | 5月5日、7月7日 |
| 海の日、山の日 | 7月の第3月曜日、8月11日。山の日は2016年から。2000～2002年の海の日は7月20日。東京大会のため移動した2020年と2021年は実際の祝日 |
| お盆 | 8月13～16日。7月盆など地域ごとの日付も登録可能 |
| 敬老の日、ハロウィン、クリスマス | 9月の第3月曜日（2000～2002年は9月15日）、10月31日、12月24～25日 |
| 誕生日、家族の記念日 | 誕生日は栄養設定とは独立して登録可能。記念日は実際に祝う日を献立で指定 |

祝日は元の日付を使い、振替休日に同じ行事を重ねて追加する処理は行いません。学校行事の提案期間、お盆とクリスマスの期間は献立のための設定です。登録した行事と誕生日、暦の行事が重なる場合はすべて表示し、料理選びでは登録した行事、誕生日、暦の行事の順で対応する料理を探します。[内閣府「国民の祝日について」](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)・[国立天文台「暦要項 備考」](https://eco.mtk.nao.ac.jp/koyomi/yoko/appendix.html)

## 毎年日付が動く行事

節分、春分の日、秋分の日、十五夜の自動提案は2020～2036年を収録しています。対応範囲外でも「家族の記念日・行事を登録」で祝う日を指定できます。

- 節分は日本時間で立春の前日です。2025年は2月2日、2026年は2月3日です。[国立天文台「節分の日が動き出す」](https://eco.mtk.nao.ac.jp/koyomi/topics/html/topics2021_2.html)・[二十四節気・雑節 長期版](https://eco.mtk.nao.ac.jp/cgi-bin/koyomi/cande/phenomena_sy.cgi?year=2033)
- 春分・秋分には国立天文台の年別表を使っています。将来の年については天文学上の予測日で、祝日は前年に暦要項が公表されて正式に決まります。[国立天文台の春分・秋分の表](https://www.nao.ac.jp/faq/a0301.html)・[暦要項](https://eco.mtk.nao.ac.jp/koyomi/yoko/)
- 十五夜は太陰太陽暦の8月15日です。2026年の十五夜は9月25日で、満月は9月27日です。2033年は解釈により9月8日と10月7日の候補があるため、その年は利用者が実際に祝う日を登録します。[国立天文台「中秋の名月とは」](https://eco.mtk.nao.ac.jp/koyomi/wiki/C3E6BDA9A4CECCBEB7EEA4C8A4CF.html)・[宗像ユリックスプラネタリウムの年別一覧](https://yurix-planetarium.jp/astro/harvest_moon/)

## 同じ料理が続くのを減らす

アレルギー、苦手な食材、選んだジャンルや食事の条件を先に適用します。その範囲で、同じ行事に合う料理が複数ある場合は、過去の食事・予定および提案済みの献立にない料理を先に選びます。一巡したら古い料理から再び候補にします。「料理を替える」でも同じ仕組みを使います。通常の献立でも直近に提案した料理の優先度を下げます。家庭の希望や除外条件によって候補が一品に絞られた場合は、その料理を再び選ぶことがあります。

家族構成にお子さんがいるときは子ども向けの料理、高齢の方がいるときはやわらかく仕上げる料理にも加点します。噛む力や飲み込む力を評価する機能はありません。ご家庭に合った大きさ、固さを選んでください。

家族の行事は本人の食事記録に保存し、メニュー希望の集計には送りません。提案した履歴は料理IDの順序だけを最大2,048品保持します。手動で書き出すJSONは登録した家族の行事も含みます。端末が自動退避する復旧用コピーからは登録した家族の行事を除きます。
