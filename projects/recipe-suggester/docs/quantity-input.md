# 数量の入力と上下操作

対応版：v3.13.0

数量欄は `quantity-input.js` と `quantity-input.css` を使います。`configureQuantityInput` が上下ボタンと上下キーの処理を共通化し、`readQuantityInput` が保存・栄養計算の前に入力を検証します。

- 食品の量は原則1刻み。2.5から上を押すと3.5にし、小数部を保持します。
- 栄養成分や倍率・可食率などの係数は例外として細かいstepを指定できます。
- 空欄、負数、数値以外、指数・16進表記、無限大、上下限外を数量として受け入れません。任意項目で許可した空欄だけをnullへ変換します。
- 選択式の具材の0は、各UIがチェックを外して再計算します。空欄やブラウザーのbadInput状態を0と解釈しません。再選択時は直近の正の量を戻します。
- 貫・個・本などの単位だけで一律に整数限定にはしません。既存の寿司や焼き鳥は半量を許可しており、その入力を保ちます。日数や人数など整数が必要な設定だけを整数として扱います。
- 固定ベースは編集できず、必須材料が欠けた料理や全具材なしの料理は従来の配合検証で保存を止めます。

HTMLのstepを1にすると、手入力の小数にstep mismatchが発生する場合があります。入力欄はstep="any"として、自前のボタン・キーボード処理で増減幅を指定します。参考：[HTML Standard — input](https://html.spec.whatwg.org/multipage/input.html)。

ラベル・disabled・readonly状態、フォームのリセットや初期値復元後の入力検証も共通処理へ含めています。保存済みの数量や栄養は書き換えません。
