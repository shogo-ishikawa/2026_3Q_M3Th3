# 京都の家庭料理と刺身

京都の料理は家庭で作りやすいよう2人分に組み直した。朝に温め直して食べられる小鉢やだし巻きは、朝食と晩酌の両方から探せる。卵春巻きと鶏卵うどんは昼食・夕食に含めた。

| 料理 | 配合と参照した資料 |
| --- | --- |
| 鶏卵うどん | だしにとろみを付けて卵を流し入れ、おろししょうがを添える。1人分はゆでうどん200gと卵1個を使い、つゆを含めて計算した。[京都いいとこウェブ](https://kyoto.graphic.co.jp/blog/archives/27878) |
| 小芋のたいたん | 小ぶりの里いもを薄口しょうゆとだしで炊く。京のえびいもの下ゆでと煮含め方を参考にした。成分値には一般の里いもの可食部を使った。[京都市「えびいも」](https://www.city.kyoto.lg.jp/sankan/page/0000029297.html) |
| 京風だし巻き | 卵とこした合わせだしに薄口しょうゆを加えて焼く。砂糖は加えない。従来の「だし巻き卵」はみりん入りの家庭用配合で引き続き選べる。[農林水産省「だし巻き」](https://www.maff.go.jp/j/keikaku/syokubunka/traditional-foods/menu/dasimaki.html) |
| 京中華の卵春巻き | 薄焼き卵を皮にして豚肉とたけのこ、しいたけを包む。家庭では少なめの油で揚げ焼きにする。油の摂取量は1人約9gを見込んだ。[京都市観光協会「京中華の基礎知識」](https://plus.kyoto.travel/entry/kyoto-chuka) |
| 京風湯豆腐 | 絹ごし豆腐を少量の昆布だしで温め、小ねぎとしょうがを添える。だしと別添えしょうゆの分も含めた。白菜と長ねぎが入る従来の「湯豆腐」と選び分けられる。[外務省『にぽにか』第26号](https://web-japan.org/niponica/pdf/niponica26/no26_ja.pdf) |
| 生麩の田楽・生麩としいたけの炊き合わせ | プレーンな生麩を田楽みそで焼く料理と、しいたけと一緒にだしを含ませる料理を収録した。生麩は水分を含む状態の重量を使う。[農林水産省「京麩」](https://www.maff.go.jp/j/keikaku/syokubunka/traditional-foods/menu/kyo_hu.html) |
| 水菜とお揚げの炊いたん | 油揚げにだしを含ませてから水菜の茎と葉を順に煮る。1人分は水菜約60gと油揚げ15g。[京都市「水菜とお揚げの炊いたん」](https://kyo-kenko.city.kyoto.lg.jp/recipe/7539/) |

## 刺身と盛り合わせ

ネギトロととろたくはご飯を含まない小鉢として登録した。まぐろは1人分60g。刺身用の赤身40gと脂身の代表値を使う中トロ20gが内訳となる。ねぎに加えて、とろたくにはたくあんも入る。市販のまぐろたたきには油脂を加えたものもあり、栄養表示がこの配合と異なる。[キッコーマン「まぐろのとろたく風たたき」](https://www.kikkoman.co.jp/homecook/search/recipe/00056770/) ／ [まぐろたたきの原材料例](https://www.micreed.co.jp/shop/commodity/0000/154812/)

カンパチは脂の少ない背側、スズキは生の可食部を使った。盛り合わせでは魚の切れ数を指定する。ネギトロととろたくは小盛りの目安を1盛り50gとし、量に合わせて魚の重量を変更できる。登録単位はどちらも魚だけの重量で、醤油と薬味は別材料として加算する。

## 新しく登録した食材の栄養値
