# 食事別の料理選び

料理ごとに朝食・昼食・夕食・間食・晩酌のうち自然な食べ方を複数登録しました。「メニュー」では食事区分に「行事・シーン」を組み合わせて料理を探せます。たとえば「朝食」と「世界の料理」を選ぶとメネメンが見つかります。自分の記録では実際に食べた食事を選んでください。

## 調べた資料

朝食の組み合わせと食事の中での役割を整理するときに参照した資料です。

- [農林水産省：食事バランスガイドとは](https://www.maff.go.jp/j/syokuiku/minna_navi/about/)
- [農林水産省：元気な一日のための朝メニュー](https://www.maff.go.jp/j/syokuiku/minna_navi/recipe/healthy.html)
- [農林水産省：ご飯を主食にした朝ご飯](https://www.maff.go.jp/j/syokuiku/minna_navi/recipe/healthy1.html)
- [農林水産省：パンを主食にした朝ご飯](https://www.maff.go.jp/j/syokuiku/minna_navi/recipe/healthy3.html)
- [農林水産省：単身者の方向けのお手軽な朝食例](https://www.maff.go.jp/j/syokuiku/zissen_navi/yun/message2.html)
- [キッコーマン：おすすめ朝食レシピ](https://www.kikkoman.co.jp/homecook/theme/kisetsu/breakfast.html)
- [キッコーマン：パン派・ご飯派の朝ごはん](https://www.kikkoman.co.jp/homecook/letter/0050/)
- [味の素：1週間の朝昼夕の献立例](https://www.ajinomoto.co.jp/company/jp/rd/miraikondate/column/article_019/)

主食に卵や魚などのおかずと野菜を組み合わせる例、パンを中心にする例、乳製品や果物を添える例を参考にしました。昼は丼や麺、サンドイッチなども選べます。夕食は主菜に副菜や汁物を組み合わせます。

資料には朝に炒め物を使う例もあります。したがって、炒め物が朝食として不適切だと一般化したものではありません。このアプリでは利用者からの要望を優先し、えびと卵の炒め物や、もやしとにらの香味炒めなどを朝の自動選択から外しました。

## 全メニューの分類

[全メニューの分類一覧（JSON）](meal-suitability-audit.json)で料理ごとの区分を確認できます。食事区分はアプリでの使い方に合わせた編集上の目安です。各資料で個々の料理の食べる時間を指定しているわけではありません。

| 区分 | 選び方と例 |
| --- | --- |
| 朝食 | ご飯やトーストに合わせやすい卵料理・焼き魚・汁物や、そのまま食べられる果物など。 |
| 昼食 | 麺や丼は一品で選べます。刺身やおかずはご飯と組み合わせられます。 |
| 夕食 | 家庭の主菜や副菜に加え、ねぎま鍋などの具だくさんの鍋も選べます。 |
| 間食 | 果物・菓子パン・菓子類のほか、おにぎりなどの軽食や食事の合間に飲むものを含みます。 |
| 晩酌 | 刺身・鶏の唐揚げ・枝豆などのつまみと、飲んだ量を記録する酒類が見つかります。 |

例えばまぐろの刺身は昼食・夕食・晩酌、バナナは朝食・間食です。おかずを選ぶ設定を有効にしても酒類は自動で加わりません。表示した食事区分の中から主菜・副菜など献立に必要な役割を選ぶため、間食向きの少量のつまみがそのまま晩の主菜になることもありません。

朝の料理は確認済みのIDと種類を使って選びます。名前に「朝」があることや調理時間が短いことだけでは、朝向けとして扱いません。主菜だけでなく副菜と汁物も同じ分類で絞ります。短時間の炒め物が複数選ばれるような組み合わせを避けています。

朝食向きの候補が除外条件でなくなった場合は、条件を外したり昼夕の料理で埋めたりせず、設定の見直しを案内します。食材・アレルギーを避ける条件を料理の傾向より先に適用します。

## 主食と飲み物

朝はご飯、パン、どちらか、オートミール、主食なしなどを指定できます。コーヒーや牛乳を固定し、ヨーグルトや果物を添えることもできます。収録されているシリアル系の料理はオートミールです。コーンフレークを登録済みとみなして代用するものではありません。

昼と夜はおまかせのほか、ご飯もの、麺、パン・ハンバーガー・サンドイッチなどを選べます。主食を含む料理を選んだ場合は、別のご飯や主菜を重ねません。汁のある麺や鍋・シチューに別の汁物を添えない規則も使います。

食事を提案しない指定と、主食を付けない指定は別です。飲み物や追加食品を固定したときも、現在の除外条件に合わなければ無理に提案しません。

自動の分量は小盛り・ふつう・大盛りや、半人分・1人分・1.5人分などの分かりやすい段階を使います。自分で指定した固定量は勝手に丸めません。

## 一食の編集と詳細設定（v3.26.0）

朝のパンは添えるトーストのほか、サンドイッチや具入りベーグル・マフィンを食事の中心に選べます。商品表示を確認した追加食材と卵料理の出典は[朝食メニュー](breakfast-recipes.md)に記しています。

主食の量とおかずの量は別々に指定できます。副菜の数と1品目の種類、汁物の有無も食事ごとに指定できます。自分で決めた副菜の数が0なら種類の指定より0品を優先します。条件に合う候補が足りない場合は、勝手に品数を減らさず案内します。

「料理を替える」の指定はその一食だけに適用します。「＋ 料理を追加」では自分で食べたい料理を足せるため、朝食向けに分類していない料理も明示的に選べます。食材・アレルギーの除外条件は引き続き守ります。

## 晩酌向けのおかず（v3.28.0）

夕食の「晩酌向けのおかずを優先する」を選ぶと、焼き鳥や刺身、冷奴などの主菜と小鉢を候補から優先します。特定の日だけ希望する場合は「料理を替える」からその夕食を設定できます。主食の種類と量、副菜の数、アレルギーや避ける食材はそのまま適用します。

家庭の食卓で主菜や副菜になる料理は普段の昼食や夕食にも使います。鍋を囲む料理は夕食向けに、小串かつや少量の珍味などは晩酌を選んだ夕食向けにしました。この区分は料理の資料と家庭用の分量を踏まえたアプリの判断です。主菜と副菜の組み合わせには農林水産省の料理例を参考にしています。[食事バランスガイドの料理例](https://www.maff.go.jp/j/syokuiku/kodomo_navi/about/count.html)

お酒は飲んだ日に種類と実際の量を記録できます。晩酌の設定で自動提案するのは料理だけです。厚生労働省は飲酒習慣のない人に無理に飲酒を勧めないよう示しています。[健康に配慮した飲酒に関するガイドライン（1ページ）](https://www.mhlw.go.jp/content/12200000/001211974.pdf)
