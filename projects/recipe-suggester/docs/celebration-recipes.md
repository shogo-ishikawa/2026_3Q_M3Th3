## 四季の食材を選ぶ仕組み

「旬の食材や行事の料理を優先する」をオンにすると、献立を作る日付に合わせて、条件に合う候補から旬の食材が入った料理を少し優先します。「夏が旬のトマトを使った料理」のように、選んだ料理の理由で食材を確認できます。

| 献立の月 | 対象にする食材 |
| --- | --- |
| 3～5月 | たけのこ、アスパラガス、あさり、いちご、かぶ、にら |
| 6～8月 | きゅうり、トマト、あじ、すいか、枝豆、ピーマン |
| 9～11月 | さつまいも、柿、さんま、しいたけ、ぶどう、なす |
| 12～2月 | 白菜、大根、ぶり、みかん、ほうれん草、れんこん |

対象の食材が1人分に10g以上含まれる料理に、小さな加点を1回だけ行います。複数あるときは、分量の多い食材を理由として表示します。たけのこはレシピの下ゆで済み重量を使います。缶入りトマトや干ししいたけなど、台帳で別の食材にしている加工品は対象外です。

関東農政局と東京都中央卸売市場が紹介する例から、アプリに収録している食材を選びました。季節の区切りは日本の四季の目安です。実際の旬や流通時期は産地や品種によって変わります。[関東農政局「食べ物と日本の四季」](https://www.maff.go.jp/kanto/syo_an/seikatsu/shokuiku/ouchi/recipe.html)・[東京都中央卸売市場「旬の食材 青果」](https://www.shijou.metro.tokyo.lg.jp/about/shoku/seika)

## 分量と栄養

家庭向けに作成した2人分の配合です。登録の基準は1皿または1杯が1人分で、「買い物」では献立の人数に合わせて材料を換算します。たとえば鶏の松風焼きは2人分に鶏ひき肉230gと卵1個を使います。4人分では鶏ひき肉460gと卵2個です。

栄養6項目は、材料ごとに台帳の1単位の成分値に使用量を掛け、合計を2で割ります。油や煮汁を残すと実際の摂取量は変わります。アレルゲンは調味料や加工材料の原料も含めて判定します。たとえばパン粉焼きには台帳のパン粉に含まれる小麦・卵・乳・大豆が反映されます。[料理別の成分・食品番号（CSV）](menu-nutrition-audit.csv)・[材料の出典](nutrition-sources.md)・[文部科学省の食品成分データベース](https://fooddb.mext.go.jp/)

## 料理構成の参考資料

- 誕生日の肉料理には、色の異なる野菜を牛薄切り肉で包み、断面を見せる方法を取り入れました。コキールは、ほたてをホワイトソースとともにオーブンで焼く料理を参考にしています。[平和堂「アスパラと人参の牛肉巻き」](https://kurashi.heiwado.jp/recipe/detail/1106)・[リンナイの調理資料（PDF）](https://www2.rinnai-style.jp/document/cook_book/604-105-000.pdf)
- クリスマスのローストは骨なしの鶏もも肉を使用します。リースサラダは緑の野菜を輪に並べる盛り付けを参考に、赤パプリカとコーンを合わせました。[キッコーマンのクリスマス料理](https://www.kikkoman.co.jp/homecook/theme/popular/christmas_recipes.html)・[サラダクラブのリースサラダ](https://www.saladclub.jp/recipe/shrimp_and_broccoli_wreath_salad.html)
- お正月の松風焼きは、鶏ひき肉にみそを合わせて焼き、ごまと青のりで表情を変えます。祝い煮は家庭で扱いやすいむきえびと花形のれんこんを使います。きんとんには栗の代わりにりんごを合わせました。[日出町の松風焼き](https://www.town.hiji.lg.jp/iryo_kenko_fukushi/kenko_iryo/kenkozukuri/2/2/1709.html)・[キッコーマンの祝い肴](https://www.kikkoman.co.jp/homecook/article/event/shogatsu/iwaizakana.html)
- 肉を巻いたり成形したりする料理では、中心部の加熱を工程に含めました。[厚生労働省「家庭での食中毒予防」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/01_00008.html)
