# 晩酌にも使える主菜12品

2026年11月18日に各発信元の資料で料理の主材料と調理法を確認しました。アプリの材料と手順は家庭で作りやすい2人分です。通常の献立に含める時間帯は、資料での扱いとアプリでの取り分け方をもとに決めました。「晩酌」の料理は食事だけでも選べます。
