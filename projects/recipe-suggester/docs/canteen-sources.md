# 弁当・定食店から着想した主菜と副菜（v3.11.0）

確認日：2026-11-13。`canteen-foods.js` に16料理・2食材を追加しました。参考にしたのは料理の組み合わせや調理法です。材料の使用量と手順は本アプリ独自の家庭用配合で、店舗の公式レシピ・味・原材料・栄養値を再現したものではありません。

ご飯・みそ汁・定食の付け合わせは含めず、必要なら別のメニューとして加えます。すべて材料は2人分、記録は1皿で1人分です。肉は既存DBの部位と皮・脂身の状態を使い、鶏むね肉と皮付きもも肉を区別します。

P・F・C等の単位はgです。どちらも1g当たりへ一度だけ換算し、黒酢はmlへの密度換算をせず、計量したgで扱います。黒酢の食物繊維・食塩の0はメーカー表示値で、未掲載値を0で埋めた値ではありません。

柚子胡椒は `simmered_yuzu_kosho` を共用し、S&Bの公式値を代表に使用します。原値と食物繊維未掲載部分の推定は [鍋料理の出典](simmered-sources.md) に記録しています。柚子胡椒は食塩相当量13g/100gの代表値なので、使用したg数の分を食塩へ加えます。料理名だけから「香辛料だから塩分ゼロ」とは扱いません。

その他の材料は既存DBの代表値と出典を利用します。新規料理に店舗の完成品の `manualNutrition` は設定せず、肉・野菜・調味料・油を含めて合計します。ほっけは開き干し、まぐろは刺身用赤身、えびはむき身、青のりは乾燥品という状態を明示しています。

## 量と調理の仮定

- 揚げ物の材料表にある油は、料理に残って食べる吸収油の目安です。揚げ鍋に張る油全量ではありません。鶏と野菜の黒酢あんの油32mlは炒め用8mlと吸収油24ml、それ以外の揚げ物は記載量を吸収油とするモデルです。
- 肉から流出して捨てる脂、衣や下味の残り、水分蒸発は個別に補正していません。これらによって実物と差が生じます。塩分を含むたれと、記載した煮汁・蒸し汁は全量を食べるモデルです。
- 柚子胡椒焼きは下味と仕上げに分け、仕上げ分の香りを残す手順。柚子胡椒蒸しは鶏むね肉を同じ厚さへそぎ切りにし、野菜の上で蒸してねぎだれを合わせます。サラダは加熱した蒸し鶏を冷やし、アボカドと組み合わせます。
- かつとじと味噌かつ煮は、卵の三分の一を衣、残りを仕上げに使います。同じ卵を材料へ二重に加えません。鶏肉・豚肉・つくねは中心75℃で1分以上の確認を含め、卵も全体へ火を通します。
- ひじきは乾燥重量で計算し、水戻し・洗浄後に使用。まぐろ小鉢は刺身用を使い、調理後長時間置かずにいただく手順にしています。
