# 全メニューの栄養と食事区分

2026年11月19日、郷土料理と世界の料理42品を加えたv4.5.0の全1,270品について、材料台帳から栄養・食事区分の一覧を再作成しました。CSVには1品につき1行で、栄養の基準量、6成分、値の根拠、参照先、食べる時間帯、行事・シーンを収録しています。Excelで料理名や食事区分を絞り込めます。[全メニューのCSV](menu-nutrition-audit.csv)

## 数字の読み方

ご飯は何gか、菓子パンは何個かを「基準量」で確認してください。エネルギーは整数、ほかの成分は小数第1位に丸めています。例えば鶏卵うどんは、ゆでうどん200gと卵1個を使った丼1杯で313kcal、食塩相当量2.5gです。とろみのあるつゆも含みます。メニュー画面や記録では、食べた量に応じて丸める前の値から計算します。

| 算出方法 | 品数 | 対象 |
| --- | ---: | --- |
| 材料から概算 | 1,126 | 可食部、製品の使用量、調理法に基づく料理や果物 |
| 公式表示値を参照 | 127 | 容量と個数を特定できる商品 |
| 参考配合から概算 | 14 | 具とご飯を合わせた一般的なレトルト料理やバーガーなど |
| 公式表示値と材料の概算 | 2 | プロテイン商品を牛乳で割る例 |
| 栄養値未登録 | 1 | 対応する6成分を確認できなかった冷凍水餃子 |

6成分がそろうのは1,176品です。93品では食物繊維など一部の成分が空欄です。冷凍水餃子の1品は6成分をすべて空欄にしています。成分の空欄は未測定、未掲載、範囲表示などを表します。表示上の「0.0」には微量の成分が含まれる場合があります。

## 照合した範囲

- 全メニューの基準量と材料の単位を確認しました。材料計算の料理は「各材料の1単位の栄養 × 全員分の材料量」を合計し、人数で割ってアプリの計算と別に照合しました。g単位の料理・食材は、栄養素の量が重量を超えていないかも調べました。全515食材の計算値について負の値や無効な数値を検査しています。
- 文部科学省の本表を取り込み、食品番号、エネルギー、たんぱく質、脂質、炭水化物、食物繊維総量、食塩相当量を照合しました。同じ食品を複数の調理状態で登録している場合があります。照合対象は346食材、335食品番号の2,076成分です。うち2,072成分は原表または明記した代理食品の値と換算後に一致しました。残る4成分は後述の食塩換算を個別に確認しました。[文部科学省の掲載ページ](https://www.mext.go.jp/a_menu/syokuhinseibun/mext_00001.html)
- 乾そばとそうめんはゆでて湯切りした後の塩分、無塩のカシューナッツは無塩品の塩分、こしたかつおだしは使った削り節に含まれる塩の最大量を使います。生と加熱後、乾燥品と戻した後の重量、殻付きのあさりと可食部、牛乳の体積と重量も区別しました。食品番号のない商品、香辛料の補助値、家庭用の配合の根拠は別に記録しています。[材料の出典と換算](nutrition-sources.md)
- 公式表示を使用する商品は参照商品の規格と1個・1包装・100gなどの表示単位を確認しました。銀座コージーコーナーのアップルパイは商品ページの改定に合わせ、1切れを344kcalから347kcalに、炭水化物を59.1gから59.5gに更新しました。商品は販売地域や改定で変わるため、手元の表示と規格が異なる場合があります。[商品の現行表示](https://www.cozycorner.co.jp/product/cutcake/57899.html)

## だしをこす料理の修正

みそ汁など28品で、こして取り除く昆布やかつお節を汁へ移る成分に置き換えました。昆布を戻して具にするおにぎりや、おかかをまぶして食べる和え物には、食べる乾物全体を計上します。購入量はどちらも用意する乾物の重さです。豆腐とわかめのみそ汁では1杯の食物繊維が2.2gから1.8gになりました。

昆布を沸騰前に取り出す調理は水出しの参考値を使い、乾燥昆布30gから汁880gを得る条件に換算しました。水出しの食物繊維は未測定のため、煮出した汁の値で概算しています。かつお節は荒節30gから汁860gを得る条件を使います。汁100g当たりの食塩0.1gは表示の丸めが大きいため、削り節そのものが含む食塩1.2g/100gを上限にしました。抽出時間、水量、温度や、家庭で実際に飲んだ汁の割合によって変わります。[文部科学省の調理条件・だし類](https://www.mext.go.jp/content/20260327-mxt_kagsei-mext-000029402_0001.pdf)

## 大きな値を確認した例

- 食塩相当量が1食6gを超えた8品はいずれも麺につゆを加えた全量です。最大は二郎系風ラーメンの10.5gでした。料理ごとに麺、しょうゆ、濃縮スープや添付調味料を含む基準を確認しました。この値を汁を残した実際の摂取量と同一には扱えません。
- ひよこ豆のスパイス煮は1人分にゆでひよこ豆を150g使い、玉ねぎとトマトなどを含めて食物繊維21.7gになりました。豆をゆでる前の重量との取り違えがないことを確認しました。
- 酒類10品はアルコールのエネルギーを含みます。主要3成分だけを4・9・4kcal/gで換算した値との差が大きい場合も、成分表に記載されたエネルギーを採用しています。

家庭料理は登録した配合による概算です。調理した全品の実測、食べ残した油や煮汁の計量、個々の店舗の料理の成分分析は行っていません。食事区分は組み合わせ方の目安です。1品に複数の場面を割り当てています。[食事区分の考え方](meal-suitability.md)

## 同じ監査を再現する

標準成分表の本表は2026年3月27日訂正版を使用しました。照合スクリプトは「表全体」シートから成分識別子を選びます。SHA-256が異なる版を読み込むと停止します。Node.jsとPythonのopenpyxlを使い、アプリのディレクトリで実行します。[文部科学省の本表（Excel）](https://www.mext.go.jp/content/20260327-mxt_kagsei-mext-000029402_02.xlsx)

```sh
python3 tools/audit_menu_nutrition.py --mext 20260327-mxt_kagsei-mext-000029402_02.xlsx --check
```

`--check`はCSV全行が公開ファイルとバイト単位で一致するか確認します。省略するとCSVを書き出します。原表を使わずに既存データの再計算とCSV照合だけを行う場合は`--mext`を省略できます。
