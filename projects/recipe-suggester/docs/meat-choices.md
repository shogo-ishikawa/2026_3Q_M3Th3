# 肉の種類の選択

肉豆腐、もつ煮込み、手作りハンバーグ各種、ロコモコ、麻婆豆腐、麻婆豆腐丼、麻婆なすで肉を選び直せます。購入品・レトルトの完成品の肉は、この機能では変更しません。

- 肉豆腐：牛肉・豚肉
- ハンバーグと麻婆料理：牛ひき肉・豚ひき肉・合いびき・鶏ひき肉
- もつ煮込み：豚小腸（ゆで）、牛小腸（生）、牛ミノ（第一胃・ゆで）

牛と豚の合いびきは1:1を目安にします。肉の総重量は元の1人分を保ち、肉以外の材料を変えません。元のレシピと過去の記録は変更せず、選んだ配合を独立した1人分レシピとして計算します。

もつは部位と状態で脂質が大きく違います。「牛肉」の筋肉の数値を転用しません。生の牛小腸は下ゆで前、豚小腸と牛ミノは下ゆで後に水気を切って量ります。下ゆで後の重量を生の小腸の値で計算しません。牛小腸版は調理工程にも下ゆでを追加します。脂の溶出や煮汁へ移る成分の量は補正しない概算です。

除外条件は選んだ肉の実際の材料と派生元で判定します。牛肉を外したときに名前だけ豚肉へ変更する処理はありません。条件に合う選択肢を生成する関数と、明示的な選択画面を分けています。
