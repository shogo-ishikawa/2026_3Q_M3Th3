# 作りやすい量と材料の目安

材料の数字は、調理するときに使いやすい大きさへ丸めて表示します。保存済みの記録と栄養計算、買い物の合算に使う値は変えません。表示の「約」は実際に用意する量の目安です。

## 献立の量

自動提案では、同じ料理に複数の倍率を重ねません。

| 対象 | 軽め | ふつう | しっかり |
| --- | --- | --- | --- |
| 炊いたご飯 | 小盛り100g | 150g | 大盛り200g |
| 食パン | 半枚 | 1枚 | 1枚半 |
| 主菜・副菜 | 少なめ・半人分 | 1人分 | 多め・1.5人分 |
| 汁物・飲み物 | 基準の1杯 | 基準の1杯 | 基準の1杯 |

ご飯の100・150・200gは、このアプリで選びやすくするために決めた量です。誰にでも適切な摂取量を示すものではありません。パンやご飯を具体的な量で固定した場合は、その指定を優先します。手入力した過去の量も書き換えません。

皿数が細かい場合は「少なめ」「多め」で量の違いを示します。料理の詳細を開くと、その量で用意する材料を確認できます。

## 材料の読み方

例えば、むきえび39.375gは「約40g」、レタス33.75gは「約35g」と表示します。一般的な大きさを確認できた食材には、個数・枚数・小さじなどの目安も添えます。

- 20g以上の材料は主に5g刻み、100g以上は10g刻みにします。
- 少量の調味料は0.1gなどの目安を残します。0.1g未満の量を0gにはしません。
- 小さじは5ml、大さじは15mlです。gへの換算は調味料ごとに異なります。
- 食材の大きさには差があります。個数が合わないときは、表示した重さを優先してください。
- 購入量の目安を丸めるときは、不足しない方向へ切り上げます。包装数の計算自体は丸めません。

## 個数・枚数の参照値

確認日：2026年11月15日

[味の素パーク「食材の目安量」](https://park.ajinomoto.co.jp/contents/basic/ingredients_bunryou/)の一般的な重量を参考にしています。同資料の丸ごとの重さは皮・芯などの廃棄分を含むため、可食部のgを個数へ厳密に変換する資料にはしていません。個数は用意するときの見当です。

| アプリ内の食材ID | 参照する単位と重さ | 適用範囲 |
| --- | --- | --- |
| lettuce | 1枚30g | 生のレタス。葉の大きさで変わる |
| cabbage | 1枚50g | 生のキャベツ。葉の大きさで変わる |
| onion | 1個200g | 丸ごとの玉ねぎ |
| carrot | 1本150g | 丸ごとのにんじん |
| cucumber | 1本100g | きゅうり |
| tomato | 1個200g | 丸ごとのトマト |
| potato | 1個150g | じゃがいもを用意するときの目安。水煮後の重量へ置き換えない |
| broccoli | 1房15g | 生の小房 |
| shiitake | かさ1枚10g | 軸を除いたしいたけ |
| shimeji・enoki・maitake | 1パック・1袋100g | 一般的な包装の例。商品表示を優先 |
| spinach・komatsuna | 1束200g・300g | 生の束。根などの廃棄分を含む |
| bean_sprouts | 1袋250g | 一般的な袋の例。商品表示を優先 |
| garlic・ginger | 1かけ8g・12g | 1かけの大きさで変わる |

数の目安が登録されていない食材には、確認できていない個数を作らず、丸めたg・mlなどだけを表示します。

## えびの尾数

[CBCテレビ・キユーピー3分クッキング「えびのクリームパイ」](https://hicbc.com/magazine/article/?id=kewpie-recipe-2024050601)には、むきえび6尾で60gの例があります。一方、[ノースイの尾付きむきえび商品](https://www.nosui.co.jp/products/details.php?id=30126)は粉付き・尾付きで約15gとされており、その重さを生のむき身へ移すことはできません。

アプリ内の`shrimp`は殻を除いた生のむき身のgです。えびの大きさや商品の規格が指定されていないため「数尾・大きさで調整」と表示し、40gを一律に3尾とは決めません。甘えびの刺身やえび天ぷらにも同じ目安を使い回しません。

## 調味料と計量スプーン

[京都市「調味料の計り方」](https://kyo-kenko.city.kyoto.lg.jp/food-education/trivia/seasoning/)と[貝印「計量スプーンの容量」](https://www.kai-group.com/faq_corporate/%E8%A8%88%E9%87%8F%E3%82%B9%E3%83%97%E3%83%BC%E3%83%B3%E3%81%AE%E3%81%9D%E3%82%8C%E3%81%9E%E3%82%8C%E3%81%AE%E5%AE%B9%E9%87%8F%E3%82%92%E6%95%99%E3%81%88%E3%81%A6%E3%81%8F%E3%81%A0%E3%81%95%E3%81%84/)を参照しています。

| 食材ID | アプリの登録単位 | 小さじ1の目安 |
| --- | --- | --- |
| salt | g | 食塩・精製塩6g。あら塩には使わない |
| sugar | g | 上白糖3g。グラニュー糖には使わない |
| miso | g | みそ6g |
| oil・olive_oil・sesame_oil | ml | 5ml。5gとは扱わない |
| soy_sauce・vinegar・sake・mirin | ml | 5ml。重さへの変換はしない |

スプーンの端数は、近い1/4杯刻みの目安を無理なく添えられる場合だけ表示します。0.5gの塩など、小さじで分かりやすく表せない量はgのままにします。目安を追加しても、アレルゲン・原材料・栄養の情報は変わりません。

## 実装を読むとき

`portion-guide.js`の`plannedQuantity`が自動提案の量、`planPortionLabel`と`portionLabel`が料理の量の表示、`formatCookingIngredient`が調理用の材料表示を担当します。`formatPurchaseAmount`は購入量の表示だけを上向きに丸めます。どの関数も保存データを更新しません。
