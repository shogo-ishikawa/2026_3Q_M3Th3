# 果物の量と栄養値

朝食に添える果物や間食の果物を、生のまま食べた量で記録できます。温州みかんは薄皮ごと、はっさくは薄皮を除いた果肉、シャインマスカットは皮付きの実で計算します。加糖シロップやヨーグルトを添えた場合は記録に追加できます。

一般的な分量の参考に農林水産省の「食事バランスガイド」を用いました。果物1つ分の例は約100gで、大きさや種類によって個数が変わります。アプリの初期量は小皿に添える一例です。個数はおおよその目安なので、実際に食べた果肉の重さに合わせて変更できます。[農林水産省「SV早見表」](https://www.maff.go.jp/j/syokuiku/zissen_navi/balance/chart.html)

新しく収録した22品は文部科学省「日本食品標準成分表（八訂）増補2023年」の2026年3月27日訂正版に対応します。それぞれの食材に食品番号と個別の出典を記載しています。栄養値は可食部100g当たりの公表値を使います。6項目とも値がそろっているため他の食品による補完はありません。ライチの試料は冷凍品です。確認日は2026年11月18日です。[文部科学省の成分表と正誤表](https://www.mext.go.jp/a_menu/syokuhinseibun/mext_00001.html)

ゴールドキウイはキウイフルーツの除外設定に対応します。温州みかん・はっさく・グレープフルーツについては消費者庁が示す「オレンジ」の表示範囲に従って扱います。[消費者庁「アレルゲンを含む食品に関する表示」D-13](https://www.caa.go.jp/policies/policy/food_labeling/food_labeling_act/assets/food_labeling_cms201_260401_23.pdf)
