# メニューのまとめ方と組み合わせの見直し

2026年11月13日、v3.7.1の855レシピを対象に、一覧で種類を選ぶ料理と、一度に複数の種類を組み合わせる料理を確認しました。既存の料理ID、材料、分量、栄養、調理手順、保存済みの記録は維持しています。

## 組み合わせて記録する料理

おでん、寿司、焼き鳥、天ぷら、刺身、チーズ、ナッツは、食べる種類と各種類の量を選んで一皿を組み立てます。ベーグルとワッフルはトッピング、マフィンとサンドイッチは具材を選べます。選択した分だけを栄養と買い物の必要量に反映します。

| 料理 | 選ぶ内容 | 一覧での入口 |
| --- | --- | --- |
| おでん | 大根、卵、練り物、豆腐類などの具と量 | おでん |
| 寿司 | 握り・細巻き・太巻き・軍艦の種類と貫数・切れ数 | 既存の4種類を残し、いずれからも寿司の組み合わせ画面へ進む。握りの盛り合わせも握りの入口へまとめる |
| 焼き鳥 | 部位、味付け、本数 | 手作りとテイクアウトを区別 |
| 天ぷら | 魚介・野菜・きのこの種類と量 | 既存の主菜・副菜、手作り・外食の分類を維持 |
| 刺身 | 魚種と量 | 刺身 |
| チーズ・ナッツ | 種類と量 | チーズ、ナッツ |
| ベーグル・ワッフル | ベースとトッピング | 各料理の入口 |
| マフィン・サンドイッチ | ベースと具材 | 各料理の入口 |

栄養が分かっていても、商品の原材料やアレルゲンが未確認の場合は確認済みにはしません。既存の購入品と、材料から組み立てる家庭向けの配合も区別します。

## 詳細の中でバリエーションを選ぶ料理

種類ごとの独立したカードを並べ続けず、同じ料理の入口を押してから種類を選ぶ形を広げました。対象IDは `menu-variations.js` に明示し、料理名だけで自動的に新しいメニューを取り込む仕組みにはしていません。

| 区分 | 今回確認した統合対象 |
| --- | --- |
| 主食 | ピザ、チャーハン、手作りラーメン、丼もの、オムライス、レトルト丼、ハンバーガー、購入品のサンドイッチ、ホットサンド、トースト、食パン、オートミールがゆ |
| 主菜 | ハンバーグ、餃子、鶏の唐揚げ、焼き魚、コロッケ、シチュー、鍋料理 |
| 汁物 | ポタージュ、即席のカップスープ、春雨スープ |
| 間食 | ヨーグルトのトッピング違い |
| 飲み物 | 牛乳・無調整豆乳、フルーツミルク・豆乳、果汁・野菜ジュース、商品表示に基づくトマトジュース、水・無糖炭酸水、レモン水・レモン炭酸水 |

既存のご飯、おにぎり、うどん、そば、パスタ、カレー、焼きそば、即席めん、みそ汁、オムレツ、お茶、コーヒーなどの入口も保ちます。肉じゃがやお好み焼きの具材選択も引き続き使えます。

確認時点の既存855品だけでは、種類をまとめた一覧の入口が751件から619件になります。この数値には新しく追加する食品の入口を含みません。元の855品は削除せず、選択肢の中に1回ずつ保持します。

握りの入口には単品11種類と旧「にぎり寿司の盛り合わせ」を含めます。表示上の所属は12レシピですが、具を選ぶ画面での握りの選択肢は11種類です。既存の盛り合わせの量単位は「皿」、単品は「貫」のまま保持し、過去の記録も書き換えません。

## まとめる際に保つ条件

- 主菜・副菜・主食などの役割、手作り・即席・購入品などの提供形態、主食を含むかどうかが一致するレシピを同じ入口にします。
- 旧データで主菜として登録された丼やホットサンドは、役割を勝手に書き換えず別の見出しへまとめます。
- フィルターやアレルギーの条件で除外された種類を、見出しの選択肢から復活させません。
- 原材料、栄養、量の単位は選択した料理のものを使います。見出し名で保存済みの料理名を上書きしません。
- ガパオライス、ビビンバ、ロコモコ、そばめし、油淋鶏などは、それぞれの料理として見つけられるよう独立した入口を保ちます。
- 具が違うだけとは限らない野菜炒め、煮物、和え物、サラダ、スープを、名前の一部が同じという理由だけで一律にまとめません。

## 確認方法

全レシピを表示用のグループに分けた後も、全IDが重複なく1回ずつ残ることを自動確認します。追加したピザ、チャーハン、ラーメン、コロッケ、飲み物の種類は、明示したIDの組み合わせとも照合します。手作りとテイクアウトの焼き鳥、主菜と副菜の天ぷら、購入品と手作りのサンドイッチが混ざらないこと、アレルギーや食材カテゴリで絞った後に除外済みの種類が戻らないことも確認します。
