# 単品のお気に入り・最近使った料理

対応版：v3.14.0

「記録」のお気に入り欄では、単品を最後に使った量で呼び出せます。g・ml・個・皿など、その料理の単位で量を変更して記録します。上下ボタンは1刻みで、小数も直接入力できます。記録先の日付・食事・予定／実績も選べます。

料理の詳細や最近使った料理から、お気に入りへ追加します。料理の材料・栄養・表示の基準量をその時点で保存するため、元のレシピやDBが変わっても再計算しません。同名でも材料や栄養の異なる配合は別に保存できます。お気に入りから外しても、食事の記録は残ります。

最近使った料理は、選択日以前の実食記録から最大12品を表示します。同じ内容は最後の量を初期値にし、未来の記録と予定は混ぜません。マイメニューへ保存していない組み合わせ料理も、その時の内容で呼び出せます。

作り置きの取り分け記録は、お気に入りと最近使った料理から追加できません。残量の二重使用を防ぐため、作り置きの残量画面でg数を指定してください。材料・アレルギー情報の未確認部分と、現在の除外条件に合わない食品は注意を表示します。記録済みの栄養の不明値を0へ置き換えることはありません。

保存項目は `favourites: [{id,name,item}]` で上限200件です。量・識別子・根拠の分類を除いた料理の内容が同じ場合は重複として扱います。根拠の分類だけが追加された旧記録と新記録もまとめ、最近の料理は新しい記録の分類と量を保ちます。お気に入りと食事の記録は、既存のJSON書き出し・読み込みへ一緒に含まれます。
