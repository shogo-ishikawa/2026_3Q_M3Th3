# 献立ノートの使い方

[ブラウザ版](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/recipe-suggester/)を開くと、そのまま使えます。ログインやAPIキーの設定は不要です。

## 避ける食材を指定する

アレルギーの対象を選びます。選択肢は、2026年11月時点の食品表示で対象とされる29品目です。それ以外にも、登録された食材を検索し、候補から選んで個別に除外できます。追加した食材は、選択済みの表示から外せます。

料理名だけではなく、材料と調味料に付けた情報を使って候補を絞ります。例えば小麦を選ぶと、小麦を含む麺や衣だけでなく、登録情報で小麦を含むしょうゆなどを使う料理も対象になります。

候補がなくなっても、アレルギーや食材の除外条件を自動で外しません。献立をそろえられない場合は、どの区分の候補が足りないかを表示します。

アプリに登録した配合と、実際に使う商品の配合は異なる場合があります。特に加工食品や調味料は商品ごとの原材料表示を確認してください。調理器具などを通じた混入の判定は行いません。

## 献立を作る

開始日、日数、人数を選び、「この条件で献立を作る」を押します。夕食1〜7日分、1〜8人分に対応しています。

1食は主菜・副菜・汁物を基本にします。丼や麺など、主食を含む主菜を選んだ日は、ごはんを重ねて追加しません。表示される理由も読み、最近の料理との重なりや食品群の組み合わせを確かめてください。

除外条件を変更した場合は、新しい条件で献立を作り直します。以前の条件で作った料理を、そのまま新しい条件に合うものとして扱いません。

## レシピを開く・料理を差し替える

献立の料理を開くと、材料・分量・作り方を見られます。分量は指定した人数に合わせて変わりますが、調理時間を人数に比例させる計算はしません。火の通り方や器具に合わせて調整してください。

別の料理にしたい場合は「差し替え」を押します。差し替えも同じ除外条件で候補を探します。候補がなければ無理に別の料理を入れず、そのことを知らせます。

レシピ一覧から料理を探すこともできます。アレルギーや食材の条件で表示される候補が変わるため、探している料理が見当たらない場合は選択中の条件も確認してください。

## 食べた内容を記録する

献立を食べたら、その日の「食べた記録へ」を押し、1食分をまとめて記録します。過去に食べた料理は「食事を記録する」から、日付と食事の場面を指定して登録できます。

アプリ内の料理はレシピから1品ずつ選びます。同じ食事で複数品を食べた場合は、同じ日付・食事の場面で追加します。外食や手作りの別の料理は、料理名と、その食事に含まれる食品群を入力します。自由記入の文章から食品や栄養素を推定する機能ではありません。

| 記録する項目 | 例 |
| --- | --- |
| 食品群 | 主食、野菜などの副菜、肉・魚・卵・大豆などの主菜、乳製品、果物 |
| 主なたんぱく源の種類 | 肉、魚、卵、大豆 |
| 自由記入 | 外食の料理名や、次回のためのメモ |

最近7日間と、提案する食事より前の当日の記録を参照します。同じ料理が続くことを減らし、記録に少なかった種類も選びやすくします。例えば夕食を考えるときは、その日の朝食・昼食も参考にします。同じ日付・食事の場面に複数の記録がある場合、集計上は1食にまとめます。

複数日分を作るときは、先に選んだ日の献立とも重複しにくくします。提案しただけの献立を、食べた記録へ自動で追加することはありません。

この集計は「食べた量」の計算ではありません。食品群を1回選ぶことと、公式の食事バランスガイドの1つ（SV）は異なります。記録が少ないときは、入力した食事だけを振り返る目安として使ってください。メモだけで食品群が分からない記録からは、偏りを推定しません。

## 買い物リストを見る

作った献立の材料を、同じ食材・同じ単位ごとに合計します。リストはコピーできます。人数を変えると必要量も変わります。家にある調味料や食材も含まれるため、購入前に手持ちの量を確認してください。

分量は使う量の目安です。1袋・1パック単位で買う個数や支払額は計算しません。

## 保存する・別の端末へ移す

設定と食事の記録は、このブラウザに保存します。同じブラウザで開き直すと、保存した内容を使えます。作成途中の献立は保存しません。設定や履歴を変更したときも、献立は新しい条件で作り直します。別のブラウザや端末とは自動で同期しません。

「記録を保存する」でJSONファイルに書き出し、別の端末の「記録を読み込む」で取り込めます。読み込む前に形式と内容を確認し、対応しないファイルで現在の記録を上書きしません。記録は1000件まで、読み込むファイルは2 MBまでです。

書き出したファイルには食事の記録や除外条件が含まれます。共有する相手と内容を確認してください。共有PCでは、使い終わった後に「食事の記録をすべて削除」を使います。除外条件が残っている場合も確認してください。ブラウザの閲覧データ削除によって記録が消える場合もあるため、残したい記録はJSONでも保存してください。

## 学習に使う

[新しいColab教材](https://colab.research.google.com/github/shogo-ishikawa/2026_3Q_M3Th3/blob/main/projects/recipe-suggester/meal_planner.ipynb)では、登録データから条件に合う料理を残す処理をPythonで試せます。料理の材料がリスト、食材の情報が辞書としてどう対応しているかを見ると、`for`と`if`の使い道が分かります。

アプリを改良するときも、まず同じ条件で実行した結果を残し、1つずつ変更して比べてみましょう。
