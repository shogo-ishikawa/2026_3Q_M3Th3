# Meal Paletteの使い方

対応版：v3.14.0 ／ 更新日：2026年11月14日

[ブラウザー版](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/recipe-suggester/)を開くとすぐに使えます。ログインやAPIキーは不要です。画面は「献立」「記録」「栄養」「メニュー」「買い物」「設定」の順に並び、起動時は献立を開きます。旧名は「献立ノート」です。v3.14.0は984品の料理と452種類の食材・調味料を収録しています。単品のお気に入り、文章からの一括記録、同じ食事の二重計上の確認、栄養値の根拠表示を追加し、汁や具を残した量も広く指定できるようにしました。鍋料理、ポトフやおでんの具材選択、刺身、エスニック料理とナン、カレーのご飯量、麺のトッピングも引き続き選べます。

## お気に入りと最近使った料理を呼び出す

料理の詳細や最近使った料理で「お気に入りに保存」を選びます。食事として記録する前の組み合わせや量も保存できます。「記録」の「お気に入り・最近使った料理」から料理を探し、g・ml・個・皿などの量と、登録先の日付・食事・予定／実績を選んで追加します。同じ内容を保存し直すと、お気に入りの量を更新します。

最近使った料理は、選択日以前に食べた記録から最大12品を表示します。同じ料理は最後に食べた量を使い、未来の記録と予定は含めません。保存時点の材料と栄養を使うため、元レシピが変わっても過去の内容を再計算しません。作り置きの取り分けは残量画面から記録します。お気に入りは200件までで、JSONにも含まれます。詳しくは[単品のお気に入り](favourites.md)を参照してください。

## 文章から料理をまとめて記録する

「記録」の「文章からまとめて記録」で、例えば「ご飯150g、納豆1パック、みそ汁1杯」と入力し、「料理の候補を作る」を押します。各行の料理と量を確認し、候補が複数なら種類を選びます。パックの重量など換算が未登録の場合は、表示された基準量を確かめて入力してください。料理名や量が不正な行も残るため、直すか明示的に削除します。

全行と登録先を確認した後に「内容を確認して一括登録」を押します。重複確認を取り消した場合は文章と候補を保ちます。文章から未登録の具材や栄養を推測する機能ではなく、選んだ標準レシピの栄養を使います。具材や汁を残した量を変える場合は料理の詳細を使ってください。入力は2000文字・30品までで、詳しくは[文章からまとめて記録](text-log.md)を参照してください。

## ご飯や料理の重複を確認する

同じ日付・食事区分・予定／実績の中で、ご飯込みの料理と単品ご飯、同じ配合・栄養の料理を重ねて登録すると確認を表示します。おかわりや追加のご飯なら、そのまま登録できます。取り消した場合は登録前の記録を保ち、自動で料理を削除したり量を減らしたりしません。名前だけで同じ料理と判断する機能ではありません。判定の範囲は[二重計上の確認](meal-overlap.md)を参照してください。

## 栄養値の根拠を確かめる

料理や記録に「材料から概算」「公式表示値（参考）」「手入力」「配合・摂取量の概算」「表示値＋概算」「根拠未記録」のラベルを表示します。ラベルには分類の意味と未入力成分の補足を添えます。料理の詳細に残した出典や基準量も合わせて確認してください。分類は精度や安全性の採点ではなく、不明な成分を0へ補うこともありません。古い記録に分類がなければ「根拠未記録」のままにします。詳しくは[栄養値の根拠](nutrition-basis.md)を参照してください。

## 汁や具を残した割合を指定する

対応する家庭用の汁物・鍋料理97品と、具材を選んだポトフでは、料理詳細の「汁と具を食べた割合」を使えます。汁は飲まない・具に絡む程度・少し・半分・ほとんど・全量から選び、0・10・25・50・80・100%として概算します。具は全量が初期値で、残した場合は具の割合も選べます。なめらかなポタージュはスープ全体を食べた割合で計算します。

栄養は指定した摂取量へ変わりますが、買い物には残す汁を含む調理前の材料全量を使います。具が吸った塩分や肉から汁へ溶けた脂の移動量までは推定しません。公式表示など合計栄養だけの料理には適用できません。ラーメンは従来の専用計算、おでんは従来の「実際に飲む汁のml」のままです。おでんの買い物では選んだ汁量を使うため、新しい汁物の扱いと区別してください。対象と仮定は[汁と具の摂取割合](soup-intake-model.md)を参照してください。

## 数量の上下ボタンと小数入力

料理や食材のg・ml、皿・個・本・枚・貫・切れ・杯、小さじ・大さじなどの数量は、上下ボタンとキーボードの上下キーで原則1ずつ増減します。例えば2.5個から上を押すと3.5個です。0.5gなどの小数は直接入力でき、勝手に整数へ丸めません。0を下回る操作は止めます。正の最小量が必要な欄では、範囲を外れる上下操作を止めます。

栄養成分の数値や換算係数、倍率は細かい調整が必要なので別の刻みを使います。日数や買い物の人数など、もともと整数で選ぶ設定は整数のままです。空欄、文字、負数、指数表記、上限を超える値は数量として登録できません。任意の栄養欄の空欄は引き続き「不明」です。

選択式の食材は数量を0にするとチェックが外れ、栄養と材料から除かれます。もう一度チェックすると、最後に入力した正の量へ戻ります。空欄や不正な入力を0とみなしてチェックを外すことはありません。1切れの重さなど換算に使う重量は、数量とは別に正の値を指定してください。

## 汁物を小分類から選ぶ

「メニュー」で区分を「汁物」にすると、「種類」で10分類に絞り込めます。「記録」でも区分「汁物」の次に同じ分類を選べます。みそ汁・豚汁、お吸い物・和風の汁物、あら汁、コンソメ・オニオンスープ、野菜スープ・ポトフ、ポタージュ、クリーム・チャウダー、中華スープ、韓国・エスニックスープ、その他の汁物に分けています。

分類を選んだ後は従来どおり具材や味のバリエーションを選べます。詳しい対応は[汁物の小分類](soup-categories.md)を参照してください。

## 材料を編集して自分の配合にする

料理の詳細で「材料を編集・追加してアレンジ」を開きます。量は1人分です。元の材料を減らす、0にして削除する、「食材を替える」で別の食材とg数を選ぶ操作ができます。新しい配合の栄養と買い物量を計算し、別の料理として保存・記録します。元の料理と過去の食事は書き換えません。

公式表示値や飲んだスープ量などから求めた栄養は、各材料へ正しく割り振れない場合があります。その料理では材料の減量・削除・置き換えを止め、理由を表示します。追加の食材は栄養をそのまま加算できます。

## 定番セットと過去の食事を使う

「記録」の「定番セット・過去の食事をコピー」を開きます。「過去の食事をコピー・定番セットに保存」でコピー元の日付・食事・実績か予定かを選ぶと、その食事枠の料理をまとめて表示します。名前を付けて保存すれば、いつもの朝食などを呼び出せます。登録先の日付・食事・種類と量の倍率を指定して追加します。今ある記録は残り、コピー元の栄養と材料を引き継ぎます。

作り置きから取り分けた料理は、残量の二重使用を防ぐためコピーできません。「作り置き・取り分けを管理」から追加してください。

## 購入時の重量と包装数を確認する

買い物リストは同じ状態の手持ちを引いた不足量を先に計算します。その後に購入量へ換算します。ご飯は生米、皮をむいたにんじん・じゃがいもは皮付き購入量を初期値で表示します。各行の購入量設定で換算係数・購入名・1包装の量を変更できます。材料と同じ状態で購入する設定にも戻せます。包装数は不足しないよう切り上げます。

換算は買い物表示専用です。食事の栄養や手持ち食材の状態・量は変更しません。乾麺を材料にしている料理へ、ゆで麺の倍率を重ねて掛けません。殻付きで登録したあさりにも殻の分を重ねません。詳しい係数は[購入量の換算](purchase-conversion.md)を参照してください。

## 作り置きの完成重量で取り分ける

「記録」の「作り置き・取り分けを管理」で料理、作った人数分、調理日、容器を除いた完成重量を登録します。料理全体の栄養と材料をその時点で保存します。食べた量をgで指定すると、完成重量に対する割合で栄養を計算します。水分の蒸発は完成重量に反映しますが、油や煮汁を捨てたことによる栄養の減少は自動では補正しません。

予定の取り分けも予約分として残量から引きます。予定を実績へ切り替えても二重には減りません。記録のg数を変更・削除すると残量も戻ります。取り分けた料理は調理済みなので、買い物リストへ材料を再び加えません。調理前の材料は通常の献立から買い物にまとめてください。使い終わった作り置きを終了しても過去の記録は残ります。保存日数や食べられる期限を判定する機能ではありません。

## いつものお店とサイズを登録する

メニューの「自分のデータベースを管理する」または料理詳細から「店別・サイズ別メニューを登録」を開きます。一般的な料理へ店舗名とサイズを紐づけ、公式資料のURL・確認日・栄養値を入力します。ご飯や付け合わせを表示値に含むかも明示します。公式値を自動取得する機能ではなく、自分が確認した表示値の保存機能です。

1食全体の表示値と100g当たりの表示値を選べます。100g当たりの場合は提供量のg数から一度だけ換算します。空欄の成分は不明のままです。材料は一般料理から推測せず、外食の登録を買い物リストへ材料として加えません。登録した店名でもメニューを検索できます。

定番セット・作り置き・購入量設定・店舗登録は、このブラウザーの記録と一緒にJSONへ書き出せます。旧版のJSONは新しい項目を空として引き継ぎます。

## 食事をカレンダーに記録する

「記録」で日付を選び、朝食・昼食・夕食・間食を指定します。月間カレンダーのほか、日付欄と「今日」からも移動できます。

まず「区分」で主食・主菜・副菜・汁物・飲み物・間食を選びます。初期表示は主食です。主菜と副菜では「食材カテゴリ」から「調理法」へ絞り込み、最後に「メニュー」を選びます。主食・汁物・飲み物・間食は「種類」からメニューへ進み、複数のバリエーションがある料理はその中で具体的な種類を選びます。量を入力して追加すると同じ日・食事に複数品を登録できます。ご飯、主菜、飲み物を別々に記録して構いません。

| 選び方の例 | 記録の仕方 |
| --- | --- |
| 主食 → ご飯 → 白米・玄米・炊き込みご飯・わかめご飯 | 食べた完成量をgで入力 |
| 主食 → おにぎり → 塩・鮭・梅・ツナマヨなど | 個数で入力。ご飯とは別の種類 |
| 主食 → うどん・そば → かけ・きつね・たぬき・肉など | 画面に表示される基準量に合わせて入力 |
| 主食 → パスタ → ペペロンチーノ・カルボナーラなど | 具体的な料理を選んで量を入力 |
| 主菜 → 肉 → 揚げ物 | 唐揚げ、フライ、カツ、コロッケなどから選ぶ |
| 主食 → お寿司 → 握り・軍艦・巻物・盛り合わせ | 握り・軍艦は貫、巻物は切れ、盛り合わせは皿で入力 |
| 主菜 → 魚介 → 刺身 | まぐろ赤身・サーモン・ぶり・たいなどを選ぶ |
| 副菜 → 食材カテゴリ → 調理法 | 枝豆・冷奴・ひじき煮・サラダ・煮物などを選び、表示単位に合わせて入力 |
| 飲み物 → 水・炭酸水 → 水・レモン水・炭酸水 | 飲んだ量をmlで入力 |
| 汁物 → みそ汁 → 豆腐やわかめ、なめこなど | 具の組み合わせを選んで量を入力 |
| 間食 → チョコレート・グミ・ドーナツ・ケーキ・チーズ・ホットスナックなど | メニューの基準に合わせて本・個・袋・gなどで入力 |

食材カテゴリと調理法は、候補を絞るための選択肢です。複数の食材を使う料理は別のカテゴリから探せることもありますが、一覧には同じメニューを重複して表示しません。調理法の「揚げ物」「焼き物」「刺身」などと、「手作り」「レトルト」などの調理・提供形態は別の条件です。

料理によってg・ml・個・皿・杯などの単位が異なります。基準量の説明も表示されるので、入力欄の単位を確かめてください。例えばご飯の基準が150gなら、100gは標準の`100 ÷ 150`倍として計算します。おにぎりの大きさは収録例の目安です。商品の表示が分かる場合は手入力で補えます。

寿司は握りと軍艦を1貫、細巻・太巻は切り分けた1切れ、盛り合わせは1皿を基準にします。握りを3貫食べた場合は「3貫」、細巻を2切れなら「2切れ」と入力します。巻物1本を食べた場合は、そのメニューの説明にある切れ数へ合わせてください。過去に保存した寿司の量や栄養は記録時点の内容を保ちます。

| 記録の種類 | 栄養と買い物への反映 |
| --- | --- |
| 食べた | 自分の摂取量へ含める。買い物には含めない |
| これからの予定 | 摂取量には含めない。買い物の対象になる |

予定を食べたら「食べたにする」を押し、実際の量や内容に直します。料理名を押すと記録した栄養・材料・作り方を開けます。「編集」では日付や食事区分なども変更できます。

### ご飯のお供を単品で記録する

納豆、おろし納豆、ゆで卵は「副菜」から探します。生卵と温泉卵も単品で選べるので、卵かけご飯に固定せず、ご飯や牛丼などと組み合わせて記録できます。収録しているすき焼きは卵も含むため、その分を単品で重ねて登録しないでください。

ツナの油漬けと水煮、味付けのり、たらこ、明太子、鮭フレークも追加できます。単品にはご飯や別添えの調味料を含めません。食べた卵の個数や食品のg数を入力し、ご飯は別に記録します。別添えのたれやしょうゆを使った場合は、手入力で補えます。

ツナの液汁を含めるかなど、計量する状態は詳細の説明に合わせてください。市販品は商品や味によって栄養・原材料が変わります。参照商品の情報は[ご飯のお供の出典](accompaniment-sources.md)から確認できます。未確認の商品例は記録用で、自動提案の対象にはしません。

### サラダの材料とドレッシングを選ぶ

1. 「メニュー」で「生野菜サラダ（ドレッシングなし）」を開きます。「記録」で同じメニューを選び、「材料を選んで記録」から進むこともできます。
2. 材料を選び、それぞれの量をgで入力します。レタスやキャベツ、トマトなどは生の可食部、ブロッコリーはゆでて水気を切った状態です。
3. ドレッシングの種類と量を選びます。ドレッシングなしも選べます。
4. 組み合わせの栄養と登録アレルゲンを確認し、日付、食事区分、予定か食べた記録か、食べる量を指定して追加します。

材料のg数はサラダ1皿分です。半分を食べた場合は記録する量を0.5皿にします。材料を半分にして0.5皿と入力すると二重に半量になるため、どちらかで調整してください。買い物では記録した材料と分量に買い物用の人数を掛けます。

同じ組み合わせを繰り返し使う場合は、追加するときに「この組み合わせをマイメニューにも保存」を選べます。保存しなくても、カレンダーにはそのときの材料と栄養が残ります。後から別の組み合わせを作っても、過去のサラダは変わりません。

ドレッシングは家庭で作る配合を基準にした概算です。市販品を使って表示値に合わせたい場合は、手入力メニューとして登録できます。既存のドレッシング付きサラダを選ぶ方法も引き続き使えます。詳しい計量方法は[サラダの組み合わせ](salad-builder.md)をご覧ください。

### 肉じゃがやお好み焼きの具材を選ぶ

1. 「メニュー」で肉じゃがかお好み焼きを開きます。「記録」で選んだ料理から進むこともできます。
2. 肉じゃがは「肉の種類」で牛肉か豚肉を選びます。お好み焼きは「お好み焼きの種類」で豚玉、イカ玉、シーフード玉、もちねぎ玉、モダン焼き、ミックス玉などから選びます。「自由に調整」も使えます。
3. 「具材とトッピング」で豚ばら肉、イカ、えび、餅、ねぎ、焼きそば麺を選び、それぞれの量をgで入力します。「ソース・たれ」はしょうゆと酢、ウスターソース、ソースなしから選び、ソースとマヨネーズの量も実際に使う量に合わせます。
4. 更新された栄養と登録アレルゲン、「材料と分量」「この内容での作り方」を確認します。日付と食事区分、予定か食べた記録か、何皿分かを指定して追加します。

表示する材料は1皿分です。肉や海鮮、切り餅は加熱前の可食部、麺は蒸し中華麺の調理前重量として量ります。例えば0.5皿を登録すると、材料と栄養も半分として記録します。好みの配合を繰り返し使いたい場合は「この組み合わせをマイメニューにも保存」を選びます。保存を選ばなくても、その時の配合と栄養は食事の記録に残ります。

肉や海鮮、麺の有無に合わせて作り方も変わります。具材を変えた後は新しい手順を確認してください。ウスターソースは専用のお好み焼きソースの栄養値ではありません。実際の商品に合わせたい場合は、表示を確認してマイメニューを編集できます。配合と計量の考え方は[料理の具材選択](dish-customisation.md)にまとめています。

### 同じ料理の種類をまとめて選ぶ

うどん、そば、パスタ、みそ汁、オムレツなどは、同じ料理を1つの入口へまとめています。詳細の「バリエーション」で種類を選ぶと、対応する材料と栄養、作り方、基準量へ切り替わります。記録画面でも「メニュー」に続く「バリエーション」で選べます。「カルボナーラ」のような具体的な名前でも検索できます。ご飯やおにぎり、寿司の握り・巻物、お茶やコーヒーも同じ考え方で選べます。カップ麺やレトルトは手作りと別の入口です。

手作りと即席、レトルトなどは区別して選べます。料理をまとめて表示しても、既存のレシピや過去の記録を削除することはありません。対象とまとめ方は[バリエーションの整理](menu-variations.md)をご覧ください。

### 記録を日付や範囲でリセットする

選択日の入力欄にある「選んだ日の入力をリセット」は、その日の記録を対象にします。日付範囲を指定するときは下部の「記録をリセットする」を開きます。範囲の最初と最後の日はどちらも対象です。日付を未来まで広げると、これからの予定も対象になるので期間を確かめてください。

範囲指定では「食べた記録と予定」「食べた記録だけ」「予定だけ」から選びます。対象の食事件数、料理数、完了チェックの日数を表示し、実行前にもう一度確認します。メモだけの記録も食事1件として数えます。

「予定だけ」では食べた記録と完了チェックを保ちます。実績を含むリセットでは範囲内の完了チェックも外します。料理が0件でも完了にしてある日は、この解除の対象です。自分のDB、設定、手持ちの食材は残ります。

実行直後は「直前のリセットを戻す」で戻せます。別の内容を保存するかページを読み込み直すと、この取り消しは使えません。残したい記録は事前にJSONへ書き出せます。

### カップ麺やレトルト食品を記録する

「調理・提供形態」を「即席」にすると、ラーメン、うどん、そば、焼きそばなどからカップ麺や袋麺を探せます。入力する1食・1袋は、画面に表示される乾燥製品の量や湯を含む基準に合わせます。乾燥重量と調理後の量を混ぜないよう説明を確認してください。

レトルトのカレーや丼は「レトルト」から探せます。カレーは詳細でご飯量を指定でき、初期値は150g、0gならルーのみです。カレーの具やレトルトの分量は、ご飯を増減しても変わりません。ご飯を含む料理に同じご飯を別に追加したり、具だけの栄養表示を1皿全体の値として使ったりしないよう、表示された材料を確認します。食べた量や商品が違う場合は手入力で調整できます。原材料やアレルギー情報の確認が必要な状態は、ご飯量を選んでも変わりません。

ハンバーガーは「ファストフード」、市販サンドイッチは「そのまま」でも絞り込めます。市販品には銘柄や店舗を指定しない一般例と、公式表示に基づく商品例があります。原材料やアレルギー情報が未確認のものには確認の案内を表示し、自動提案には使いません。実際に食べたものをカレンダーへ記録することはできます。

商品の表示が分かる場合は「見つからない食事を入力」から名前、基準量、栄養や原材料を登録し、自分のDBへ保存できます。収録されている市販品の例を記録しただけで、原材料の確認が済んだ扱いにはなりません。

### お菓子やスイーツを記録する

間食の「種類」ではチョコレート、飴・キャラメル・ラムネ、グミ、クッキー・ビスケット、スナック菓子、せんべい・米菓、ドーナツ、ケーキ、和菓子、アイス・氷菓から探せます。ポッキーなどの商品例も追加しています。果物、ナッツ、ヨーグルト、チーズ、ホットスナック、補食はそれぞれ別の種類です。

1個や1袋の量は商品によって異なります。メニュー詳細の基準量を確認し、食べた量に合わせて入力してください。商品の栄養表示を使う例でも、原材料やアレルギー情報が未確認なら自動提案には入りません。詳しい参照先は[菓子・スナックの出典](confectionery-sources.md)と[スイーツの出典](dessert-sources.md)をご覧ください。

### プロテイン・補食・お酒を記録する

飲み物の種類には「清涼飲料水」「プロテイン飲料」「お酒」を用意しています。プロテインはソイとホエイを区別し、粉末を水で割る場合と牛乳で割る場合も別に選べます。粉末のgと液体のmlを足して完成容量としないため、粉末の調製例は配合全体を1杯として扱います。牛乳割りには牛乳の栄養とアレルゲンも加えます。

間食の「補食・栄養補助食品」にはバーやゼリーなどの記録例があります。商品に表示される本数・個数・容量と画面の基準量を確かめて入力してください。

商品例の栄養は公式表示を確認した時点の参考値です。参照先と基準量は[酒・飲料・補食の出典](performance-food-sources.md)にまとめています。味や容量、商品の仕様が変わる場合があるため、購入した包材の表示を優先してください。成分表示が範囲になっているものや不明な成分は、勝手に平均や0へ置き換えません。原材料やアレルギー情報が未確認の商品は自動提案に使いません。

お酒は飲んだ量を記録するための項目です。献立の候補や飲み物の自動提案には入りません。ストレートの基準量に氷や割り材は含まれないため、ハイボールなどは表示する配合を確認してください。

### 1日の記録を完了する

その日に飲食したものをすべて登録したら「この日の飲食をすべて記録した」にチェックします。最近の平均には、この確認が済んだ日を使います。入力途中の日を、摂取量が少ない日として数えないための操作です。

食事や飲み物の入力を忘れていた場合は内容を追加・修正し、記録がそろっていることを確認してください。予定を入れただけでは1日の摂取量を記録したことになりません。

## DBにない食事を入力する

「見つからない食事を入力」から料理名、種類、量を入れます。外食や市販品も記録でき、栄養・材料・作り方は分かる範囲で補います。手入力では基準量と単位も設定できます。例えば基準を100gにして100g当たりの栄養と材料を入力し、50g食べた場合は「食べた量」を0.5倍とします。基準を1人分にした場合も、半分なら0.5倍です。

商品の栄養成分表示が分かる場合は入力できます。空欄は不明として残し、0を入れた場合だけ「0と分かっている」値として扱います。料理名やメモから栄養を推測する機能はありません。

全材料と分量を登録した場合は確認欄を選び、「材料から栄養の概算を入力する」を押せます。入力欄が概算値に変わるので、商品の値が分かれば後から修正してください。ボタンを押さなければ空欄を自動計算しません。

アレルギー情報は別に確認します。含まれる登録アレルゲンを選び、確認できたときにチェックします。全材料が分かるメニューでは、材料と原料に登録されたアレルゲンも引き継ぎます。

「自分のデータベースにも保存する」を選ぶと、次回からメニューとして呼び出せます。選ばなければその食事だけの記録です。自分のDBはブラウザー内に保存し、公開レシピ集へ送信しません。

アレルギー情報が未確認のメニューは自動提案しません。材料全体が未確認で追加の除外食材がある場合も候補から外します。実際に食べた事実としてカレンダーへ残すことはできます。

自分のメニューは「メニュー」タブのDB管理から削除できます。DBを削除しても記録済みの料理は残ります。記録時点の栄養と材料を保存するため、後からメニューを変えても過去の数字が勝手に変わることはありません。

## 栄養の量と最近の傾向を見る

「栄養」で日付と期間を選びます。1日・7日・30日を切り替え、エネルギー、たんぱく質、脂質、炭水化物、食物繊維、食塩相当量の6成分を確認できます。摂取量に使うのは「食べた」の記録だけです。

不明な成分を含む場合は、分かっている合計と不明分を区別します。数字が小さくても食事全体の量が少ないとは限りません。記録がない食事も食べなかったとは判断しません。

最近の平均では「この日の飲食をすべて記録した」を選んだ日を使います。栄養が不明な日は、その成分の平均から除きます。例えばエネルギーが分かる日が5日、食物繊維が分かる日が3日なら、それぞれ5日と3日で平均します。成分ごとの対象日数も確かめてください。記録がそろった日がなければ平均を確定しません。

家庭向けレシピの栄養は食品成分表と材料の分量から求めた概算です。商品の記録例には公式の栄養表示を使うものもあります。商品の配合や調理方法、汁の残し方などで変わるため、各メニューの基準量と出典も確認してください。根拠は[栄養値の出典](nutrition-sources.md)にまとめています。

## 比較の目安を自分に合わせる

「設定」で「プロフィールから参考値を選ぶ」を選びます。18歳以上の年代、基準表で参照する性別区分、普段の活動量を指定して保存すると、厚生労働省の2025年版食事摂取基準を参考に比較値を選べます。未選択の項目はアプリが推測しません。

活動量は、座って過ごすことが多い「低い」、通勤・通学や家事などで動く「ふつう」、活発な仕事や運動習慣がある「高い」から選びます。75歳以上の「高い」には原表の値がないため、自動の参考値を作りません。

| 成分 | 比較する目安の意味 |
| --- | --- |
| エネルギー | 参照体位に対する推定値。個人の体格から必要量を求めた値ではない |
| たんぱく質 | 推奨量を主な参考値にする |
| 脂質・炭水化物 | エネルギー比率の範囲をgへ換算する。中央の値は表示や提案のための参考値 |
| 食物繊維 | 目標量は「以上」 |
| 食塩相当量 | 目標量は「未満」。不足分を足すための数値ではない |

「自分で数値を設定する」も選べます。初期値は表示を試すための参考値です。プロフィールも、体格による調整、妊娠・授乳中、18歳未満、治療用の自動計算には対応していません。1日分や入力途中の記録から健康状態を診断する表示ではありません。

詳しい表と換算は[年代・性別・活動量による目安の出典](dietary-reference-sources.md)を参照してください。

## 献立を作る

「献立」で開始日、日数、買い物の人数、食事区分を選びます。「朝・昼・夕の3食」なら指定した日の3食をまとめて作ります。例えば3日分は9食です。朝食・昼食・夕食・間食のどれか1つだけでも作れます。期間は1〜7日、買い物用は1〜8人分です。条件に合う候補が足りないときは、途中までの献立を予定として保存せず、見直す条件を案内します。

主食は「主食の決め方」で選びます。

| 決め方 | 動き |
| --- | --- |
| 献立に合わせる | 食事区分や主菜に合わせて種類を選び、各メニューの基準量を使う |
| 種類と量を指定する | 具体的な主食と量を決め、まとめて作る各食に使う |
| 別の主食は付けない | 主菜などとは別に主食を追加しない。麺や丼などに含まれる主食まで取り除く設定ではない |

飲み物は種類とメニュー、量を指定します。ご飯はg、おにぎりは個数、飲み物はmlなど、選んだメニューの単位に合わせます。指定した量は提案の栄養、カレンダーの予定、買い物の必要量にも使います。

パスタやカレーライス、丼など一品で主食を含む料理を選んだ場合は、別のご飯や主菜を重ねない構成を使います。間食では間食メニューを中心に選びます。

アレルギーや追加の除外食材を先に確認し、ジャンルや比率、気分、優先したい食材を指定できます。ジャンルや気分は希望で、食材を避ける条件が優先です。必要な候補がなくなっても除外を自動で取り消しません。加工品や調味料は商品表示も確認してください。

「献立はどうやって選ぶ？」を開くと基準を確認できます。アレルギーと除外食材は必ず守る条件です。ジャンルや比率、気分は希望として扱い、該当する候補がなければ別の候補を使う場合があります。最近食べた料理や今回すでに提案した料理の繰り返しを避け、優先食材と手持ちの食材も参考にします。

栄養の順位付けにはエネルギー、食塩相当量、たんぱく質、食物繊維を使います。最近の記録からエネルギーと食塩の摂りすぎを避け、たんぱく質と食物繊維が少ない場合は補いやすい候補を優先します。脂質と炭水化物は振り返り画面で確認できますが、候補の順位には使いません。

最近の栄養は記録を完了した日を参考にし、当日すでに食べた内容も対象の食事より前の分を使います。予定や後の食事を摂取量へ加えません。今回作る複数食の間では料理の重複も調整します。

収録したテイクアウトや即席食品、市販の菓子・スイーツのうち原材料やアレルギー情報が未確認のものは、固定指定や差し替えでも自動提案へ戻りません。食べたものとして記録することはできます。商品表示を確認して自分のDBへ登録した場合は、材料やアレルギーなどの検査を通れば候補になります。お酒は常に記録専用です。

提案した各食の「この食事の主食を調整」では、ほかの食事を変えずに主食と1人分の量を変更できます。「この食事に反映」で栄養と買い物も更新します。麺や丼など主食を含む一品料理には別の主食を重ねず、量はカレンダーへ登録してから調整します。

「料理を替える」で別の候補を探せます。料理のチェックを外すと、その日の予定保存と買い物から外れます。料理名を押すと材料と作り方を開けます。内容を確認して「予定としてカレンダーへ」で登録し、食べたら実績に切り替えてください。

提案は目安に合う候補を選びやすくする仕組みで、1日の全成分をぴったり合わせる最適化ではありません。参考にした理由も確認できます。作成中の提案は予定として保存するまで再読み込み後には残りません。

## 必要なものを買い物リストへまとめる

「買い物」で手持ちの食材と調味料を選び、家にある量を登録します。同じ食材を再登録すると量を更新します。単位は食材ごとに決まっており、生米・炊飯済みのご飯、乾麺・ゆで麺などの状態も区別します。

リストは「いま提案されている献立」と「カレンダーの予定」を切り替えられます。最初の日と日数を選ぶと、必要な材料をメニューの量と人数分にまとめ、手持ちの量を食材ごとに一度だけ差し引きます。「食べた」実績は対象外です。

カレンダーは自分1人の記録です。例えば4人分の夕食を作って自分がご飯150gを食べる場合、カレンダーは150g、買い物はその材料を4人分として計算します。

材料が未登録、全体が未確認、現在のDBにない材料を含む場合はメニュー名を知らせます。表示された材料だけで必ず足りるとは考えず、不明分を確認してください。

ハンバーガーや市販サンドイッチは完成品の個数で集計します。例えば1人1個を2人分なら、完成品を2個買う量になります。肉やパンへ分解して買い足す計算ではありません。レトルトのご飯込みメニューは、具と炊飯済みのご飯を分けて必要量に加えます。袋麺やカップ麺では登録された乾燥製品の量などを使います。

買う商品の種類と分量が分かる場合は、原材料の詳細が未確認でも商品量を集計できます。その場合も「原材料や商品の確認が必要なメニュー」の案内は残ります。買い物の数量が表示されたことと、アレルギー情報を確認できたことは別です。手入力でも、必要な商品と分量がそろっていることを確認して登録してください。

購入済みチェックは目印です。在庫の数値を変えるものではありません。使った分や買い足した分は自分で更新します。在庫だけを直す場合は提案を残して再集計します。「買うものをコピー」も使えます。完成品の個数に加え、1包装の量を設定すると袋・パック単位へ切り上げます。支払額は計算しません。

## 記録を保存し、別の端末へ移す

「設定」から「データを書き出す」でJSONを保存できます。「データを読み込む」で形式を検査し、確認後に現在のデータを置き換えます。追加ではなく置き換えなので、必要なら先に書き出してください。不正なファイルで現在の記録を上書きしません。

v3.0.0〜v3.13.0の保存データやJSONはv3.14.0でも読み込めます。保存形式は引き続きversion 3です。お気に入りがない旧データは空の一覧として読み込み、栄養値の根拠の分類がない記録は「根拠未記録」と表示します。新しい主食設定がないデータも受け入れ、以前の主食指定を引き継ぎます。過去の食事の料理名や量、栄養、不明な成分は記録時点の内容を保ちます。以前の店舗名も自動で改名しません。新しく選ぶメニューには現在の表示名、分類、基準量を使います。

旧「献立ノート」のv1・v2の保存やJSONも引き継げます。アレルギー、除外食材、好み、記録を残し、プロフィールは未選択、記録を完了した日は未確認で始めます。旧保存領域を読み込み時に消すことはありません。

食事の記録、プロフィール、自分のDB、在庫や設定はブラウザー内に保存します。個人データをGitHubや共通DBへ送信せず、別の端末との自動同期もありません。書き出したJSONには食事やアレルギーの情報が含まれるため、共有先も確認してください。

JSONは2MB以下、食事の記録は5000件、マイレシピは500品までです。件数内でもサイズ制限があります。保存できない場合は画面に案内するため、閉じる前にデータを書き出してください。

「食事の記録をすべて削除」はカレンダーが対象です。自分のDBや設定も消す場合はブラウザーでこのサイトの保存データを削除します。

## メニューやPythonのコードを見てみる

## 栄養の見積もりを確認する

家庭料理の栄養は、食材・調味料の代表値に使用量を掛けて人数で割った概算です。例えば牛肉の薄切りは輸入牛の肩ロース脂身付き、豚肉の薄切りは豚肩ロース脂身付き、鶏もも肉は皮付きの値を使います。豚ばら・豚ロース・牛ひき肉・豚ひき肉などはそれぞれ別の値です。合いびき肉はレシピ内の牛肉と豚肉の使用量を合わせて計算します。

メニューの詳細にある「栄養の見積もりに使う食材・部位」を開くと、各材料の成分表の対応と補完の根拠を読めます。酒やみりんの脂質のような微量成分も計算に含め、クミンやターメリックには海外の公的成分表の一般値を用いています。油はmlから重量へ換算し、卵は1個の可食部50gとして扱います。

家庭用の汁物・鍋料理97品と選択式ポトフでは、汁や具を残した割合を指定して概算できます。ラーメンは専用のスープ割合、おでんは飲んだ汁のmlで指定します。肉から落ちる脂、具への塩分の移動、対象外の料理の残り汁は自動補正しません。過去の記録を今回の概算で自動更新することもありません。未確認の商品や手入力の空欄は不明として残ります。詳しい数値と仮定は[汁と具の摂取割合](soup-intake-model.md)と[栄養値の出典と換算方法](nutrition-sources.md)をご覧ください。

## 食べる種類と量を組み合わせる

おでん、ポトフ、寿司、刺身、焼き鳥、天ぷら、チーズ、ナッツは、料理を開いて食べる種類にチェックを入れます。おでんは具材の個数と飲む汁のml数、寿司は貫数や切れ数、焼き鳥は本数、天ぷらは個数、刺身は切れ数、チーズは個数や枚数、ナッツはg数で指定します。刺身とチーズは1つあたりの重さを補正できます。選んでいない材料は栄養と買い物へ加えません。おでんの汁や天つゆは外すこともできます。

寿司では握り・軍艦・細巻き・太巻きを同じ皿へ選べます。握りはまぐろ赤身、中トロ、サーモン、えび、いか、たい、ぶり、ほたて、たこ、玉子、あなごの11種類です。細巻きは1本6切れ、太巻きは1本8切れを目安としています。握り1貫と巻き寿司1切れは同じ量として扱いません。

ベーグルとワッフルはプレーンのベースとトッピング、マフィンは生地と混ぜ込む具材、サンドイッチはパンと具材を選びます。ベースだけで十分な場合はトッピングを外せます。マフィンは表示した生地へ具材を加えて焼く家庭用の配合例です。おでんの具の標準重量や焼き鳥1本の大きさなども目安なので、実際の量に合わせて調整してください。

選択した内容で材料・栄養・作り方が変わります。画面下の登録フォームの「1皿」は、その時に選んだ組み合わせ全体を表します。半分食べた場合は0.5皿、同じ組み合わせを2皿食べた場合は2皿にします。買い物画面の人数は別に掛かるため、1人分の記録を作ってから必要な人数へ合わせてください。

「この組み合わせをマイメニューにも保存」を選ぶと同じ配合を繰り返し使えます。保存しない場合も、その時の種類、量、栄養は食事の記録に残ります。購入品の参考値を含む組み合わせは実物の原材料を確認してください。未確認の食品を自動献立の候補へ変えることはありません。


## 切れ数・個数で量を決める

刺身は魚介ごとに切れ数、チーズは個・枚・小さじ杯数で入力できます。1切れ・1個あたりの重さと、選んだ量の合計g数を表示します。刺身はまぐろなら1切れ15gなどを目安にし、薄切りや厚切り、実物の商品に合わせて重さを変更できます。チーズの個数は切り分け・個包装など表示した形を基準にします。塊全体の1個とは区別してください。

確定時には切れ数と重さを掛けたg数を材料へ保存します。例えばまぐろ3切れ×15gは45gです。買い物リストではこの重量に料理の量と人数を掛け、手持ちの重量を差し引きます。以前の記録は、後から標準重量を変えても変わりません。

刺身の組み合わせは20種類です。マダコはボイル、ミズダコは生として区別し、しめさばは酢締めした加工品の成分値を使います。甘えびと赤えびは尾数で指定し、重さは頭・殻を除いたむき身です。その他も食べる可食部のg数に換算し、丸魚や殻付きの購入重量には逆算しません。イナダは若魚の代表値からの推定です。魚種ごとの目安と対応する成分表は[刺身の出典](seafood-sources.md)を参照してください。

## カレーのご飯量とナンを選ぶ

「主食」からカレーを開き、料理の種類を選びます。マッサマン、マトン、サグチキン、サグパニールも含め、材料の内訳が分かる19品でご飯を0〜1000gに指定できます。初期値は1人分150gです。炊いた後の重さを入力し、炊く前の米の重量とは混ぜません。

ルーだけ食べた場合は0gにします。カレーの具・ルーは元の1人分を保ち、米の栄養と買い物量だけを置き換えます。0gのカレーにナンを付けたいときは、主食の「ナン」からプレーン・ガーリック・バター・チーズ・ごま・全粒粉を別に追加します。ナン1枚の基準量も画面で確認してください。

ご飯0gのカレーは主菜として保存します。ご飯ありのカレーを登録した場合、そのご飯を別に重ねないよう材料を確認します。米の内訳が分からない手入力の完成品からご飯だけを差し引くことはしません。詳しくは[カレーのご飯量](curry-rice.md)と[エスニック料理・ナンの出典](world-food-sources.md)をご覧ください。

## 麺の種類・トッピング・スープを飲んだ量を選ぶ

ラーメンの詳細では、しょうゆ・塩・みそ・タンメンに加え、煮干ししょうゆ、味噌バターコーン、豚骨、家系風、二郎系風、背脂、担々麺を選べます。汁なし麺の油そば・冷やし中華・汁なし担々麺も含め、14種類の麺料理に対応します。麺のg数はゆで上がりの重さです。生麺や乾麺の重量と読み替えないでください。

味玉、チャーシュー、メンマ、コーン、長ねぎ、海苔、ほうれん草、ゆで卵、もやしなどを選び、卓上にんにくは小さじで指定できます。小さじ1杯は3gの目安です。表示した具や麺を全量食べる想定で計算し、麺・具を残した場合は記録する料理の量も調整します。

スープのある料理では、飲んだ量を次の5段階から選びます。初期値は完飲なので、実際の残量に合わせて変更してください。

| 選択 | 栄養計算に使うスープの割合 |
| --- | ---: |
| 麺に絡む程度 | 10% |
| 少し | 25% |
| 半分 | 50% |
| ほとんど | 80% |
| 完飲 | 100% |

この割合は入力を計算へ置き換える仮定です。麺・固形の具・追加トッピングは全量、スープ側の栄養だけを選んだ割合で加えます。スープの塩分・油・みそなどが均等に混ざると仮定し、溶かしたバターや背脂もスープに含めます。卓上にんにくなど追加して食べた分は全量を加えます。油そばなど汁なし料理はたれも全量で、飲用率を使いません。

買い物リストはスープを残しても、調理で用意する全量を集計します。例えばスープを半分飲んだからといって、必要なだしや調味料を半量にしません。家庭用の代表配合であり、店舗商品の量や栄養を再現した値ではありません。材料・計量状態・仮定の詳細は[麺類の出典](noodle-sources.md)をご覧ください。

## 材料のアレンジとオリジナルレシピ

1. 料理の詳細を開いて「材料を編集・追加してアレンジ」を押します。具材選択型の料理では、先に組み合わせを決めます。
2. 食材カテゴリや検索から追加する材料を選び、1人分のg数を入力して「この食材を追加」を押します。材料と量は後から編集・削除できます。
3. 追加後の材料と栄養を確認し、「レシピだけ保存」またはカレンダーへの追加を選びます。

元のレシピは書き換えません。追加分は元の1人分へ合算し、元材料を変更した場合は変更後の材料全体から再計算します。材料別に分解できない表示値は変更を制限します。加熱で流れ出る脂や、揚げ物の吸油などは自動補正しません。卵や油なども登録済みの重量換算を使ってgから個数・mlへ換算します。換算のない食品は表示された元の単位で入力します。

「メニュー」→「自分のデータベースを管理する」→「オリジナルレシピを作る」からは、料理名・区分・材料・作り方を登録できます。「レシピだけ保存」なら食事の記録は増えません。保存した料理はメニュー一覧と記録画面から選べます。このブラウザーだけに保存するため、必要に応じて設定画面からバックアップを書き出してください。

手入力の料理や市販品をアレンジする場合、元の栄養が不明な項目は不明のままです。原材料や買い物に使う商品量が未確認なら、追加材料を選んでも料理全体が確認済みになることはありません。詳しくは[食材追加の仕様](recipe-arrangement.md)を参照してください。


## 本格麻婆豆腐（陳建一風）

メニューで「麻婆豆腐」または「陳建一」と検索し、料理の種類から「本格・陳建一風（にんにくの芽）」を選びます。通常の「麻婆豆腐」では本格配合を最初に表示し、辛くない配合も選べます。ひき肉は豚が初期値で、牛・合いびき・鶏にも切り替えられます。

葉にんにくの代わりに、にんにくの芽（茎にんにく）を使います。薄く切って先に炒め、豆腐を加える前に硬さを取ります。豆板醤・甜麺醤・豆豉・粉とうがらしを炒め、仕上げにラー油と花椒を加える配合です。表示する材料と栄養は1皿分で、買い物の人数は別に掛かります。調理用の油とラー油も栄養に含めます。

出典と材料ごとの代表値は[本格麻婆豆腐の出典](mapo-sources.md)にまとめています。


## 鍋・ポトフ・おでんを選ぶ

鍋料理は21種類です。「主菜」から肉・魚介・豆腐などの食材カテゴリと「鍋料理」で絞るほか、「石狩」「合鴨」「トマト鍋」など具体的な料理名でも検索できます。入口にまとまっている種類は詳細の選択肢で切り替えます。鍋に含めた肉・魚介・野菜・豆腐・調味料の量と、締めのご飯や麺が材料に入っているかを確認してください。材料表に含まれていない追加分は別に記録し、すでに含まれる具材を二重に登録しないでください。

ポトフは「メニュー」で「ポトフ」と検索して開きます。登録上の区分は汁物です。

1. ベーコン・ウインナー・鶏もも・鶏むね・豚薄切り肉から使う肉を選び、1皿分のg数を入力します。肉なしの野菜だけにもできます。
2. キャベツ・じゃがいも・にんじん・玉ねぎ・セロリ・かぶ・ブロッコリー・マッシュルーム・しめじ・トマトから、使う具材とg数を選びます。野菜は皮や根など食べない部分を除いた調理前の重さです。
3. 煮汁の水をmlで指定します。食塩・黒こしょう・パセリはg数を変更したり外したりできます。加工肉の塩分は別に含まれるので、食塩を外しても料理全体の食塩が0になるわけではありません。
4. 材料・栄養・作り方を確認して記録します。選んだ具に合わせて下ごしらえや加熱順も変わります。1皿の半分を食べたら、記録する量を0.5皿にします。

ポトフは肉・野菜・煮汁の全量を食べる想定です。水も調理量として選び、汁だけを減らす飲用率は設定していません。ラーメンの飲用率や、おでんの飲んだ汁のml数とは別の計算です。

おでんは21種類の具材を選べます。大根・卵・ちくわ・厚揚げ・餅巾着・牛すじに加え、じゃがいも・里いも・ウインナー・結びしらたき・結び昆布・たこ串・さつま揚げ・ちくわぶ・魚のつみれ・ごぼう巻き・うずら卵・ロールキャベツを追加しました。具によっては個数や本数に加え、1個・1本の重さも実物に合わせて変更できます。

おでんの汁は実際に飲むml数の概算です。具に染みた汁もその量へ含める目安で、煮る鍋の汁全量を自動で計上しません。汁を飲まない場合は選択を外せます。さつま揚げなど、商品によって原材料が変わる具材の未確認状態は選んだ記録にも引き継ぎます。材料の状態と出典は[鍋料理・おでんの出典](simmered-sources.md)で確認できます。

## 柚子胡椒の鶏料理と、外食店を参考にしたおかず

「柚子胡椒」または「ゆずこしょう」で検索すると、鶏もも焼き、鶏むねときのこの蒸し物、蒸し鶏とアボカドのサラダ、鶏鍋を探せます。もも肉の皮や、むね肉の皮なしの違いを分け、柚子胡椒と調味料に含まれる食塩も加えています。材料表は2人分、具材を組み立てた画面のプレビューは1皿分なので、表示を確かめて調理してください。

今回はオリジン、ほっともっと、ほっかほっか亭、日高屋、餃子の王将、やよい軒、大戸屋、ガスト、ロイヤルホスト、ココス、鳥貴族、サイゼリヤの公式メニューを参考にしました。黒酢あん、味噌かつ煮、レバニラ、きくらげと肉卵の炒め物、洋食の焼き物や煮込み、コンソメやお吸い物など67料理を加えています。既存の917料理・429食材は書き換えていません。

外食した料理を記録するときにも一般的な目安として選べます。ただし同じ料理名でも、店ごとの量、部位、油、たれ、付け合わせは異なります。今回追加した家庭用配合を、その店の商品表示と同じ栄養値とは扱わないでください。栄養表示が分かる場合は「見つからない食事を入力」から値を入れ、マイメニューに保存できます。原材料やアレルギーが分からない部分は未確認のまま残します。

参照した公式メニューと採用した料理は[弁当・定食](canteen-sources.md)、[中華・焼鳥店](tavern-sources.md)、[洋食店](bistro-sources.md)、[追加した汁物](soup311-sources.md)にまとめています。
