# 麺類の配合・栄養概算（v3.10.0）

確認日：2026-11-13。`noodle-foods.js` は家庭で用意できる代表配合です。特定の店舗のレシピや栄養表示ではありません。

## 重量とスープの扱い

- 中華麺は既存の成分表 **01048「中華めん・ゆで」**を使い、**ゆで上がりの可食部重量**で入力します。生麺や乾麺の重量へ読み替えません。一般モデルは250g/杯、二郎系風は400g/杯とするアプリ内の配合仮定で、店舗の「麺400g」という表示の意味を推定するものではありません。
- 新しい汁ありモデルの「400ml」は、調味料・油・濃縮品を加える前のだし・水の基準量です。出来上がりスープの厳密な体積ではありません。既存4モデルは元の水350ml/杯を保持します。
- 抽出用の骨・煮干し・肉を丸ごと食べた栄養へ加算せず、抽出液または表示済み濃縮スープの栄養を使います。買い物リストも「だしの液体」「濃縮スープ」を扱い、骨や煮干しの必要量へは逆算しません。
- **麺・固形の具・トッピングの全量＋スープ栄養×飲用率**で計算します。麺そのものの塩分は、スープを残しても減りません。新しいレシピは既定で全量飲用です。

| 選択 | 計算用飲用率 |
|---|---:|
| 麺に絡む程度 | 10% |
| 少し | 25% |
| 半分 | 50% |
| ほとんど | 80% |
| 完飲 | 100% |

この比率は本人の選択を計算へ変換する**アプリの仮定**で、医学的・実験的に検証された吸着率ではありません。油・塩分・ごま・味噌がスープに均一に分散すると仮定します。実際には麺・具への付着、浮いた脂、沈んだごまで変わります。

バターは味噌スープに溶かし、背脂は加熱した脂も含めスープに混ぜます。したがって両者は飲用率の対象です。担々麺のごま・ラー油もスープ側、肉そぼろとその炒め油は固形の具側です。卓上にんにくを追加する場合は「追加した分を食べた」として全量を加え、ベーススープ中のにんにくとは分けます。冷やし中華・油そば・汁なし担々麺のたれと油は全量を食べる想定で、スープ飲用率を適用しません。

買い物量はスープを残しても**用意する全量**です。食べた栄養だけを飲用率で減らし、購入量を減らしません。肉・野菜は表示された調理前の可食部重量、焼き豚とメンマ水煮は調理済み重量です。調理による微量栄養の流出・蒸発・脂の流出は未補正で、加熱後のg数と混同しません。

成分表のTrとメーカー未掲載値を実測0へ書き換えず、`rawNutritionPerUnit` ではnull、計算用補完は `estimatedNutrients` と出典説明へ分けて残します。CのTrは既存DBと同じく0.01以上0.05g未満/100gの中央0.03g/100gで近似。食物繊維未掲載の抽出液・濃縮スープ・具なし油は、計算上0g/100gと仮定します。具入り油・繊維添加品へは適用しません。[文科省の凡例](https://fooddb.mext.go.jp/help.html)

豚骨白湯は豚骨抽出物と油を含む製品の一例です。ごま・大豆・豚肉を含む設定。鶏油は純粋な鶏脂ではなく、ごま油等を混ぜた香味油の公式例を使い、大豆・鶏肉・ごまを含めます。中華だしは鶏・豚・野菜の抽出液で、顆粒とは異なります。

背脂は専用値がないため「かたロース・脂身・生」を代理にします。実際の背脂や下ゆで後の含水率は異なります。チャーシューは標準成分表の焼き豚で、脂の多い豚バラ・厚切りなどの店舗商品にはそのまま当てはまりません。しょうゆで味付けする想定から小麦・大豆・豚肉を含めています。実物の表示や実重量が分かる場合はそちらを優先します。

既存食材（中華麺、味噌、しょうゆ、野菜、ひき肉、ごま、ラー油等）は従来のDBを再利用します。出典は食材の `nutritionSource`、全体方針は [nutrition-sources.md](nutrition-sources.md)、四川調味料は [mapo-sources.md](mapo-sources.md) を参照してください。

## トッピングの単位換算

| 選択 | 1表示単位あたりの材料 | 仮定 |
|---|---|---|
| 味玉1個 | 卵1個＋しょうゆ3ml＋みりん1ml＋砂糖1g | 卵は可食部50g。付着・吸収分だけを仮定し、漬け汁全量は食べない。みりんは加熱して使う |
| チャーシュー1枚 | 調理済み焼き豚20g | 厚さ・大きさは商品により異なる |
| 味付けメンマ約1g | 水煮0.85g＋しょうゆ0.06ml＋砂糖0.03g＋ごま油0.025ml＋水0.0242ml | しょうゆ1ml＝1.18g、ごま油1ml＝0.92gとして合計0.998g。出来上がり約100g分の材料合計は99.8gで、水分減少は未補正。煮汁も絡めて食べる配合 |
| 卓上にんにく小さじ1杯 | 生にんにく3g | 食塩・油を含まないおろしにんにく |
| 海苔小片1枚 | 焼き海苔0.5g | 全形1枚ではない |
| コーン・長ねぎ・ほうれん草・もやし1g | 既存食材1g | ほうれん草・もやしは加熱前の可食部を量り、加熱して食べる |
| ゆで卵1個 | 卵1個 | 殻を除く約50g |

味玉・メンマの調味料保持量と各単位重量は一次資料の分析値ではなく、このアプリの計算用配合です。既存のしょうゆ・みりん・砂糖・ごま油・卵の栄養を使って合算します。

## 既存データの互換性

既存の `daily-ramen-soy`、`daily-ramen-salt`、`daily-ramen-miso`、`daily-ramen-tanmen` の材料・レシピ本文・栄養値は変更しません。元の2杯分を正確に半分にしたモデルを別途定義し、水・しょうが・ごま油・しょうゆ・塩・味噌・スープ用にんにくをスープへ分類します。初期トッピングは空で、全量飲用時の材料・栄養が従来どおりになるようにします。インスタント麺や完成品は、製品表示から麺とスープを分離できないため、このモデルへ取り込みません。
