# 手持ち食材の分類と追加食材

手持ち食材は「ジャンル → 種類 → 具体的な食材」の順に選びます。肉は牛肉・豚肉・鶏肉・加工肉・合い挽きや混合・その他へ分けます。各種類では普段使う薄切り肉や一般的な部位を先に置き、内臓や特殊部位を後に置いています。

分類と表示順は `pantry-catalog.js` の食材ID一覧で管理します。名前から肉の種類を推測する方式ではありません。新しい食材で分類が未登録なら、そのジャンルの「その他」に残します。既存食材の材料ID・単位・栄養値は変更しません。

食材を選ぶプルダウンと検索結果には、この分類に登録した調理用の食材を表示します。新しい材料を追加するときは `pantry-catalog.js` の該当分類にもIDを追加してください。料理や市販品を候補から外す条件は `ingredient-options.js` にあります。

## 追加した生肉

| 食材ID | 区分 | 栄養値の根拠 |
| --- | --- | --- |
| `beef_round_raw` | 牛肉 | 文部科学省の食品番号11076。輸入牛もも・皮下脂肪なし・生の可食重量 |
| `beef_pork_mince_raw` | 合い挽き・混合 | 登録済みの牛ひき肉と豚ひき肉を重量比50:50で平均した参考配合 |

牛ももの出典は[文部科学省食品成分データベース・食品番号11076](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=11_11076_7)です。2026年11月15日にページの食品名と数値を確認しました。可食部100g当たりは133kcal、たんぱく質20.0g、脂質6.7g、炭水化物0.4g、食物繊維(0)g、食塩相当量0.1gです。食物繊維の括弧付き0は原表の推定値を表します。和牛や脂身付き肉、調理後の重量には読み替えません。

合い挽き肉は、公式な混合肉の成分値として扱いません。既存の牛ひき肉・豚ひき肉の計算用プロフィールを同じ重さで平均します。直接分析した原値は未登録のままとし、6成分すべてに概算であることを付けています。購入品の牛豚比率や脂肪量が異なる場合は、商品表示に合わせた登録が必要です。

追加2品は `createPantryExtraIngredients()` が別IDのデータとして作ります。この関数は元の食材を変更しません。旧版の食事スナップショットも再計算しません。
