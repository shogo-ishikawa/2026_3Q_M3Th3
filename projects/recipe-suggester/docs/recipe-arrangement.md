# 食材追加とオリジナルレシピ

既存料理の「食材を追加してアレンジ」では、元レシピ1人分に加える食材と量を選びます。元レシピを変更せず、1皿＝1人分の新しい料理として記録できます。保存を選ぶとマイメニューにも残ります。

「オリジナルレシピを作る」では料理名、区分、使う材料と量を登録します。作り方も任意で入力できます。食材はデータベース内の肉、魚介、野菜、きのこ、卵・豆、乳製品、穀類、果物、調味料から選べます。

量は可食部のg数を基本にします。元の単位がmlや個でも、データベースに重量・密度の換算値がある場合はgで入力し、栄養計算と買い物リストでは登録済みの単位に戻します。換算値が未登録ならその食品の元の単位を表示します。骨、殻など食べない部分は入力量から除きます。

追加分は食材に登録された状態の代表栄養値をそのまま合算する概算です。加熱による栄養損失、油の吸収、煮汁の残りは自動補正しません。元レシピが持つ手入力の栄養値も保持し、同じ栄養を二重計上しません。元の栄養値が不明の成分は、食材を足しても不明のままです。

元の料理の原材料・アレルギー確認が未完了なら、その状態を引き継ぎます。食材を足しただけでは確認済みになりません。元料理の買い物用構成も不明なら、料理全体の買い物リストは未確定として表示します。保存・記録した料理はその時点の材料と栄養を持ち、後で元のレシピや食材データを更新しても過去の記録は変わりません。
