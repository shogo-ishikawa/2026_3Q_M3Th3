| 数量在庫の控除 | 手持ちの数量を買い物の必要量から差し引いた |
| 予定の保存 | 提案をカレンダーの予定へ登録できた |
| 再読み込み | 保存した記録と設定を保持した |
| JSON | 書き出し、不正入力の拒否、旧版からの移行を確認した |
| 狭い画面 | 幅337pxでページ全体の横あふれがなかった |

手入力の栄養概算は「材料から栄養の概算を入力する」を押した場合だけ入力欄を更新する設計です。在庫の数量変更では提案を維持して買い物を再集計します。これらの仕様は[使い方](manual.md)と[設計](design.md)にも反映しています。

### 確認していない範囲

全レシピの調理試作、メーカーごとの原材料調査、混入の検査、個人の必要栄養量への適合は確認していません。栄養は成分表と材料数量から求めた概算で、調理中の溶出、油の吸収、食べ残しなどを再現していません。根拠と換算は[栄養値の出典と換算方法](nutrition-sources.md)を参照してください。
