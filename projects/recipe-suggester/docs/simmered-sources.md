# 鍋料理・おでん・ポトフの調査と概算（v3.11.0）

確認日：2026年11月13日。`simmered-foods.js` は鍋の主菜12品と食材10種を追加します。特定店舗の秘伝の配合・分析値を再現したデータではありません。公式の料理例から食材の組み合わせや投入順を調べ、家庭で量を把握できる配合へ組み直しました。材料と手順の全文は同モジュールにあります。

## おでんとポトフの具材選択

`food-composer.js`では、おでんの具材を21種へ拡張しています。新しい製品食材は、つみれ18g/粒・ごぼう巻27g/本（公式包装重量から換算）、うずら卵9g/個・さつま揚げ30g/枚・ちくわぶ30g/切れ（入力のための目安）です。実物のサイズが異なる場合は、具材ごとの「1個・1枚・1本の重さ」欄を変更できます。

おでんは固い具から弱めの火で煮て、煮崩れやすい具は後から入れる構成です。[紀文 定番おでんの作り方](https://www.kibun.co.jp/knowledge/oden/basics/howto/index.html)と、[紀文ちくわぶの加熱方法](https://www.kibun.co.jp/products/all_169430a)を参照しました。既存どおり具材と飲んだ汁の量で計算し、鍋の汁全量を自動で食べたことにはしません。

ポトフは既存のベーコンと野菜の配合を初期値として残し、肉・加工肉・野菜などを選べます。煮えにくい根菜を先に煮て、柔らかい野菜や加工肉は後から加える方法は[キッコーマン 鶏もも肉のポトフ](https://www.kikkoman.co.jp/homecook/search/recipe/00000305/)を参考にしています。選択後はその材料・量・栄養を記録へ確定し、元のレシピや過去の記録を書き換えません。
