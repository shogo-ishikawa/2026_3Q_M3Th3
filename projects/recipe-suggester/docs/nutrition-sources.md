# 栄養値の出典と換算方法

確認日: 2026年11月12日

Meal Palette（ミールパレット）の栄養値は食材や調理済み食品の代表的な成分から求めた概算です。食べた量や商品の表示値を記録できる場合は、その値を手入力する方が実際の食事に近づきます。登録したレシピや個別商品を分析した値ではありません。

## 出典

「日本食品標準成分表（八訂）増補2023年から引用」して換算しました。

- [文部科学省の掲載ページ](https://www.mext.go.jp/a_menu/syokuhinseibun/mext_00001.html)
- [第2章・本表 Excel（2026年3月27日更新）](https://www.mext.go.jp/content/20260327-mxt_kagsei-mext-000029402_02.xlsx)
- [電子書籍（第2章を除く）](https://www.mext.go.jp/content/20260327-mxt_kagsei-mext-000029402_0001.pdf) 第1章・表12「調理方法の概要および重量変化率表」（じゃがいも水煮: PDF41ページ）
- [食品成分データベース](https://fooddb.mext.go.jp/)（2026年6月9日に同正誤表へ対応した旨を確認）
- [食品成分データの利用・引用について](https://www.mext.go.jp/a_menu/syokuhinseibun/)

文部科学省の本表は原則として可食部100g当たりの標準値です。`ingredient-nutrients.js` の `FOOD_PROFILES` に食品番号と6成分を保存し、`INGREDIENT_PROFILES` でアプリの食材IDに対応させています。加工品や総称の食材には代表的な1食品を選びました。その対応は下表に明記しています。栄養値の対応からアレルゲンを推定する処理は行いません。

成分の列はエネルギー `ENERC_KCAL`（G列）、たんぱく質 `PROT-`（J列）、脂質 `FAT-`（M列）、炭水化物 `CHOCDF-`（U列）、食物繊維総量 `FIB-`（S列）、食塩相当量 `NACL_EQ`（BI列）です。利用可能炭水化物や糖類を炭水化物の代わりには使用していません。食物繊維は炭水化物の内数です。

## 単位と未確定値

`nutritionPerUnit` は食材に宣言された1単位当たりの値です。`g` なら1g、`ml` なら1ml、卵の `個` なら1個当たりです。エネルギーの単位はkcal、それ以外はgです。

計算式は `成分表の100g値 × 1単位の可食重量(g) ÷ 100` です。卵は1個の可食部を50gと仮定します。殻付きあさりには成分表の廃棄率70%を適用し、1g当たりの可食重量を0.3gとしています。ほかの魚介や野菜は下処理後の可食部の重量として扱います。

じゃがいもはレシピが加熱を前提とするため、皮なし水煮（食品番号02019）を加熱後の代表値としています。成分表の調理重量変化率97%を用い、材料の可食部1gを水煮0.97gに換算します。例えば材料100gから求める食物繊維は `3.1 × 0.97 = 3.007g` です。生の値8.9g/100gをそのまま加熱後の摂取量に使用しません。蒸す・焼く・煮込むなど複数の調理法を水煮で近似するため、実際の仕上がりによる差があります。[文部科学省の調理重量を用いた栄養計算方法](https://fooddb.mext.go.jp/nutman/nutman_10.html)に従った換算です。

- 成分表の数値を引用します。括弧付きの推定値も使用し、分析値と区別なく正確だとは扱いません。
- `0` と `(0)` は成分表の表示精度でのゼロとして扱います。
- `Tr`、`(Tr)`、`-`、空欄は `null` とします。微量や未測定をゼロに変換しません。
- 適切な個別食品の対応を確認できなかったターメリックとクミンは6成分とも `null` です。
- 無調味カシューナッツはフライ味付け品の主要成分を参考値としています。味付け品の塩分を流用せず、食塩相当量を `null` としています。
- 乾そばと乾そうめんは湯切りで失われる塩分を確定できないため、食塩相当量を `null` としています。乾麺の塩分を全量摂取したと断定しません。
- 無糖・無塩の水、および水と二酸化炭素だけの無糖・無塩の炭酸水は対象6成分を定義上のゼロとしています。ミネラルの評価は対象外です。加糖のサイダーやコーラとは区別します。

`null` を含む献立は、分かる成分の合計と未確定成分の有無を併記します。値がそろわない食材を含む場合に「食塩ゼロ」「栄養十分」などとは判断しません。

## 調理による変化と利用範囲

ご飯・ゆでうどん・ゆで豆と、乾燥パスタ・乾そば・乾そうめん・乾燥押麦を区別しています。表の食品状態と食材の計量状態が合っていることが前提です。

原料をすべて食べるものとして合算する概算のため、じゃがいもの代表的な加熱状態への換算を除き、各レシピの加熱による水分変化、ゆで汁への成分の溶出、揚げ油の吸収率、食べ残し、だし取り後に取り除く昆布やかつお節の分離は再現しません。煮汁や油を残す場合などは摂取量と差が出ます。清酒と本みりんのエネルギーにはアルコールも含まれますが、加熱による蒸発は補正していません。エネルギーを単純な4・9・4換算で上書きしません。

豆類の状態も区別しています。ゆで大豆は黄大豆ゆで（04024）、レンズ豆は全粒ゆで（04094）、ひよこ豆は全粒ゆで（04066）、白いんげん豆と赤いんげん豆は全粒ゆで（04008）の値です。乾豆の値を水煮の材料重量に乗じてはいません。成分表では食物繊維がそれぞれ8.5g、9.4g、11.6g、13.6g/100gと多く含まれます。豆が多い食事では比較目標を超えることがありますが、それだけで異常や過剰摂取とは判断しません。

栄養の比較目標は学習用の編集可能な参考値です。個人の必要量や病気の診断、アレルギー反応の予測を行うものではありません。品種、部位、商品の配合、調理方法、量の見積もりによって結果が変わります。

### 定番メニューと市販品の扱い

焼きそば用の蒸し中華めん、ゆで中華めん、ピザ生地、菓子、アイスクリームなども成分表の代表的な食品へ対応させています。メーカーや店舗の固有商品を分析したDBではありません。商品の表示が分かる場合は手入力で上書きできます。

えび天ぷらは完成品の重量に衣と吸収した油が含まれる値です。揚げ鍋に入れる油の全量を摂取量に加算しません。ツナ水煮は液汁を含む成分表の値なので、水切り後の状態との違いに注意してください。

成分表の微量・未測定値は追加した食品でも `null` を保ちます。コーラやスポーツドリンクの脂質などを、表示にないゼロとして補っていません。

### 生・加熱済み・乾物の区別

刺身の重さは皮や骨を除いた可食部です。表の「生」という状態は生食の可否を示しているわけではなく、刺身用として売られた食品を想定しています。ゆでだこは既存の `octopus`（食品番号10362）を使います。ほっけの開き干し、さんま、からふとししゃも、豚ロースは調理前の可食重量から計算する材料モデルです。加熱による水分変化や流出した脂質の量までは反映していません。

マカロニと即席麺は乾物の重さです。即席麺は添付調味料などを含む1食分を計上し、加える湯は栄養0の水として扱います。スープを残した場合の食塩摂取量は未補正です。食後の重量から計算する場合は商品表示を参照して手入力します。カップそばは専用の行がないため和風カップめんの共通参考値です。味噌・豚骨・シーフードも味ごとの精密値として扱いません。

### 完成品と具のみの区別

カレー類はソースと具、親子丼は具のみ、麻婆豆腐は豆腐を含む完成品の成分表代表値です。ご飯は別に計上し、麻婆豆腐の値に豆腐を重ねて加えません。特定メーカーのレトルト製品を分析した値ではありません。

ハンバーガーはバンズ、調理済みパティ、野菜、ソースなどを積み上げる一般的なモデルです。白身フライとささみフライには衣と吸収した油が含まれるため、揚げ油を追加しません。個別商品に合わせる場合は商品の栄養表示と原材料表示を確認して置き換えます。原材料やアレルゲンが確定しない市販品は、栄養の代表値があっても安全な献立の根拠にはしません。

成分表で括弧付きの数値は参考値として数値を保持し、`Tr` や `-` は `null` を保ちます。追加分では板こんにゃくの脂質、白身フライとささみフライの食物繊維がこれに該当します。しらすや海藻の塩分も無塩の0に置き換えていません。
