# メニューの調査と分類の見直し

確認日：2026年11月13日 ／ 対応版：v3.2.0

## 調べた目的

主菜や副菜を探すときに、肉や魚などの食材と唐揚げや焼き物などの調理法が同じ段に並んでいました。表示を「主菜・副菜 → 食材カテゴリ → 調理法 → 個別のメニュー」へ整理し、日常の食事で選びやすい料理が足りない部分も確認しました。

食堂、外食チェーン、学食、レストラン、居酒屋の代表的な公開メニューを参照しています。すべての店や料理を網羅した調査ではありません。価格や季節限定品の販売状況は本DBの対象外です。

## 本DBでの扱い

公開メニューは、料理の種類や構成に不足がないかを調べるために参照しました。店名を使った再現レシピや商品別の栄養データは登録していません。料理名は一般的なものを選び、材料・分量・作り方は教材用の家庭向け例として記述しています。各社の紹介文、写真、レシピは転載していません。

栄養は登録食材の量と公的な成分表から求める概算です。実際の外食は商品ごとに分量や原材料が異なるため、同じ名前の料理でもこの値と一致するとは限りません。商品表示の数値で記録したい場合は手入力を使います。市販食品の一般例に設定した「原材料未確認」の扱いも維持しています。

## 既存メニューの見直し

- 既存の主菜・副菜を料理ごとに確認し、主な食材と調理法を割り当てました。
- しょうゆや油などの原材料だけを理由に、豆料理や肉料理へ分類していません。
- 複数の食材を使う料理には補助の食材カテゴリを設け、どちらの入口からも探せるようにしています。同じ検索結果へ二重には表示しません。
- じゃがいものコロッケ、肉のメンチカツ、魚のフライなどは、料理名の一部分だけでまとめず内容に応じて分類しました。
- 既存の「合いびきハンバーグ」は普通の牛豚合いびき肉の料理です。同じ内容を別名で追加せず、肉の焼き物から探せるようにしました。
- 過去の記録が参照するIDと材料・分量を保ち、表示の分類を別のモジュールで管理しています。

## 今回追加した料理

定番料理を87品追加し、収録数は667品、食材・調味料は241種類になりました。主菜・主食の追加が50品、副菜・汁物の追加が37品です。

| 分野 | 追加例 | 記録するときの扱い |
| --- | --- | --- |
| 主食 | カツ丼、天丼、天津飯など | ご飯と具を含む1皿。別のご飯を重ねて登録しない |
| 魚介 | エビフライ、ムニエル、かれいの煮付け、ぶり大根など | 主菜の魚介カテゴリから調理法を選ぶ |
| 肉 | 和風おろし・チーズ・煮込みのハンバーグ、シチューなど | 主菜の肉カテゴリから焼き物や煮込みを選ぶ |
| 鍋 | 水炊き、寄せ鍋、すき焼きなど | 人数で分けた具と汁を基準にする。締めや追加のたれは別に記録する |
| 野菜・サラダ | 生野菜、野菜スティック、シーザーサラダ、温野菜など | ドレッシングや卵・チーズなどの添え物も材料と栄養に含める |
| 汁物 | ポトフ、ミネストローネなど | 汁物として主菜とは分けて記録する |

各料理は名称だけでなく材料・作り方も既存メニューと照合しました。異なる名前で同じ配合を増やさず、同じ一般料理でも味付けや調理法が異なる場合は違いが分かる名称にしています。

参照URLと追加メニューID、家庭向けに変更した点、重複追加を見送った判断は[調査対応データ](menu-research-data.json)にまとめています。
