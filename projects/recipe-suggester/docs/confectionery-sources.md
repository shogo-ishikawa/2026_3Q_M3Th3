# 市販のお菓子とスナックの出典

確認日：2026-11-13。メーカー公式の商品ページで確認した34品の記録例です。献立の手作りレシピとは分け、購入した完成品として扱います。

## 表示量と栄養の扱い

- 数値は表に示した量の栄養表示です。エネルギーはkcal、その他はgです。入力した量に合わせて倍率換算します。袋を食べきることを勧める量ではありません。
- ポッキーなど本数別の表示がない品はg入力です。箱や大袋の総量と内袋1袋を区別します。飴・グミの1粒はアプリでは1個とし、標準重量を併記します。
- ソフトサラダは2枚で1個包装という公式表示を使います。入力1枚なら栄養は半量、買い物量は小袋の半分です。
- 未表示や範囲表示はnull（不明）です。中央値を推測したり0とみなしたりしません。表示が0の項目だけ数値0を使います。
- 量は1人分、食材は2人分です。買い物リストには完成品の袋・枚・個などを加え、製造原料へ分解しません。
- 商品表示のアレルゲンを参考情報として登録していますが、全原材料や共通設備まで網羅したDBではありません。全品でallergensKnownとingredientsKnownをfalseとし、自動献立の候補に加えません。
- 食材単体の栄養は全項目nullです。完成品の公式表示をmanualNutritionに持たせ、重複加算を避けます。実物のパッケージが異なる場合はそちらを優先してください。
- メニューには店舗名を含めません。ポッキーなど、利用者が指定した商品を探せるように製品ブランド名を使っています。一般名の項目も参照した製品と規格を下表に明示します。

- さやえんどうしお味61g：食塩相当量0.4〜0.9gは不明です。食物繊維6.5gは単一値として保持します。
- マイクポップコーン バターしょうゆ味50g：食物繊維3.4〜7.0gは不明です。製造はジャパンフリトレー、販売はカルビーです。旧フリトレー商品ページだけでは栄養表を取得できないため、販売者の現行商品ページを参照しました。
- コロロ巨峰48g：公式ページ本文で確認したたんぱく質0.4g・炭水化物33.7gを使います。検索結果に残っていた旧表示0.5g・33.6gを転記しません。

- プリッツは塩味ですが製品形態を基にビスケットへ、チーザはおつまみのスナックへ分類します。分類は栄養の優劣を示しません。
