## そのほかに確認したこと

- **生成AIモードの成功時の流れ**（模擬サーバー）：API への送信は1回で、送信先は `/v1beta/interactions`、モデル名は `GEMINI_MODEL` の値、JSON Schema 付きの `response_format` と `store: false` が送られた。APIキーはヘッダー `x-goog-api-key` で送られ、本文には含まれない。単価表にない食材ID（`beef`）の候補は採用せず、ほかの候補は「生成AIによる提案」と表示し、費用は Python で計算した。
- **SDK の自動導入**：google-genai が入っていない Python 3.12 の新しい環境で、有効にしたときだけ pip で 2.3.0 以降（2.33.0）が導入され、同じセッションのまま import して呼び出せた。2回目は導入し直さなかった。
- **SDK の再試行回数**（google-genai 2.33.0、模擬サーバー）：何も設定しないと、429 や 5xx のときに同じ要求が最大4回送られた。ノートブックでは `retry_options` の `attempts` を 1 にしており、このときの送信は 429／5xx で2回、400／403／404 で1回だった。
- **Colab のシークレット**（模擬モジュール）：未登録、アクセス不許可、時間切れのそれぞれで説明を表示して切り替え、登録済みのときは前後の改行を除いたキーで呼び出した。
- **データ**：レシピ20品すべてで、材料の食材がすべて手順に出てきて、手順に出てくる食材はすべて材料にあること、手順に分量を書いていないことを確認した。分類の全選択肢がデータに含まれ、レシピIDと単価表の表示名は重ならない。
- **Python の版**：Python 3.11／3.12／3.13 で同じ64項目を確認した。Python 3.9／3.10 は、構文として読み込めることだけを確認した（実行はしていない）。
- **秘密情報など**：プロジェクトのファイルに、APIキーらしい文字列、キーの直書き、学籍番号やメールアドレスのような個人情報がないことを確認した。
