# 汁物の小分類

「メニュー」の区分を「汁物」にすると、「種類」から次の小分類へ絞れます。「記録」でも「区分 → 汁物 → 種類」と進むと同じ分類を使えます。既存の86品を10分類に整理しています。

| 小分類 | 収録数 | 主な料理 |
| --- | ---: | --- |
| みそ汁・豚汁 | 9 | 豆腐とわかめ、なめこ、あさり、豚汁 |
| お吸い物・和風の汁物 | 11 | お吸い物、すまし汁、かきたま汁、けんちん汁、すり流し、すいとん |
| あら汁 | 2 | 鮭のしょうゆ仕立て、ぶりのみそ仕立て |
| コンソメ・オニオンスープ | 4 | コンソメ、野菜のコンソメ、あめ色玉ねぎ、オニオングラタン |
| 野菜スープ・ポトフ | 11 | ミネストローネ、ガスパチョ、ポトフ、野菜や豆のスープ |
| ポタージュ | 12 | かぼちゃ、コーン、にんじん、じゃがいも、市販カップスープ |
| クリーム・チャウダー | 11 | ミルク・豆乳スープ、きのこのクリーム、クラムチャウダー |
| 中華スープ | 19 | ワンタン、酸辣湯、春雨、卵、わかめ、中華風コーン |
| 韓国・エスニックスープ | 6 | トムヤムクン、ユッケジャン、ココナッツやカレー風味 |
| その他の汁物 | 1 | きゅうりとヨーグルトの冷製スープ |

同じ料理の味違いは、これまでどおり料理の詳細内で選びます。即席のカップスープ6品はポタージュ、即席の春雨スープ5品は中華スープへまとめています。「調理・提供形態」から即席だけを選ぶこともできます。

新しく作るオリジナルレシピは、料理名やジャンルから小分類を求めます。分類を明示して保存したメニューはその設定を使います。名前だけで判別できない汁物は「その他の汁物」に残します。鍋料理やラーメンは主菜・主食の分類を維持します。

## 保存データと計算

分類は一覧を探すための表示情報です。既存レシピのID、名前、材料、栄養、量、調理手順は変更していません。旧版の大まかな`family: 'soup'`や`'miso-soup'`もデータ内では保ち、`recipeFamily()`が表示用の小分類を返します。

`catalogFamilies()`と`catalogVariants()`をメニューと記録の両方で使い、料理の漏れ・重複を防ぎます。汁物の基準量が明示されていない場合は、どの小分類も従来と同じ1杯を使います。半杯などの記録もこれまでどおり可能です。過去の記録は登録時の栄養と材料を保ちます。
