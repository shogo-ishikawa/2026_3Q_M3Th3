# 汁と具の摂取割合のモデル（v3.14）

材料から栄養を計算できる家庭用の汁物・鍋料理97品に、汁を残した割合を指定できます。選択式ポトフにも、現在選んでいる具材をそのまま使って適用します。料理・食材のデータベースの分量や既存の栄養値は変更しません。

## 栄養と買い物の扱い

`SOUP_INTAKE_STAGES` は、飲まない0%、具に絡む程度10%、少し25%、半分50%、ほとんど80%、全量100%です。麺類の割合と揃えています。具は初期値100%で、必要に応じて0・25・50・80・100%に変更できます。APIは0〜1の任意の有限数も受け付けます。

各材料の「汁へ入る割合」を `b`、汁を飲んだ割合を `r`、具を食べた割合を `s` とすると、材料の栄養へ掛ける係数は `b*r+(1-b)*s` です。汁と具がともに100%なら、従来の1人分の栄養値をそのまま返します。具に肉や魚を割り当てた場合、汁0%でもその脂質・たんぱく質は具側に残ります。

生成するマイレシピは1人分へ正規化し、`manualNutrition` に摂取した栄養を保存します。材料表は**残す汁も含め、用意する1人分の全材料**を保持します。買い物集計はこの材料表を使います。全量を飲む場合と残す場合で、用意する食材は変わりません。記録時の栄養と材料はスナップショットに保存され、過去の記録は変更しません。保存形式には計算の説明である `sourceNote` と既存の `manualNutrition`、共通の `nutritionBasis:'estimate'` を使い、専用の摂取率フィールドは増やしません。

## 材料配分の監査

`soup-intake.js` の `AUDITED_PARTITIONS` に、レシピIDごとの全材料と汁側の材料を明示しています。全材料にない食材が追加された組み合わせには操作画面を出しません。材料名や調味料の種類を推測して、任意の料理へ自動適用しません。

- みそ汁・お吸い物・あら汁・チャウダー・その他の家庭用スープ75品と、鍋料理22品が対象です。
- 水、液体だし、溶かしたみそや塩、汁に混ぜた油や乳類などを、各料理の手順に沿って汁側へ配分します。
- 水炊き・豚しゃぶしゃぶ・湯豆腐の付けだれは具側です。汁を飲まなくても、選んだ具と一緒に付けだれを食べる仮定です。
- ちゃんこ鍋と鶏団子スープのしょうが・片栗粉は肉だねに残します。鶏むね肉の塩レモン鍋の片栗粉も、肉にまぶす材料なので具側です。
- 手作り皮のワンタンスープは、水の10%と塩・しょうゆの半量を皮・肉だね側に残します。市販皮を使う豚ワンタンは、しょうゆ・ごま油の半量を肉だね側に残し、肉だねの塩・黒こしょう・しょうがは全量を具側に残します。
- 豆乳担々鍋でひき肉と炒める油・にんにく・しょうが・豆板醤・甜麺醤は具側です。後で汁へ溶かすみそ・しょうゆ・豆乳・すりごま・ラー油は汁側です。
- なめらかに混ぜるポタージュ8品は、全材料を均一なスープとする明示的な仮定を使い、全体を食べた割合だけで計算します。かぼちゃのココナッツスープはかぼちゃを潰さないため、この方式には含めません。
- すり流し汁は、すりおろしたれんこん・なすを汁側へ、きのこや薬味の固形具を具側へ分けます。

選択式ポトフは、専用ビルダーの名前・説明・家庭料理区分に加え、既知の材料のみで構成され、材料から再計算した栄養とビルダーの合計値が一致することを確認します。この場合に限り、水・塩・黒こしょうを汁側、選んだ肉・野菜・パセリを具側として適用します。

## 対象外と限界

市販品や外食の公式合計栄養、任意の手入力による合計栄養は、具と汁に分解できないため対象外です。すでに割合を適用したマイレシピへ重ねて適用することも防ぎます。

ラーメンは既存の麺・具・スープの専用モデルを使います。選択式おでんは、従来から「実際に飲む汁のml」を選ぶモデルです。こちらの買い物量を新しい意味へ変更しません。

煮汁は均一と仮定します。実際には、脂が浮く、みそが沈む、具が塩分を吸う、肉の脂が汁に溶ける、といった違いがあります。本機能はこれらの移動量を自動推定しません。だし用乾物なども既存データの配合栄養を引き継ぐ概算です。説明は操作画面と保存後の出典欄に表示します。
