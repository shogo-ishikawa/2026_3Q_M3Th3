# 献立ノート

避けたい食材を指定し、最近の食事も振り返りながら献立を考えるブラウザアプリです。料理を選ぶだけでなく、材料・分量・作り方をアプリ内で確認できます。

205品（主菜96品・副菜68品・汁物40品・ごはん1品）と143種類の材料を登録しています。

**[ブラウザで開く](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/recipe-suggester/)** ／ [使い方](docs/manual.md) ／ [コード一式（ZIP）](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/recipe-suggester/dist/meal-planner_v1.1.0.zip)

[学生オリジナル「AI献立スマートシェフ」を開く](https://cish25155-prog.github.io/SmartChef/)

## できること

| 機能 | 内容 |
| --- | --- |
| 食材を避けて提案 | アレルギー表示の対象29品目と、登録済みの個別食材を除外条件にする |
| 献立づくり | 主菜・副菜・汁物を組み合わせ、丼や麺などを除いてごはんを添える。夕食1〜7日分、1〜8人分を指定できる |
| ジャンルと気分 | ジャンルをおまかせ・1種類・割合で指定する。さっぱり・ガッツリ・時短・定番や、優先したい食材を選べる |
| レシピを見る | 材料と調味料、人数に合わせた分量、調理の目安時間、作り方を表示する |
| その日は作らない料理を外す | 「今回は除外」で日ごとに一時的に外し、買い物リストと食事の記録の対象から外す。後から戻せる |
| 食事の記録 | 食べた料理を登録する。外食なども料理名と食品群で記録できる |
| 記録を使った提案 | 最近の記録を参照し、料理の繰り返しや食材の種類の偏りを減らす候補を優先する |
| 買い物リスト | 作る料理の材料を人数に合わせてまとめる。家にあるものをチェックし、購入対象から外せる |
| 保存と持ち運び | このブラウザに設定・食事の記録を保存し、JSONファイルで書き出し・読み込みができる |

## 食材のチェックについて

アレルギーの除外条件は、献立作成でも料理の差し替えでも優先します。候補がなくなっても条件を自動で外しません。料理をそろえられない場合は、足りない区分を表示します。

追加の食材除外では、登録された原料の関係もたどります。例えばトマトを除外すると、トマト缶とトマトペーストも候補から外します。原料やアレルゲン情報が不明な料理は提案しません。

チェックの対象は、登録した食材と調味料の情報です。市販品の配合、代替品、製造・調理中の混入までは判定できません。実際に使う商品の原材料表示と調理環境を確認してください。選択肢にない食品も、登録食材にあれば個別に除外できます。

「バランス」の表示は、記録された食事に含まれる食品群と料理の重複から考える目安です。栄養素量・エネルギー・塩分を計算した判定ではありません。記録していない食事を「食べていない」とは扱いません。

ジャンル、気分、優先食材は、除外条件を守った候補の中で使う希望です。希望のジャンルに候補がない場合は、そのことを示して別のジャンルから提案します。食材の除外条件を緩めることはありません。

## まず試すには

1. アレルギーの対象と、追加で避けたい食材を選びます。
2. 日数・人数・開始日と、ジャンル・気分などの希望を選んで献立を作ります。
3. 料理を開いて材料と作り方を確認します。差し替えや「今回は除外」で調整できます。
4. 買い物リストで家にある食材を外し、必要なものを確認します。
5. 食べた内容を記録し、次の献立を作って変化を比べます。

食事の記録と設定はブラウザ内に保存します。作成途中の献立は保存しません。アカウント登録やAPIキーは不要です。共有PCでは、利用後に記録を削除してください。別の端末で使いたいときはJSONを書き出して持ち運べます。
