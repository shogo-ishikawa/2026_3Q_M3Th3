# Meal Palette（ミールパレット）

対応版：v3.15.0 ／ 更新日：2026年11月14日

食事の記録、栄養の振り返り、次の献立と買い物をつなぐブラウザーアプリです。食べたものを種類から選び、ご飯はg、飲み物はml、おにぎりは個数で記録できます。旧「献立ノート」の機能を引き継ぎ、6つのタブで操作を切り替えます。

v3.15.0では「メニュー」のカードに、料理の種類を見分ける小さなイラストを加えました。イラストは種類を示す目印で、実際の盛り付け・量・材料を表すものではありません。食べる量や配合は料理詳細と数量欄で確認できます。

## 6つのタブで使う

| タブ | できること |
| --- | --- |
| 献立 | 朝・昼・夕をまとめて提案する。主食をおまかせ・固定・追加なしから選び、提案後も食事ごとに調整する |
| 記録 | 食事を選ぶ・お気に入りから呼び出す・文章からまとめる。定番セットのコピーと作り置きの取り分けにも対応する |
| 栄養 | エネルギー・たんぱく質・脂質・炭水化物・食物繊維・食塩相当量を概算し、1日・7日・30日の記録を振り返る |
| メニュー | 料理の種類や具材を詳細で選び、材料と作り方を確認してその場で記録する |
| 買い物 | 人数分の必要量から手持ちを引き、生米・皮付き重量や包装数へ換算する |
| 設定 | 比較用のプロフィールや数値を設定し、JSONで記録を保存・読み込みする |

起動時は「献立」を開きます。タブは表の順に並び、特定の画面を指定したリンクからも移動できます。

## メニューを選んで量を記録

「ご飯」と「おにぎり」は別の大分類です。ご飯の中で白米・玄米・炊き込みご飯・わかめご飯などを選び、おにぎりは塩・鮭・梅・ツナマヨなどから選べます。

うどん・そば・パスタ・焼きそば・カレーライス・ピザ・チャーハンなども種類ごとに探せます。飲み物は水やお茶、コーヒーなどから選び、水の中にレモン水や炭酸水をまとめています。みそ汁は具の違いを小分類で選べます。間食にはチョコレート、飴・キャラメル・ラムネ、グミ、クッキー・ビスケット、スナック菓子、せんべい・米菓、ドーナツ、ケーキ、和菓子、アイス・氷菓を用意しています。ポッキーなどの商品例もあり、チーズや果物、ホットスナック、補食も別の種類から探せます。

「記録」ではまず主食・主菜・副菜などの区分を選びます。主菜と副菜は食材カテゴリから調理法へ進み、具体的な料理を選びます。例えば「主菜 → 肉 → 揚げ物」や「主菜 → 魚介 → 刺身」から探せます。唐揚げ、フライ、カツ、コロッケは「揚げ物」にまとめ、最後に料理名を選びます。刺身なども食材からたどる構成です。枝豆や冷奴、卯の花、ひじき煮、ポテトサラダなども副菜から探せます。

「メニュー」の区分は「すべて → 主食 → 主菜 → 副菜 → 汁物 → 飲み物 → 間食」の順です。主菜・副菜と「すべて」では食材カテゴリと調理法で絞り込み、主食・汁物・飲み物・間食では従来の種類を使います。複数の食材を使う料理は別のカテゴリからも見つかる場合がありますが、同じメニューを重複して表示しません。

v3.2.0では肉野菜炒め、焼き鳥、煮魚、ムニエル、鍋料理、シチューなどの主菜に加え、丼やドリア、生野菜サラダ、温野菜、揚げ出し豆腐、ポタージュなどを補いました。詳しい見直し方は[メニューの調査と分類](docs/menu-research.md)にまとめています。

| 絞り込み | 選択肢の例 |
| --- | --- |
| 食材カテゴリ・調理法 | 肉 → 揚げ物、魚介 → 刺身、野菜・いも → サラダなど。主菜・副菜で使う |
| 種類 | ご飯、おにぎり、うどん、みそ汁、水・炭酸水など。主食・汁物・飲み物・間食で使う |
| ジャンル | 和食、洋食、中華、エスニック、その他 |
| 調理・提供形態 | 手作り、即席、レトルト、ファストフード、そのまま。調理法とは別の条件 |

カップ麺はラーメン・うどん・そばなど元の料理の種類から探せます。レトルトのカレーは詳細でご飯量を指定できます。ご飯を含む丼やカレーでは、同じご飯を別に重ねて登録しないよう基準量を確認してください。市販品には食品成分表や配合から求めた一般例と、メーカー・販売元の公式表示を使う商品例があります。商品や全原材料が未確認のものは自動提案に使いません。食べたものの記録はできるので、商品の表示に合わせたい場合は手入力で自分のメニューを作れます。

握りと軍艦は1貫、細巻・太巻は切った1切れ、寿司の盛り合わせは1皿を基準に記録します。例えば握りを3貫食べたら「3貫」と入力します。料理ごとの基準量も確認してください。

「飲み物」には清涼飲料水、プロテイン飲料、お酒を分け、間食には「補食・栄養補助食品」を加えました。ソイとホエイ、水割りと牛乳割りも選び分けられます。商品例の栄養は公式表示の確認時点の参考値で、不明な成分は不明のまま扱います。原材料やアレルギー情報が未確認の商品は自動提案に使いません。お酒も飲んだ量の記録用で、献立には提案しません。

メニュー詳細の「カレンダーに追加」では日付、朝食などの食事区分、予定か実績か、量を指定できます。

1人分を150gとするご飯を100g食べた場合、栄養と材料は`100 ÷ 150`倍になります。献立で指定した量もカレンダーと買い物へ引き継ぎます。買い物用の人数は別に設定するため、家族4人分を作っても自分の摂取量が4倍になることはありません。

DBにない食事は名前と量だけでも手入力できます。栄養成分表示や材料が分かれば補い、自分のDBにも保存するか選べます。空欄は不明のまま残し、共通DBへ自動で送信しません。

「記録」では選択日欄の「選んだ日の入力をリセット」でその日を消せます。下部の「記録をリセットする」では指定範囲をまとめて処理できます。食事・料理・完了チェックの対象件数を確認してから実行します。予定だけのリセットでは完了チェックを保ち、実績を含む場合は範囲内の完了を取り消します。直後は「直前のリセットを戻す」を使えます。

## ご飯のお供やサラダを組み合わせる

少量で添える納豆、おろし納豆、ゆで卵は副菜から選びます。納豆を使う丼や、主菜として組み立てた卵料理まで一律に副菜へ移すものではありません。

ツナは油漬けと水煮を分け、生卵、温泉卵、味付けのり、たらこ、明太子、鮭フレークも単品で記録できます。例えばご飯と納豆、牛丼と生卵を別々に追加し、実際に食べた組み合わせを残せます。収録しているすき焼きのように卵を含む料理では、同じ卵を重ねて登録しないよう材料を確認します。単品にはご飯や別添えのたれを含めないため、それぞれの量を確認して加えます。

「生野菜サラダ（ドレッシングなし）」の詳細では、使う野菜とg数、ドレッシングの種類とg数を選べます。レタスやキャベツ、トマトなどは生、ブロッコリーはゆでた状態の量で扱います。選んだ内容から栄養と材料を計算し、その組み合わせでカレンダーへ追加できます。繰り返し使う場合は「この組み合わせをマイメニューにも保存」を選べます。ドレッシングは家庭用の配合による概算で、市販品の表示値とは区別します。既存のサラダもそのまま選べます。

単品食品の基準量と出典は[ご飯のお供の出典](docs/accompaniment-sources.md)、サラダの計量と操作は[サラダの組み合わせ](docs/salad-builder.md)にまとめています。

## 料理の中で具材や種類を選ぶ

肉じゃがは牛肉か豚肉を選び、お好み焼きは豚玉、イカ玉、シーフード、モダンなどをもとに具材と量を調整できます。豚バラ肉、イカ、えび、餅、ねぎ、麺の有無に合わせて材料と栄養を計算し、作り方も更新します。ソースやマヨネーズも使う量に含めます。

うどん、そば、パスタ、みそ汁、オムレツなどは同じ料理を1つの入口へまとめ、詳細の中で種類を選びます。選んだ料理の材料と栄養、作り方、基準量を確認してカレンダーへ追加できます。即席やレトルトなどは手作りと区別して選べます。好みの具材で作った組み合わせはマイメニューにも保存できます。

具材の選択はその場で計算するので、組み合わせの数だけ共通DBへメニューを増やす必要はありません。以前のレシピとIDは保ち、過去の食事も書き換えません。詳しくは[料理の具材選択](docs/dish-customisation.md)と[バリエーションの整理](docs/menu-variations.md)をご覧ください。

カレーのご飯量は1人分の炊飯済み重量です。カレーの具・ルーの量は変えず、ご飯だけを置き換えます。初期値は150gで、0gはルーのみです。ナンはプレーン、ガーリック、バター、チーズ、ごま、全粒粉から別に選びます。米の内訳が分からない手入力の完成品は分離しません。詳しくは[カレーのご飯量](docs/curry-rice.md)と[エスニック料理・ナンの出典](docs/world-food-sources.md)をご覧ください。

麺料理は味玉、チャーシュー、メンマ、卓上にんにくなどを選び、スープは「麺に絡む程度・少し・半分・ほとんど・完飲」から指定します。順に10・25・50・80・100%を飲んだという仮定で、スープの栄養だけに掛けます。麺と具は表示量を食べるモデルです。汁なしの料理はたれも全量に含めます。店舗の実測値や、残したスープの正確な分析値ではありません。配合と計算方法は[麺料理の出典](docs/noodle-sources.md)、刺身の魚種と標準重量は[刺身の出典](docs/seafood-sources.md)にまとめています。

## 鍋・ポトフ・おでんを選ぶ

鍋は寄せ鍋、キムチ鍋、ごま豆乳鍋などに加え、石狩鍋、合鴨と焼きねぎの鍋、かきと豆腐の味噌鍋、常夜鍋、チーズトマト鍋などを選べます。同じ料理の入口で種類を切り替え、材料と具体的な手順を確認します。鍋の米や麺、締めの追加分は材料表を確認して別に記録します。

ポトフでは肉5種類と野菜・きのこ10種類から、食べる具とg数を選びます。煮汁の水・食塩・黒こしょう・パセリも分けて指定できます。具材と煮汁を全量食べる概算で、おでんの「飲む汁」やラーメンのスープ飲用率とは異なります。おでんは21種類の具材の個数・本数などを選び、具によっては1個あたりの標準重量も変更できます。実際に飲んだ汁のml数も入力します。

柚子胡椒は鶏もも焼き、鶏むねときのこの蒸し物、蒸し鶏とアボカドのサラダ、鶏鍋に使います。肉と柚子胡椒のg数、たれや汁の量も栄養へ反映します。新しい料理の参照先は[鍋料理とおでん](docs/simmered-sources.md)、[弁当・定食のおかず](docs/canteen-sources.md)、[中華・焼鳥店のおかず](docs/tavern-sources.md)、[洋食店のおかず](docs/bistro-sources.md)、[追加した汁物](docs/soup311-sources.md)にまとめています。

## 料理を探して作り方を確認する

「唐揚げ」「からあげ」「カラアゲ」や「焼売」「しゅうまい」「シューマイ」など、収録料理でよく使う表記を同じ検索語として扱います。料理名と食材名のかな・カタカナ、漢字の別表記、半角・全角をそろえ、記録とメニューの検索、使いたい食材・避けたい食材の検索で共通に使います。「鶏肉 しょうが」のように空白で区切ると、すべての語を含む候補へ絞れます。料理名に一致する候補を先に表示し、材料だけに含まれる候補はその後に続きます。未知の漢字を自動で読む機能ではなく、辞書に登録した表記へ対応します。

手作りは材料に加えて下ごしらえ、加熱の進め方、火の通りや仕上がりの目安を表示します。工程数は料理に合わせ、簡単な盛り付けを無理に長くすることはありません。即席、レトルト、ファストフード、購入済みの食品には3工程の作り方を付けず、商品名や量、栄養の基準と出典を中心に示します。調理や再加熱が必要な場合は、商品の表示を確認してください。

追加した家庭向けの料理は[定番料理の追加調査](docs/menu-research-v3-4.md)と[家庭向け料理5品の出典](docs/comfort-food-sources.md)にまとめています。菓子やスナックは[菓子の商品表示](docs/confectionery-sources.md)、ドーナツやケーキなどは[スイーツの商品表示](docs/dessert-sources.md)を参照できます。

惣菜や持ち帰り料理の見出しには店舗名を入れず、「焼き鳥・もも（たれ・テイクアウト）」などの一般名を使います。栄養値の参照商品、規格、基準量、公式URLはメニュー詳細の出典と[即席食品・惣菜・持ち帰り料理の出典](docs/takeaway-food-sources.md)へ残しています。表示名を一般化しても、栄養値は出典の商品を参考にした記録例です。同じ料理でも商品や量によって異なるため、手元の表示を優先してください。

## 栄養を振り返る

食べた記録だけを1人分で集計します。予定や未記録の食事は摂取量へ加えません。不明な栄養は0とせず、分かる量と区別して表示します。家庭向けレシピの栄養は食品成分表と材料の分量から求めた概算です。商品の記録例には公式の栄養表示を使うものもあり、説明に出典と基準量を示します。

その日の飲食をすべて登録したら「この日の飲食をすべて記録した」を選びます。最近の平均には記録を完了した日を使い、成分が不明な日はその成分の平均から除きます。計算に使った日数も表示するので、入力途中の日が平均を小さく見せることを避けられます。

「設定」では18歳以上の年代、基準表の性別区分、普段の活動量を選び、厚生労働省の「日本人の食事摂取基準（2025年版）」から比較の目安を選べます。数値を自分で設定する方法も使えます。体格に応じた必要量の計算や健康状態の診断ではありません。妊娠・授乳中、18歳未満、治療用の自動設定には対応していません。

酒・飲料・補食の商品例は[商品表示の出典](docs/performance-food-sources.md)にまとめています。食品の対応や換算は[栄養値の出典](docs/nutrition-sources.md)、年代別の目安は[食事摂取基準の出典](docs/dietary-reference-sources.md)にまとめています。

## 献立から買い物へ

献立は朝・昼・夕の3食をまとめるか、朝食・昼食・夕食・間食のいずれかを選び、1〜7日分作れます。買い物は1〜8人分です。必要な候補が足りない場合は途中までの献立を保存せず、条件の見直しを案内します。

主食は「献立に合わせる」「種類と量を指定する」「別の主食は付けない」から選びます。提案後も各食の「この食事の主食を調整」で変更できます。ジャンルや比率、気分、優先する食材、飲み物の希望も設定できます。パスタやカレーライスなど一品で主食を含む料理には、別の主菜やご飯を重ねることを避けます。

アレルギーと個別食材の除外は候補選びでも変更時でも優先します。候補が足りなくても条件を自動で外しません。市販品の配合や混入は判定できないため、実際に使う商品の表示も確認してください。

「献立はどうやって選ぶ？」では候補選びの順序を確認できます。先にアレルギーと除外食材、確認状況を検査し、残った候補からジャンルや気分、最近の重複、優先食材、在庫を考慮します。記録がある場合はエネルギーと食塩の摂りすぎ、たんぱく質と食物繊維の少なさも順位に反映します。脂質と炭水化物は集計・表示しますが、この順位計算には使いません。希望ジャンルや気分の候補がなければ別の候補を使う場合があり、全成分を目標へ合わせる最適化ではありません。

収録したテイクアウト、即席食品、市販の菓子・スイーツには原材料やアレルギー情報が未確認の記録例があり、自動提案には入りません。食べた事実の記録はできます。商品表示を確認して登録したマイメニューは条件の検査を通れば候補になります。お酒は確認状況にかかわらず記録専用です。

提案した献立を確認して予定へ登録し、食べたら内容と量を直します。買い物リストは提案中の献立かカレンダーの予定を使い、同じ食材の必要量を合算してから在庫を一度だけ差し引きます。在庫の数量更新では提案を維持して再計算します。食べた実績から在庫を自動で減らす機能ではありません。

ハンバーガーなど購入品の構成を登録したメニューは、調理用の肉やパンへ分解せず完成品の個数を買い物へ反映します。レトルトのご飯込みメニューは具とご飯を別々に集計します。買う商品量が分かっていても原材料が未確認の場合は注意を表示するため、実際の商品表示も確認してください。

## 記録を手元に残す

食事の記録、プロフィール、自分のDB、手持ちの食材や設定はブラウザー内に保存します。ログインやAPIキーは不要です。GitHubや共有DBへ個人の記録を送る機能と、端末間の自動同期はありません。

「設定」の「データを書き出す」でJSONを保存できます。読み込み時は形式を検査し、確認後に現在のデータを置き換えます。v3.0.0〜v3.4.0の保存データとJSONはそのまま使えます。保存形式は引き続きversion 3です。旧「献立ノート」のv1・v2の記録も引き継げます。旧版では1日の記録がそろっているか分からないため、完了した日のチェックは自動で付けません。過去の食事は記録時点の内容を保ち、今回の分類整理で栄養や量を計算し直しません。以前の記録に残る店舗名も自動で改名しません。
