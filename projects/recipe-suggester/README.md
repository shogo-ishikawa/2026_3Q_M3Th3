# 料理・レシピ提案

料理の種類、食材、ジャンル、食事の場面などを指定すると、条件に合う料理とレシピを提案する教材です。

教員がGoogle Colabで動く初期コードを用意し、学生が入力を変えて試した後に、改善目標を見つけて開発を進めることを想定しています。

**現在の状態：開発準備済み・コード未実装です。** このディレクトリに実装と関連ファイルを追加します。

## Claude Codeで作成する場合

詳細な作成指示は [CLAUDE_CODE_PROMPT.md](CLAUDE_CODE_PROMPT.md) にまとめています。リポジトリのトップでClaude Codeを起動し、次を伝えてください。

```text
projects/recipe-suggester/CLAUDE_CODE_PROMPT.md を読み、仕様に沿って初期コードを実装してください。説明書の更新と、可能な範囲の動作確認までお願いします。
```

## 初期版の方針

- Google ColabのCPU環境で、上から順に実行できるノートブックを中心にします。
- APIキーなしで動く、同梱レシピの検索・提案を基本機能にします。
- 生成AIへの接続は任意の追加機能にし、基本機能を実行するための必須条件にはしません。
- 本体は `recipe_suggester.ipynb` に置き、初期レシピと単価表はノートブック内のセルにまとめる予定です。Colabで開いた直後から試せるようにします。
- 学生が条件の扱い、費用計算、表示を読み、変更できる大きさにまとめます。

## 入力と出力

| 項目 | 例・扱い |
| --- | --- |
| 料理の種類 | 麺類、ご飯類、スープ、おかず、おまかせ |
| 主な食材の区分 | 肉、魚介、野菜・豆類、卵・乳製品、おまかせ |
| ジャンル | 和食、中華、洋食、エスニック、おまかせ |
| 食事の場面 | 朝食、昼食、夕食、おまかせ |
| 人数・予算 | 人数と、1人当たりの材料費の上限 |
| 使いたい食材 | 必須で使う食材と、できれば使いたい食材を区別 |
| 出力 | 最大3品の候補、指定人数の材料と分量、手順、所要時間、概算材料費 |

料理は1品ずつの候補として提案します。複数品を組み合わせた献立の最適化は、発展課題として考えられます。

## 予算の扱い

同梱する参考単価と使用量から、Pythonで材料費を計算します。表示するのは「使う量に相当する材料費」の概算で、店で購入する一袋・一パック単位の支出や、実際の販売価格を保証するものではありません。調味料も単価表に含め、価格の前提を説明します。

必須条件を満たす候補がなければ、その旨と条件を見直す案を表示します。条件を黙って無視して候補を出すことは避けます。

## 学生が試せる改善例

- 同じ食材で提案が偏る理由を調べ、並べ替え方を変える。
- 朝食向けの判定に、調理時間などの条件を加える。
- レシピや参考単価を追加し、提案できる範囲を広げる。
- 材料費の内訳を見やすく表示する。
- 入力欄やボタンを付ける。
- 生成AIによる提案と、登録済みレシピからの提案を比較する。

実装時には、実際に動く手順、データの説明、確認結果をこのREADMEに追記してください。
