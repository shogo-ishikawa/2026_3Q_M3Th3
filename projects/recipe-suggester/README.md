# 献立ノート

朝・昼・夕・間食をカレンダーに記録し、次の献立と買うものを考えるブラウザーアプリです。食べた内容から分かる栄養の量を振り返り、手持ちの食材も使いながら献立を提案します。材料と作り方もアプリの中で確認できます。

v2.0.0では325品と160種類の食材・調味料を収録しています。主菜112品、副菜80品、汁物50品、主食31品、飲み物22品、間食30品です。

**[ブラウザーで開く](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/recipe-suggester/)** ／ [使い方](docs/manual.md) ／ [コード一式（ZIP）](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/recipe-suggester/dist/meal-planner_v2.0.0.zip)

[学生オリジナル「AI献立スマートシェフ」を開く](https://cish25155-prog.github.io/SmartChef/)

## できること

| 機能 | 内容 |
| --- | --- |
| 食事カレンダー | 日付と朝食・昼食・夕食・間食を選び、複数の料理を記録する。「これからの予定」と「食べた」を切り替えられる |
| 栄養を振り返る | エネルギー・たんぱく質・脂質・炭水化物・食物繊維・食塩相当量を概算する。1日分と直近7日間を表示する |
| 記録を使った献立 | 直近の食べた内容、分かる栄養、料理の重複、手持ちの食材を参考に候補を選ぶ |
| 主食と飲み物 | ご飯・パン・うどん・パスタなどの主食と飲み物を選ぶ。主食を含む主菜には主食を重ねない |
| アレルギーと除外食材 | 表示対象29品目と個別の食材を指定する。材料の原料関係もたどって候補から除く |
| ジャンルと気分 | ジャンルのおまかせ・単一指定・比率指定、気分、優先したい食材を使い分ける |
| 自分のメニュー | DBにない食事を手入力する。栄養・材料・作り方も記録でき、希望すれば自分のDBに保存する |
| 手持ちの数量管理 | 食材と調味料の量をg・ml・個などの登録単位で保存する |
| 買い物リスト | 提案中の献立やカレンダーの予定から必要量を合計し、手持ちの量を差し引く |
| 保存と持ち運び | このブラウザーに記録を保存する。JSONでのバックアップと旧版の記録の引き継ぎに対応する |

## まず試すには

1. カレンダーで日付を選び、食べたメニューを登録します。外食や市販品は手入力できます。
2. アレルギーと避けたい食材を確認し、献立の日数・人数・食事区分を選びます。
3. 主食や飲み物の希望を選んで献立を作ります。料理を開くと1人分の材料と作り方を見られます。
4. 内容を調整し、「予定としてカレンダーへ」で保存します。食べたら状態や量を更新します。
5. 手持ちの食材を登録し、買い物リストで不足分を確認します。

献立は1〜7日分、買い物の人数は1〜8人分で指定できます。カレンダーと栄養は1人分を基準にするため、家族4人分の買い物を作っても自分の摂取量が4倍になることはありません。食べた量は各メニューの「人分」で調整します。

## 数字と食材の扱い

栄養の数字は食材の分量から求めた概算です。商品の配合や調理方法によって変わります。不明な成分は0にせず、分かる分の合計に「＋不明分」を添えます。未記録の食事を食べなかったとは判断せず、未来の予定も摂取量には含めません。

比較値は自由に編集できます。初期値は学習用の参考値であり、個人の必要量を決めるものではありません。食品の対応、単位の換算、概算の限界は[栄養値の出典と換算方法](docs/nutrition-sources.md)にまとめています。

アレルギーと食材の除外条件は候補選びでも組み合わせの変更でも維持します。候補が足りない場合はそのことを表示し、条件を自動で外しません。自分で登録したメニューも、アレルギー情報が未確認のものは自動提案しません。

判定に使うのは登録済みの材料情報です。市販品の配合、代替品、製造・調理中の混入までは確認できません。実際に使う商品の表示と調理環境も確かめてください。

## 記録は手元に保存

食事の記録、自分のDB、手持ちの食材、除外条件はブラウザー内に保存します。アカウント登録やAPIキーは不要です。個人の記録をGitHubや共有DBに送る機能はなく、別の端末との自動同期もありません。

「データを書き出す」でJSONを保存すると端末の移行やバックアップに使えます。読み込み時には形式を検査し、内容を確認してから現在のデータを置き換えます。旧版の記録も引き継げます。

作成中の提案はカレンダーへ登録するまで保存されません。在庫の数量を変えた場合は提案を残して買い物リストを再計算します。「食事の記録をすべて削除」で消えるのはカレンダーの記録です。自分のDBや設定も消したい場合は、ブラウザーでこのサイトの保存データを削除してください。

## コードを変更する

| ファイル | 内容 |
| --- | --- |
| `data.js`・`expanded-foods.js` | レシピ、食材・調味料、アレルゲンと食品群 |
| `ingredient-nutrients.js` | 食材の栄養値と成分表との対応 |
| `planner.js` | 除外条件、候補選び、記録を使った提案、組み合わせの変更 |
| `nutrition.js` | 1人分の栄養計算、記録の集計、不明値の扱い |
| `journal.js` | カレンダーとマイDBの保存、JSONの検査、旧版からの移行 |
| `shopping.js` | 予定の材料を合計し、手持ちの量を差し引く処理 |
| `app.js`・`index.html`・`styles.css` | 操作と表示 |
| `storage.js` | 従来の保存形式と互換用の処理 |
| `meal_planner.ipynb`・`recipe_suggester.ipynb` | Pythonの基礎を学ぶColab教材 |
