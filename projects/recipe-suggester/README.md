# Meal Palette（ミールパレット）

食事の記録、栄養の振り返り、次の献立と買い物をつなぐブラウザーアプリです。食べたものを種類から選び、ご飯はg、飲み物はml、おにぎりは個数で記録できます。v3.0.0では画面を6つのタブに整理し、旧「献立ノート」から名称とデザインも改めました。

v3.0.0は421品のメニューと183種類の食材・調味料を収録しています。主菜112品、副菜80品、汁物55品、主食92品、飲み物27品、間食55品です。

**[ブラウザーで開く](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/recipe-suggester/)** ／ [使い方](docs/manual.md) ／ [コード一式（ZIP）](https://shogo-ishikawa.github.io/2026_3Q_M3Th3/projects/recipe-suggester/dist/meal-planner_v3.0.0.zip)

## 6つのタブで使う

| タブ | できること |
| --- | --- |
| 記録 | カレンダーで朝食・昼食・夕食・間食を管理する。予定と食べた実績を分け、量や内容を直せる |
| 栄養 | エネルギー・たんぱく質・脂質・炭水化物・食物繊維・食塩相当量を概算し、1日・7日・30日の記録を振り返る |
| 献立 | アレルギーや除外食材を確認し、好みと食べた記録を参考に提案する。主食と飲み物の種類・量も指定できる |
| 買い物 | 献立の必要量を人数分まとめ、手持ちの食材・調味料を差し引く |
| メニュー | 種類から料理を探し、材料と作り方を確認する。自分のメニューも管理できる |
| 設定 | 比較用のプロフィールや数値を設定し、JSONで記録を保存・読み込みする |

## メニューを選んで量を記録

「ご飯」と「おにぎり」は別の大分類です。ご飯の中で白米・玄米・炊き込みご飯・わかめご飯などを選び、おにぎりは塩・鮭・梅・ツナマヨなどから選べます。

うどん・そば・パスタ・焼きそば・カレーライス・ピザ・チャーハンなども種類ごとに探せます。飲み物は水やお茶、コーヒーなどから選び、水の中にレモン水や炭酸水をまとめています。みそ汁は具の違いを小分類で選べます。間食には菓子やスイーツ、チーズ、ホットスナックなども収録しています。

1人分を150gとするご飯を100g食べた場合、栄養と材料は`100 ÷ 150`倍になります。献立で指定した量もカレンダーと買い物へ引き継ぎます。買い物用の人数は別に設定するため、家族4人分を作っても自分の摂取量が4倍になることはありません。

DBにない食事は名前と量だけでも手入力できます。栄養成分表示や材料が分かれば補い、自分のDBにも保存するか選べます。空欄は不明のまま残し、共通DBへ自動で送信しません。

## 栄養を振り返る

食べた記録だけを1人分で集計します。予定や未記録の食事は摂取量へ加えません。不明な栄養は0とせず、分かる量と区別して表示します。収録メニューの栄養は食品成分表と材料の分量から求めた概算です。

その日の飲食をすべて登録したら「この日の飲食をすべて記録した」を選びます。最近の平均には記録を完了した日を使い、成分が不明な日はその成分の平均から除きます。計算に使った日数も表示するので、入力途中の日が平均を小さく見せることを避けられます。

「設定」では18歳以上の年代、基準表の性別区分、普段の活動量を選び、厚生労働省の「日本人の食事摂取基準（2025年版）」から比較の目安を選べます。数値を自分で設定する方法も使えます。体格に応じた必要量の計算や健康状態の診断ではありません。妊娠・授乳中、18歳未満、治療用の自動設定には対応していません。

食品の対応や換算は[栄養値の出典](docs/nutrition-sources.md)、年代別の目安は[食事摂取基準の出典](docs/dietary-reference-sources.md)にまとめています。

## 献立から買い物へ

献立は朝食・昼食・夕食・間食から選んで1〜7日分、買い物は1〜8人分を指定できます。主食と飲み物の希望、ジャンルや比率、気分、優先する食材を設定できます。パスタやカレーライスなど一品で主食を含む料理には、別の主菜やご飯を重ねることを避けます。

アレルギーと個別食材の除外は候補選びでも変更時でも優先します。候補が足りなくても条件を自動で外しません。市販品の配合や混入は判定できないため、実際に使う商品の表示も確認してください。

提案した献立を確認して予定へ登録し、食べたら内容と量を直します。買い物リストは提案中の献立かカレンダーの予定を使い、同じ食材の必要量を合算してから在庫を一度だけ差し引きます。在庫の数量更新では提案を維持して再計算します。食べた実績から在庫を自動で減らす機能ではありません。

## 記録を手元に残す

食事の記録、プロフィール、自分のDB、手持ちの食材や設定はブラウザー内に保存します。ログインやAPIキーは不要です。GitHubや共有DBへ個人の記録を送る機能と、端末間の自動同期はありません。

「設定」の「データを書き出す」でJSONを保存できます。読み込み時は形式を検査し、確認後に現在のデータを置き換えます。旧「献立ノート」のv1・v2の記録も引き継げます。旧版では1日の記録がそろっているか分からないため、完了した日のチェックは自動で付けません。

## コードを変更する

| ファイル | 内容 |
| --- | --- |
| `data.js`・`expanded-foods.js`・`everyday-foods.js` | メニュー、材料・調味料、アレルゲンと分類 |
| `catalog.js` | 大分類と小分類、1人分の表示量、入力した量から倍率への換算 |
| `ingredient-nutrients.js` | 食品成分表と単位当たりの栄養 |
| `dietary-reference.js` | 年代・性別・活動量と比較用の目安 |
| `planner.js` | 除外条件と候補選び、記録を使った提案、組み合わせの変更 |
| `nutrition.js`・`intake.js` | 1人分の計算、期間集計、不明分と記録完了日の扱い |
| `journal.js` | v3保存形式の検査、旧版からの移行、日付処理 |
| `shopping.js` | 予定の材料を合計して在庫を差し引く処理 |
| `app.js`・`tabs.js`・`index.html`・`styles.css` | 操作、タブの切り替え、表示 |
| `storage.js` | 旧版のAPIと互換処理 |
